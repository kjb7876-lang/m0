# R1304 3D 환도 마감 — 7분야 전문가 심사

심사 조건: Edge 154 headless + SwiftShader, PC 1280×720 / 모바일 844×390. 새 게임 난수는 고정했고 플레이어 `(87.7, 64)`, 카메라와 겹침 벽 `(88, 64, 0.24×2, 높이 2.85)`을 고정했다. 전후는 각각 [PC 전](before-pc.png)·[PC 후](after-pc.png), [모바일 전](before-mobile.png)·[모바일 후](after-mobile.png)이다. 별도 실행으로 인한 배경 시뮬레이션 프레임 차이가 있어 가림 판정은 스크린샷과 장면 그래프/depth 속성 검사를 함께 사용했다.

| 분야 | 점수 / 10 | 심사 |
|---|---:|---|
| 미술 | 8.2 | 한지색 저채도 필터를 셰이더로 옮겨 기존 영웅 톤을 유지했다. 로브 중앙 14,719정점을 Pelvis 179/255 + 양 Thigh 38/255로 맞춰 하단이 두 바지처럼 갈라지는 원인을 제거했고, 부츠의 좌우 웨이트는 유지했다. |
| 연출 | 8.2 | 대기·걷기·베기 크로스페이드와 방향 완급을 보존했다. 벽 앞에서는 영웅이 공간 안으로 물러나 보이고, 앞쪽 효과 레이어는 계속 영웅 위에 남는다. |
| 카메라구도 | 8.0 | 기존 등각 카메라를 그대로 공유한다. 발 기준점 오차 2.53px, 화면 높이 58.95px(기준 53.68px)로 PC·모바일 모두 읽히며 별도 캔버스 좌표 드리프트가 없다. |
| 공간·인테리어 | 8.6 | 별도 오버레이를 없애고 모델을 벽/몸과 같은 layer 2에 배치했다. 모든 GLTF 메시가 `depthTest=true`이고, 불투명할 때만 `depthWrite=true`라 반투명 피격 중에도 실제 활성 scene의 벽·지형과 같은 depth pass에서 가림이 결정된다. |
| 조명·색채 | 8.1 | 기존 월드의 따뜻한 주광·주변광을 함께 받아 배경과 분리되지 않는다. 채도 0.62의 회백 한지 톤, 낮은 금속성, 높은 거칠기로 호러 장면의 저채도 긴장감과 실루엣 우선 원칙을 유지한다. |
| 애니메이션·VFX | 8.2 | Idle/Walk/Attack 세 클립, 속도 연동 걷기와 공격 완급 검사가 모두 통과했다. R350/R448이 원래 몸을 먼저 처리한 뒤 본체만 3D로 치환하며, 방어막·오라·사몽 십자와 R113/R945 재귀 분신은 원래 레이어에 남긴다. |
| UX·레벨 | 8.3 | 기본 꺼짐과 기존 저장 키를 유지한다. 꺼짐 GLB/GLTFLoader 요청 0, 첫 켬 각 1, 재활성화 추가 요청 0이며 다른 영웅으로 바꾸면 즉시 2D로 복귀한다. 로더는 모듈/GLB 병렬 시작과 `parseAsync`의 fetch·parse·전체 시간 계측을 제공한다. |

평균 **8.23 / 10 — 통과** (`8.23 > 7.77`).

색채심리·호러 원리 확인: 고채도 경고색을 새로 만들지 않았고, 인물의 저채도/밝은 실루엣은 유지하되 벽 뒤에서는 의도적으로 대비를 낮춰 공간적 불확실성을 만든다. 화면 가장자리의 암부와 중앙 한지빛 시선 유도도 기존 구도를 보존한다.

미검증: SwiftShader가 아닌 실제 GPU/실기기 장시간 플레이의 GPU 시간·VRAM·열화상은 이번 환경에서 측정하지 못했다. 헤드리스 샘플은 R1303 `loadMs` 1,895ms, R1304 `fetch 46.3ms / parse 56.4ms / load 158.1ms`였지만 캐시와 장치 영향이 큰 참고값이며 성능 보장은 구조 검사(두 번째 WebGLRenderer 제거, 병렬 로드, 1회 요청)로 판단했다.
