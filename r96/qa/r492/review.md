# R492 렉 개선 — 테두리 굽기를 거리 변환 한 번으로 (2026-11-09 밤)

사용자 요청(11-09 14:31Z): "렉도 최대한 없도록 렉개선 … 여러 전문가 검수해서 통과하면 알아서 병합배포".

## 재현·증거 (헤드리스 Chromium, 640×360, 777 → 길잡이 켬, 지역마다 12초 CPU 프로파일)
- 세 지역(dist00·ep1a08·ep1b04) 게임 JS 13.6초 중 **R409 테두리 굽기 2,095ms(15.4%) — 파일 1위**.
  그중 1,717ms 가 drawImage: 가림판 캔버스를 둘레 각도 8~16개 × 고리 2~3겹으로 수십 번 그려 '불리는' 방식.
- 먼저 세운 가설 "같은 텍스처를 다시 올린다"는 실측(같은 그림 객체 반복 업로드 0~2번)으로 기각하고 그 코드는 버렸다.

## 고침 (combat-read-r409.js, REV R409-combat-read-4)
- 가림판(알파>115, R440 칼날 빼기 그대로)의 거리 변환(세로 앞뒤 훑기 + 가로 Felzenszwalb)으로 픽셀마다 몸까지 실제 거리를 구한다.
- 덮임 = clamp(반지름 + 0.5 − 거리). 바깥 테 → 안쪽 선 → 칼날 선(알파 .75) → 원본 순서, 색·알파·두께(r, ri=round(.45r))·여백(pad=r+1)·캐시 열쇠·6ms 굽기 예산 그대로.
- 끄기: `localStorage['storyworld.r409.combatRead']='{"fastBake":false}'` (바꾸면 캐시를 비워 다시 굽는다).
