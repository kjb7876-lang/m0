# R217 — 뿌리 보스 너프 · 보스 최소 크기 · 시야 배율 · 통로 확장 · 렉

사용자 요청(2026-11-02):
1. 뿌리 보스 분신 사용 간격 늘리기(66% 이상 너프), 뿌리 보스 체력을 지금의 66% 수준으로
2. 맵 통로 전체 확장, 보스는 최소 영웅의 1.6배 이상(보라검천사가 너무 작게 나옴)
3. 시야를 0.7배까지 좁혀 영웅이 잘 보이게 하는 설정
4. 전체적인 렉 개선 / 실제 플레이하며 시각·렉·디버깅 개선

### 렉

헤드리스 길잡이 자동 진행 상태에서 JS 자체 시간을 쟀다.
- 충돌 질의 사슬이 JS 시간의 약 1/3이다. 사슬에는 겹겹이 감싼 `blocked`, 문 `isOpen`, `explorationBlocked`, `clearPath3` 가 들어 있다.
- dist00에서 10초 동안 `clearPath3` 는 48,476회, 729ms였다. 그중 칸 중심 간선이 47,612회이고, 35,580회는 같은 간선을 다시 물은 것이었다.
- 기억을 켠 뒤 같은 조건에서 390ms로 줄었다(적중률 약 63%).

### 보스 크기

dist01 보라검천사와 dist00 뿌리의 문지기를 영웅 옆에 깨워 두고 스크린샷으로 비교했다(헤드리스, 그래픽 검증 아님).
