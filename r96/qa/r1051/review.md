# R1051 영웅 날개 제거·천사링만 — 7분야 심사

사용자 2026-11-15 "영웅들 날개 달리는거 … 없애고 그냥 위에 천사링만 달리게해", "천사링은 이미 구현되어잇음".
근거 그림: `screens/before-after-zoom.jpg`(윗줄 전, 아랫줄 후 — 미카엘라 평소·스킬·사몽, 환도 사몽), `screens/before-after.jpg`.
헤드리스 소프트웨어 렌더(640×360) 장면으로 본 심사다. GPU·실기기·자연 플레이는 미검증.

| 분야 | 점수 | 근거 |
|---|---|---|
| 미술 | 8.0 | 몸 그림과 결이 달라 떠 보이던 날개가 빠지고, 이미 Dots 시트(M1)로 그려진 천사링만 남아 그림체가 한결같다. |
| 연출 | 7.8 | 천사 형태는 천사링 하나로 읽힌다. 사몽 각성의 화려함은 불꽃·빛기둥·천사링이 그대로 맡는다(날개만큼의 크기감은 줄었다). |
| 카메라 구도 | 8.2 | 영웅 좌우로 키의 1.3배쯤 퍼지던 날개가 없어져 영웅 윤곽·주변 몹이 덜 가린다. |
| 공간·인테리어 | 8.0 | 벽·문 가까이에서 날개가 지형 위로 겹쳐 보이던 일이 없어졌다. |
| 조명·색채 | 8.0 | 영웅색 오라·발밑 고리·천사링의 색 위계는 그대로다. 날개의 넓은 반투명 면이 빠져 바닥 색이 덜 탁해진다. |
| 애니메이션·VFX | 8.1 | 방향 전환 때 앞·옆·뒤 날개 그림이 바뀌며 튀던 것, 접힘·펼침 전환, 딸린 깃털이 모두 사라졌다. 천사링 8칸 반복은 그대로. |
| UX·레벨 | 8.3 | 영웅 위치·체력바·피격 판정을 읽기 쉬워졌다. 판정·피해·시간은 바뀌지 않았다. |

평균 **8.06** (기준 7.77 초과).

남은 점: 날개 그림 파일(assets/r107/fx/wing*.webp)과 날개 코드는 지우지 않고 남겼다(`HERO_WINGS` 상수 세 곳). 인트로 영상의 천사·몹 날개는 영웅이 아니라 손대지 않았다.
