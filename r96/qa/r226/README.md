# R226 — 미카엘라 대각선 위(북동·북서) 달리기 다리 번갈기

사용자 2026-11-02: "미카엘라 이동모션 대각위동작만 개선해줘봐 한쪽발만나가는거 같은데 다리만좌우반전해서 디테일개선해서하믄되지않을까"

## 원인

- 게임은 북동에 `assets/r164/michaela/run-ne-v2.webp`(8칸, R169 v2)를 쓴다. 북서는 이 그림을 좌우 반전해서 쓴다.
- 칸마다 아래 다리를 확대해 보니 8칸 모두 왼다리가 딛고 오른다리만 뒤로 굽혀 차올렸다. 정말 한쪽 다리만 나갔다.

## 고친 것

새 시트 `assets/r226/michaela/run-ne-v3.webp` 를 만든다. 원본은 그대로 둔다.

- **1~4칸**: 그대로.
- **5~8칸**: 윗몸(팔·머리·지팡이·코트)은 그 칸 그대로 두고, 코트 밑단 아래 다리만 1~4칸 다리를 좌우 반전해 넣는다.
  - 엉덩이 축(이음선 아래 불투명 x 중앙값)을 칸마다 맞춘다.
  - 이음선은 y=178이다(코트 밑단 최저 175). 6px 동안 서서히 섞는다.
  - 뒤집은 다리에서는 발에 이어진 덩어리만 남긴다. 떠 있는 코트 조각은 지운다.
- **결과**: 앞 4칸은 오른다리, 뒤 4칸은 왼다리가 차올라 두 다리가 번갈아 나간다.
- **유지하는 것**: 발 기준점(96,226)·칸 크기·몸 키는 그대로다.
- **끄기**: `visual-r119.js` 설정 `{run226:false}` 로 v2 로 돌아간다.
