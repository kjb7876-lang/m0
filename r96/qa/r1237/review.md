# R1237 7분야 심사 (헤드리스 스크린샷 기준 — GPU·실기기·자연 플레이 미검증)

대상: 환자와 중독의 도시(ep1a10) 낙서 상점 건물 2채(100/90px → 210px, 벽 끝에 붙임, 상시 글자 제거, C 창),
결전의 날(ep1a09b) 보스방 봉인 성물함 1개(58 → 130px), 포인트 상자 +1 구슬 1~7개 흩뿌리기.
스크린샷: 1280×720 헤드리스(/mnt/project-files/r1237/ before·store0·store1·panel·orbs-mid·orbs-land·seal1).
