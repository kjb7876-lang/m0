# R222 — 스킬업(P · 패시브 강화) 창 다듬기

사용자 2026-11-02: "스킬업ui 개선해줘"

## 실측 문제(헤드리스 1280×720, Lv.12)

- **설명에 가려진 카드**: 창 위쪽 설명 다섯 줄 때문에 강화 카드가 아래로 밀렸다. 창 높이 1145px 중 660px만 보였다.
- **겹치는 표시**:
  - 포인트가 두 번 표시됐다.
  - 쓸 수 없는 '앞으로 ▶' 단추가 보였다.
- **이유 없는 회색 +1 단추**:
  - Z·X·C 스킬강화: 원래 카드에는 "사몽 루트를 시작하면 열립니다"가 있었지만 모음에는 보이지 않았다.
  - 일반강화 9종: 이미 최대(6/6 등)인데 "다음 1점"으로 보였다.
- **읽기 어려운 설명**:
  - 설명이 '…'로 잘렸다.
  - 수식이 그대로 보였다. 예: `공격 간격 × [0.28 + 0.72 / (1 + 0.04 × 단계)]`

## 바뀐 것: `ui-upgrades-r222.js`

- 읽는 위치: `play-r115.js` 바로 뒤
- 그림·구매 규칙·비용은 그대로 두고, R115 모음 위에 덧칠만 한다.

| 항목 | 전 | 후 |
|---|---|---|
| 설명 문단 4개 | 항상 펼침 | "규칙 · 지금 효과 보기" 접기 안 |
| 포인트 | 본문 문장 | 제목 옆 배지 "사용 가능 N점" |
| 최대 단계 | "다음 1점" + 회색 +1 | "N단계 · 최대" + '최대' |
| 잠긴 강화 | 회색 +1 | '잠김' + 🔒 열리는 조건 한 줄 |
| 포인트 부족 | 회색 +1 | '부족'(필요 점수는 마우스 올리면) |
| 살 수 있는 강화 | 다른 단추와 같음 | 금빛 테두리 |
| 수식 설명 | `× [0.28 + 0.72 / (1 + 0.04 × 단계)]` | "공격 간격 100% → 다음 97.2%"(원래 수식은 마우스 올리면) |
| 긴 설명 | 한 줄 '…' | 두 줄까지 |

- 수식 계산은 숫자와 `+ - × / ( )`만 받는 작은 계산기로 한다. eval 은 쓰지 않는다.
- 끄기: `localStorage['storyworld.r222.upgradesUi']='{"on":false}'`
