## 실측 문제(헤드리스 1280×720, Lv.12)

- **설명에 가려진 카드**: 창 위쪽 설명 다섯 줄 때문에 강화 카드가 아래로 밀렸다. 창 높이 1145px 중 660px만 보였다.
- **겹치는 표시**:
  - 포인트가 두 번 표시됐다.
  - 쓸 수 없는 '앞으로 ▶' 단추가 보였다.
- **이유 없는 회색 +1 단추**:
  - Z·X·C 스킬강화: 원래 카드에는 "사몽 루트를 시작하면 열립니다"가 있었지만 모음에는 보이지 않았다.
  - 일반강화 9종: 이미 최대(6/6 등)인데 "다음 1점"으로 보였다.
- **읽기 어려운 설명**:
  - 설명이 '…'로 잘렸다.
  - 수식이 그대로 보였다. 예: `공격 간격 × [0.28 + 0.72 / (1 + 0.04 × 단계)]`

## 바뀐 것: `ui-upgrades-r222.js`

- 읽는 위치: `play-r115.js` 바로 뒤
- 그림·구매 규칙·비용은 그대로 두고, R115 모음 위에 덧칠만 한다.

| 항목 | 전 | 후 |
|---|---|---|
| 설명 문단 4개 | 항상 펼침 | "규칙 · 지금 효과 보기" 접기 안 |
| 포인트 | 본문 문장 | 제목 옆 배지 "사용 가능 N점" |
| 최대 단계 | "다음 1점" + 회색 +1 | "N단계 · 최대" + '최대' |
| 잠긴 강화 | 회색 +1 | '잠김' + 🔒 열리는 조건 한 줄 |
| 포인트 부족 | 회색 +1 | '부족'(필요 점수는 마우스 올리면) |
| 살 수 있는 강화 | 다른 단추와 같음 | 금빛 테두리 |
| 수식 설명 | `× [0.28 + 0.72 / (1 + 0.04 × 단계)]` | "공격 간격 100% → 다음 97.2%"(원래 수식은 마우스 올리면) |
| 긴 설명 | 한 줄 '…' | 두 줄까지 |

- 수식 계산은 숫자와 `+ - × / ( )`만 받는 작은 계산기로 한다. eval 은 쓰지 않는다.

# R222 — 길잡이 멈춤 풀기 (`guide-unstick-r222.js`)

## 실플레이에서 찾은 멈춤

처음부터 미카엘라 엔딩까지 길잡이로 헤드리스 실플레이를 돌렸다.

| 곳 | 증상 | 재현·원인 |
|---|---|---|
| dist01 거미동굴 (19.5, 58.1) | 길 168점이 있는데 40초 넘게 제자리 | 같은 자리에 세우면 매번 멈춘다. 다음 길점(13.88, 55.5)이 영웅 반지름 .27로는 막혀 있다. 길찾기는 칸 중심을 .29로만 묻고, 편 길점은 벽 끝에 걸친다. |
| dist00 앞방 (52, 61.9) | 20분 넘게 제자리, 가까운 적 0, 침식체 2/3 | 앞방 문을 닫고 안에 세워 보니 길잡이가 문을 열고 나왔다. 정확한 원인은 **미확정**이다. 실플레이 기록기에 멈춤 순간 상태를 남기도록 했다(STUCKDUMP). |

## 고친 것

길잡이가 켜져 있을 때만 바뀐다. 손으로 움직일 때는 그대로다.

| 제자리 시간(게임 시간) | 하는 일 |
|---|---|
| 0.6초 | 영웅 반지름에서 막힌 앞쪽 길점을 건너뛴다(최대 6개). |
| 1.5초 | 다음 길점 쪽으로 직각 옆걸음 0.3칸(막히지 않은 쪽). |
| 3초 | 손 닿는 닫힌 문이 있으면 연다. 없으면 길을 비워 다시 찾게 한다. |
| 6초 | 마지막 수단: 길 앞쪽 2칸 안의 막히지 않은 길점으로 옮긴다(`stats.hops`로 센다). |

- 길잡이의 E 는 열린 문을 닫지 않는다. 그 순간만 열린 문을 손 닿는 거리 밖으로 뺐다가 되돌린다.
- 3칸 안에 살아 있는 적이 있으면(제자리 전투) 움직이지 않는다. `room.engaged` 는 '집결한 생존 적' 같은 필드 전투 내내 켜져 있어 기준으로 쓰지 않는다. 처음에 그걸 기준으로 했더니 dist01 멈춤이 다시 났다.
- 사몽 구역 입구의 '이전 구역' 표지는 길잡이 E 로 고르지 않는다. 사몽 실플레이에서 S01-3 에 도착하자마자 단서를 줍다 S01-2 로 되돌아갔다 오는 왕복이 있었다.
- 끄기: `localStorage['storyworld.r222.guideUnstick']='{"on":false}'`
