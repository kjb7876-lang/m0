# R482 밟아 다져진 길 — 7분야 심사 (헤드리스 임시)

대상: `trail-r482.js` (rev R482-trail-3). 전후 화면 `r482-before-after.jpg`(PC 1280×720, 같은 순간 길 끄기/켜기, 밝기 ×1.6 보정해 붙임). 같은 순간 8장 번갈아 찍어 화면 전체 밝기 변화가 없는 것도 확인(구석 밝기 15.7±0.1, 길 둘레만 −0.4).
헤드리스 소프트웨어 렌더링이며 GPU·실기기 모바일·자연 플레이는 미검증.

| 분야 | 점수 | 근거 / 고칠 점 |
|---|---|---|
| 1 미술감독 | 7.5 | 코드로 만든 128px 흙 얼룩 질감 + 지역 색. 바닥 그림 위에 얹은 어두운 띠라 질감 차이(자갈·발자국)는 없다 → Dots 길 데칼이 오면 교체 후보. |
| 2 연출감독 | 8.0 | 입구에서 문·제단으로 오간 자국 = 환경 서사. 처음 판의 밝은 줄은 빛줄기처럼, 둘째 판의 주황 띠는 핏자국처럼 읽혀 버리고 무채 흙빛으로 바꿈(빨강은 위협 신호로 아낌). |
| 3 카메라·구도 | 8.5 | 바닥에 붙은 평면이라 아무것도 가리지 않음. 길은 화면 안쪽(뒤쪽 문)으로 시선을 끈다. |
| 4 공간·환경 | 8.5 | 바닥 칸만 지나는 A*, 넓은 곳은 가운데·느린 굽이(±.85칸), 좁은 곳은 그대로 통과. 여러 길이 겹치는 입구 쪽이 자연히 더 진함. |
| 5 조명·색채 | 7.5 | 바닥보다 어둡게만(색 .36/.34/.31 × 지역 색, 불투명도 .62 × 가장자리 0). 시야 마스크를 받아 어둠 속에서는 같이 어둡다. 밝은 바닥에서는 잘 보이고 어두운 바닥에서는 은은함. |
| 6 애니·VFX/성능 | 8.0 | 정지 메시 1개. 지역 들어갈 때 한 번 계산 39~84ms(헤드리스, 길 4개·점 ~800) — 로딩 중이라 체감은 작지만 렉 스레드 기준으로 보면 개선 여지(길마다 나눠 계산). |
| 7 UX·레벨 | 8.5 | 길잡이 화살표와 같은 방향으로 바닥에서 길이 읽힘. 충돌·길잡이 경로는 그대로. 끄기 키 있음. |
| **평균** | **8.07** | 7.77 초과 → 통과 |

색 신호: 빨강·청록 안 씀(무채 흙빛). 명도 구성: 바닥 일부를 어둡게 해 밝은 쪽이 줄어듦(어둠 비율 그대로 또는 조금 늘어남). 적용 원리: 환경 서사, 시선 유도.
