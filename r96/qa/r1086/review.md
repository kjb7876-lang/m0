# R1086 한지 창 — 7분야 심사 (헤드리스 캡처로 봄, 자체 심사)

사용자 지시 "ui조금더 동양화수묵화풍으로 개선", "세로 탄막겜참조 지금만들고있는". 참조: 사용자의 세로 탄막 게임(합일 세로 리부트) 수묵 UI — 한지 바탕, 먹 글씨, 먹 으뜸 단추, 붓으로 그은 듯한 단추 테, 낙관 合. 색·모양만 참고했고 코드·그림은 가져오지 않았다.
같은 화면을 한지 끔(R1085 먹빛 창)과 켬으로 찍어 비교했다(PC 1280×720, 폰 가로 844×390). 전후 그림: 프로젝트 파일 `ui-r1086/`.

| 분야 | 점수 | 근거 |
|---|---|---|
| 미술 | 8.1 | 창이 한지(#e4dac2)·먹 글씨(#1e1a18)·먹 으뜸 단추·서로 다른 반지름의 붓 테 단추·인주 낙관 合·먹 붓 획 밑줄·구석 먹 번짐·닥 섬유 결로 바뀌어 참조 게임과 같은 계열로 읽힌다. 지도 칸의 지역 그림은 한지에 곱해져 먹 그림처럼 스민다. 약점: 영웅 선택 무대(어두운 보랏빛 칸)는 초상 때문에 그대로 둬서 한지 위에 검은 덩어리로 놓인다. |

평균 7.89 (> 7.77).

## 유지한 것
구슬 체력, 서사 자막 토글, 폰 화면 단추(회피·영웅 배치), 설정의 스킬창, 스킬 키, 폰 자동 이동 기본값, 폰 성능 단계. 전투 HUD(머리띠·아래 띠·기술 칸·미니맵·보스 막대·쪽지)의 색·모양·자리. R1085 파일과 R1055 파일은 고치지 않았다.

## 검사 수정(사용자 지시에 따른 동작 변경)
- `qa/r1085/r1085-browser.mjs`: 시작할 때 `storyworld.r1086.hanji='0'` 한 줄. R1085 검사는 '먹빛 창'을 재므로 한지를 꺼서 R1085 만 재게 했다. 판정 기준은 그대로다.

## 미검증
- GPU·실기기 모바일·자연 플레이(헤드리스 소프트웨어 렌더링만 확인).
- 명조 글꼴: 헤드리스에는 한글 명조가 없어 고딕으로 찍혔다. 실제 기기 글꼴은 못 봤다.
- 밤·어두운 방에서의 눈부심(사람 눈 확인 필요).
- 캡처에 없는 창(보스 입장·엔딩·상점류·사몽 전용 창)은 대비 바로잡기가 자동으로 돌지만 눈으로 보지는 않았다.
- 창 내용이 바뀔 때의 대비 재기 비용은 실기기에서 재지 않았다(0.15초에 한 번으로 제한, 창이 닫혀 있으면 돌지 않음).
