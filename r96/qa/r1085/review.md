# R1085 수묵화풍 UI — 7분야 심사 (헤드리스 캡처로 봄, 임시)

사용자 지시 "ui도 간결하고 수묵화풍으로 개선". 같은 화면을 끔(예전 금테 UI)과 켬으로 찍어 비교했다(PC 1280×720, 폰 가로 844×390). 전후 그림: 프로젝트 파일 `ui-r1085/`.

| 분야 | 점수 | 근거 |
|---|---|---|
| 미술 | 7.9 | 창·머리띠·기술 칸·쪽지가 R1055 진경산수풍과 같은 먹(#12161c)·중간 먹·한지(#ccc7b3)로 통일됐다. 금 그라데이션·둥근 알약·장식 틀 그림이 없어졌다. 붓 한 획 밑줄과 낙관 한 점이 제목마다 들어간다. 다만 붓 질감은 제목 밑줄과 창 윗선뿐이라 전체 인상은 '수묵'보다 '먹빛 단색'에 가깝다. |
| 연출 | 7.8 | 어두운 공포 분위기 유지. 으뜸 단추만 한지 조각이라 시선이 '처음부터 시작' 한 곳에 모인다. 영웅 선택 무대의 영웅별 강조색은 채색 한 점으로 남겼다. |
| 카메라 구도 | 7.8 | HUD 요소의 자리·크기는 끈 화면과 같다(검사로 대조). 아래 띠의 금 테두리 그림이 걷혀 화면 아래쪽이 덜 가린다. |
| 공간·인테리어 | 7.8 | 설정·지도의 '상자 안 상자'를 걷고 제목으로만 묶음을 나눠 줄이 정돈됐다. 카드·접는 줄만 가는 먹선 칸. |
| 조명·색채 | 8.0 | 본문 글자 대비 10 이상, 옅은 글자 4.5 이상, 으뜸 단추 7 이상(CPU 검사). 순백 없음. 따뜻한 색은 낙관·체력 구슬·영웅 강조색에만 남는다. |
| 애니메이션·VFX | 7.6 | 움직임을 더하지 않았다(흐림·키프레임·필터 없음). 번지는 먹 같은 움직임은 없다. |
| UX·레벨 | 8.2 | 끈 화면에서 보이던 조작(단추·입력·접는 줄)이 켠 화면에 모두 남는다(10개 화면 × PC·폰 대조). 숨긴 것은 영어 장식 줄·머리띠 부제·STORY 딱지뿐. 설정 → '수묵화풍 UI' 체크로 바로 끄고 켠다. |

평균 7.87 (> 7.77).

## 유지한 것
구슬 체력, 서사 자막 토글, 폰 화면 단추(회피·영웅 배치), 설정의 스킬창, 스킬 키, 폰 자동 이동 기본값, 폰 성능 단계. 초상 금테·길잡이 화살표·영웅 선택 무대 색은 그대로.

## 미검증
- GPU·실기기 모바일·자연 플레이(헤드리스 소프트웨어 렌더링만 확인).
- 명조 글꼴: 헤드리스에는 한글 명조가 없어 고딕으로 찍혔다. 윈도우(바탕)·맥(AppleMyungjo)·안드로이드(Noto Serif)에서 제목이 명조로 나오는지는 실기기 확인이 필요하다.
- 무한 생존·영화 모드·사몽 HUD, 보스 체력바, 황금실 도안 창은 규칙은 넣었지만 캡처로 보지 않았다.
- 기존 R1015 브라우저 검사의 '첫 화면 단추 9개 이하' 항목은 이 변경 전부터 11개로 실패한다(R1055 가 첫 화면에 단추 둘을 더한 뒤). 이 PR 은 단추 수를 바꾸지 않는다.
