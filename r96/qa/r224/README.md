# R224 — 실내 맵 방형식

사용자 2026-11-02 요청:
- 영상 첨부와 함께 "실내맵은 이런 느낌 방형식으로 만들어줘 디아블로섞어서"
- "이터널리턴도 많이참고해줘"

## 참고 영상에서 본 것

- 직사각형 방(회의실·화장실·복도)
- 낮게 자른 두께 있는 벽
- 방마다 다른 바닥
- 방 용도 가구(회의 탁자·소파·책장·벤치·포스터·화분)
- 건물 밖은 검은 공백

이터널리턴처럼 구역이 이름 있는 방 단위로 또렷하게, 디아블로처럼 어두운 톤으로 맞췄다.

## 바뀐 것: `cave-r204.js`, 실내 26곳

### 방 직사각형 키우기

R219 의 둘레 넓히기(BFS)를 대신한다. `prefs.rooms` 가 기본 켬이다.

- **기준**: R171 방(`worldR74.rooms`) 직사각형을 한 칸씩 사방으로 키운다.
- **멈추는 조건**:
  - 다른 방과 1칸 틈(= 벽)을 남긴다.
  - 문·입구 둘레와 외벽 1칸은 넘지 않는다.
  - 원래 바닥은 그 방에서 길로 가까운 것만 먹는다. 닫힌 문을 돌아가는 길이 생기지 않게 R219 와 같은 기준을 쓴다.
- **출입구**: 원래 통로가 방 사이 틈을 지나는 곳은 바닥으로 남는다.
- **벽·바닥 다시 만들기**: 칸막이 보존과 연결 확인은 R219 그대로다.

### 낮은 벽

새 벽 높이를 1.3으로 낮췄다(원래 2.85). 영상처럼 벽 너머 옆방이 보인다.

### 방 가구

방마다 뒤쪽 두 벽(위·왼쪽)을 따라 지역 계열 가구를 1~4개 놓는다.

| 계열 | 가구(world-r80) |
|---|---|
| 병원 | 침대·사물함·약장·링거대·모니터·휠체어·상담 탁자·의자 |
| 주택 | 낡은 소파·깨진 거울·주방 화덕·쓰레기 더미 |
| 도심·호텔 | 출입 단말·경보함·장부·소파 |
| 대장간 | 시간 압착기·검은 모래 화로·사슬 기둥 |
| 기계 | 빈 권한 단말·명령 중계기·신경 모니터·연결 캡슐 |
| 교단 | 흑장미 칩 제단·성물함·기억 그릇·기록판 |

- 막지 않는 장식이다(`solid:false`).
- 문·입구·목표·출입구 둘레 2칸은 비운다.
- 그림은 방에 들어온 뒤 읽는다(R80 은 자기 소품 그림만 미리 읽는다).

### 방 이름 표시

이터널리턴식 구역 표시다. 실내에서 다른 방에 들어서면 그 방 이름·용도를 1.6초 띄운다("◇ 보스 전투실").

- 같은 방에서는 다시 띄우지 않는다.
- 지역에 처음 들어온 방과 전투 중(`room.engaged`)에는 띄우지 않는다.

### 끄기

`storyworld.r204.cave {rooms:false}` 로 R219 둘레 넓히기로 돌아간다.
