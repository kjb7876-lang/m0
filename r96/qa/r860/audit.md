# R860 보스 전수 검수 (2026-11-12)

사용자 2026-11-12 02:09Z "타락천사기사등 모든 보스들 이미지 검수및 코드조사해서 디버깅 및 퀄리티떨어지는 보스 리부트재생성".

방법: `census.mjs` 가 64개 지역에 들어가 보스·중간보스(72명)를 하나씩 불러 세우고, 게임 시간 0.4초마다 14번 drawEnemy 의 실제 몸 그림 명령(경로·칸·화면 키·발 위치·상태)을 기록했다(헤드리스 소프트웨어 렌더, 1280×720). 결과 원본 `census-main.json`(수정 전 main 41db095), `census-after.json`(R860 뒤 5개 지역). GPU·실기기 모바일·자연 플레이는 미검증.
R700(7대죄 6명)·R760(불면귀) 검수와 겹치는 부분은 다시 고치지 않았다. 맘몬(b06·b06b)은 Codex 담당이라 재기만 했다.
