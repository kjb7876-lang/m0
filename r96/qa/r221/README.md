# R221 — 붉은 하이힐 서윤 광폭화 렉

사용자 요청(2026-11-02): "7대죄하이힐서윤보스 광폭화시 렉발생"

## 원인(헤드리스 실측, ep1b05 보스 b05-boss)
- R205 광폭화(체력 30% 이하)는 새로 깔리는 위험물의 범위를 모두 2배로 키운다.
- 서윤은 광폭화 뒤 어두운 장판(field)을 같은 자리 근처에 10~12개 연달아 깐다. 2배가 되면 장판끼리 크게 겹친다.
  - 장판 총면적: 16.7칸² → 506칸²
  - 반투명 장판이 같은 픽셀을 여러 번 덮어 그려져 프레임이 무거워졌다.

## 바뀐 것 (`boss-r205.js`)
- 새 장판이 같은 보스의 **이미 2배로 키운 장판** 안에 중심이 있으면 원래 크기로 둔다.
  - 바닥에서 위험한 범위는 이미 큰 장판이 덮고 있어서 거의 같다.
  - 겹쳐 그리는 면적만 준다.
- 그대로 2배인 것:
  - 첫 장판
  - 멀리 떨어진 장판
  - 다른 보스의 장판
  - 장판이 아닌 위험물(고리·선 등)
- 공격력 +6%, 크기 2배, 몸 공격 범위 2배는 그대로다.
- 끄기: `storyworld.r205.boss {enrageLite:false}` 로 되돌린다(R217 동작).

## 실측(헤드리스, 서윤 광폭화 같은 장면)

| 항목 | 전 | 후 |
|---|---|---|
| 장판 총면적 | 506칸² | 180칸² |
| 그리기 호출 | 361 | 297 |

## 검사
- `node r96/qa/r221/r221-cpu-check.cjs` — 13/13
  - 첫 장판 2배, 겹치는 장판 원래 크기
  - 겹침 면적 3배 이상 감소
  - 끄면 모두 2배
  - 원래 크기 장판의 중심이 큰 장판 안에 있음
  - 떨어진 장판·다른 보스 장판·고리 위험물은 2배
  - 체력 30% 위에서는 변화 없음
- `r205` 16/16, `r217` 22/22

## 미검증
- GPU·모바일 실기기에서의 프레임 시간. 헤드리스 소프트웨어 렌더 수치만 쟀다.
- 광폭화 난이도 체감. 큰 장판 하나가 덮는 범위는 같지만, 가장자리 장판 몇 개는 전보다 작다.

# R221 — WebGL2 없는 브라우저의 빈 화면

사용자 Drive 리뷰 캡처: `storyworld-live-failure-20261102.jpg`(2026-11-02 08:02)

## 증상
- 허브 화면이 비어 있었다.
- 아래 줄에는 "Three.js 실행 실패 · PC 테스트를 중단합니다." 한 줄만 보였다.

## 재현과 원인
- 크로미움을 `--disable-webgl --disable-webgl2` 로 띄우면 같은 화면이 나온다. 이유는 `WebGL2 context unavailable`.
- 게임은 Three.js(WebGL2) 화면이 필수다. 이 규칙은 두 곳에 있다.
  - phase1 어댑터: `requiredThree:true`
  - `hospital-pc-test.js`: 렌더러가 없으면 진행·조작을 막는다("Canvas 플레이로 대체하지 않습니다").
- 2D(Legacy) 대체 화면도 시험해 보았다. 헤드리스에서 6fps 정도로 지도는 그려졌다. 하지만 위 규칙을 뒤집는 일이라 넣지 않았다(사용자 판단 필요).

## 바뀐 것: `webgl-fallback-r221.js`
- 읽는 위치: `dist/phase1.js` 바로 뒤
- 바꾸는 것: phase1 알림만 감싼다.
- WebGL2 없음 때문에 실패하면 화면 가운데에 설명 상자를 띄운다.
  - 이유: 3D 화면을 시작하지 못함, WebGL2 없음
  - 해결 방법: 최신 브라우저 사용, 하드웨어 가속 켜기
  - 원격·자동화 브라우저에서는 열리지 않을 수 있다는 안내
- 아래 상태 줄도 같은 뜻의 문장으로 바꾼다.
- 다른 Three.js 오류와 WebGL2 가 있는 브라우저는 그대로다.
- 등록한 곳:
  - `runtime-text/index.html` 스크립트 태그
  - `verify-r96-public.py` 기대 목록
  - `sync-r99.py` 인자
- `r171` 순서 검사는 이 파일이 `phase1` 과 `story-maps-r171` 사이에 오는 것을 허용하도록 바꿨다.

## 검사
- `r221` 19/19. WebGL 알림 6개 검사가 추가됐다.
  - 순서
  - 공개 확인 목록
  - `requiredThree` 유지
  - 안내 문구
  - WebGL2 있으면 그대로
  - 일반 알림 무시
- 헤드리스 확인
  - WebGL2 끈 크로미움: 안내 상자가 보인다.
  - 일반 크로미움: `active=three`, 변화 없음.

## 미검증
- 사용자가 캡처한 실제 브라우저가 WebGL2 가 없는 환경이었는지는 캡처의 문구로만 추정했다.
