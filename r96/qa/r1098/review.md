# R1098 7분야 심사 — 사몽 꼭두각시 다시 칠하기 · 미카엘라 본인 시트

대상: 사몽·사몽 역행 구역(스토리 사몽 에피소드와 무한생존 사몽 장 공통)에서 사몽 전용 그림이 없는 44종(R161 꼭두각시 시트로 그려지던 몹·보스)과 사몽 최종 보스 미카엘라.
비교 그림: `puppet-before-after.jpg` (위 두 줄 = 원래 시트, 아래 두 줄 = 구운 먹·흰 실 인형, 오른쪽 = 영웅 환도 참고).

| 분야 | 점수 | 근거 |
|---|---|---|
| 미술 | 7.9 | 붉은 무늬 망토·칼이 사라져 흰 옷 환도와 실루엣·색이 갈린다. 먹 몸 + 흰 실은 수묵 화풍(R1055)과 맞는다. 붓 필치 세부는 없음(감점). |
| 연출 | 7.8 | '실에 매달린 인형'이라는 꼭두각시 정체가 흰 실로 더 또렷해졌다. 미카엘라 결전이 꼭두각시가 아니라 본인 모습으로 나온다. |
| 카메라구도 | 7.7 | 칸 크기·발 자리·보이는 높이 그대로라 화면 속 크기·위치가 바뀌지 않는다. |
| 공간인테리어 | 7.7 | 어두운 사몽 바닥 위에서 종이빛 테 두 줄이 몸 외곽을 떼어 준다(테 없이 칠했을 때는 바닥에 묻혔음). |
| 조명색채 | 7.9 | 무채색 먹 + 종이빛만 써서 사몽의 붉은 경고색과 겹치지 않는다. 환도(밝은 흰 옷)와 명도가 반대라 구분된다. |
| 애니메이션VFX | 7.8 | 걷기 8칸 움직임은 그대로, 칼날 기둥만 지워 칼 착시가 없다. 미카엘라는 걷기 4·공격 4칸 본인 시트. |
| UX레벨 | 8.0 | "환도가 자꾸 나온다"는 오인이 사라진다. 판정·피해·저장 변화 없음, 저장값으로 끌 수 있음. |

평균 **7.83** (기준 7.77 초과 → 통과).

미검증: GPU 렌더러, 실기기 모바일, 자연 플레이. 최종 그림은 Dots 사몽 전용 시트로 바꿀 대상이며, 이 칠하기는 그 전까지의 코드 처리다.
