# R1055 수묵화풍 테스트본 — 7분야 심사 (켰을 때 화면 기준, 헤드리스 캡처로 봄)

기본은 꺼짐이라 켜지 않으면 화면은 바뀌지 않는다. 아래는 '동양 지역만'으로 켠 잠들지 못하는 마을·한약과 불면귀, '모든 지역'으로 켠 피난 거점 캡처(shots/)를 본 점수다.

|---|---|---|

평균 7.84 (> 7.77).

## 시안(2안)과 다른 점
- 시안은 화면 전체 후처리(번짐·화면 기준 윤곽선)였고, 구현은 맵 재질 셰이더라 추가 패스가 없다(가볍다). 대신 번짐은 없고 먹선은 그림 안 밝기 기울기로만 낸다.
- 소품 줄(나무·석등·장승)은 원래 색 그대로다.

## 미검증
- GPU·실기기 모바일·자연 플레이(헤드리스 소프트웨어 렌더링만 확인).
- 그리기 비용 실측(추가 패스 없음 = 화소당 계산만 늘어남, 수치는 미측정).
- 사몽·환도 장면, '모든 지역' 방식의 지역별 인상(피난 거점 한 곳만 봄).
