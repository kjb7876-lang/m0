# R1055 수묵화풍 테스트본(화풍 다섯 가지) — 7분야 심사 (켰을 때 화면 기준, 헤드리스 캡처로 봄)

기본은 꺼짐이라 켜지 않으면 화면은 바뀌지 않는다. 아래는 '동양 지역만'으로 켠 잠들지 못하는 마을에서 화풍 다섯 가지를 차례로 본 캡처(r1055-styles.jpg)와 한약과 불면귀, '모든 지역'으로 켠 피난 거점 캡처를 본 점수다. 사용자 지시 "눈 조금 덜 아프고 퀄리티 높아 보이게"가 기준이다.

| 분야 | 점수 | 근거 |
|---|---|---|
| 미술 | 7.7 | 낱알·끊기는 농담 단계를 없애 면이 매끈하게 이어진다. 화풍마다 색 온도가 갈린다(진경 찬 먹, 담채 따뜻한 옅은 색, 송대 안개 낀 갈먹, 스미에 무채, 수채 원색 유지). 다만 밤 장면이라 종이 흰빛까지는 안 올라가 시안 그림보다 차이가 은은하다. |
| 연출 | 7.8 | 동양 몽세에 들어서면 약 0.25초에 걸쳐 바뀐다. 밤·공포 분위기 유지. |
| 카메라 구도 | 7.8 | 구도 변화 없음. 가장자리 테두리는 부드럽게 낮췄다. |

| 애니메이션·VFX | 7.6 | 정지 질감. 번짐·화면 기준 윤곽선 없음. 깜빡이는 요소를 더하지 않았다. |
| UX·레벨 | 8.2 | 영웅·몹·탄·체력바·UI 그대로. 첫 화면 단추 두 개(켜기 방식, 화풍)로 고른다. |

평균 7.84 (> 7.77).

## 시안과 다른 점
- 시안은 화면 전체 후처리 그림이고, 구현은 맵 재질 셰이더(추가 패스 없음)다. 번짐·붓 윤곽선이 없어 화풍 사이 차이가 시안보다 약하다.
- 소품 줄(나무·석등·장승)은 원래 색 그대로다.

## 측정 한계
- 잔입자 값은 필터를 끈 채로도 9.7~16.4 로 흔들린다(등불 깜빡임). 끔·켬을 번갈아 4번씩 재고 게임 시간을 멈춰도 화풍 하나의 평균은 실행마다 ±15% 쯤 움직인다. 세 번 실행에서 화풍별 +15% 항목이 한 번 걸렸다(담채 10.71 → 13.29, 같은 값). 다섯 화풍 평균 항목은 세 번 모두 통과.

## 미검증
- GPU·실기기 모바일·자연 플레이(헤드리스 소프트웨어 렌더링만 확인).
- 그리기 비용 실측(추가 패스 없음, 화소당 계산만 늘어남, 수치 미측정).
- 사몽·환도 장면, '모든 지역' 방식의 지역별 인상(피난 거점 한 곳만 봄).
