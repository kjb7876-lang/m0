# R1261 7분야 심사 — 초저(성능 1단계)에서 전투 읽기 테두리 끄기

바뀐 것: 성능 1단계(초저)를 고른 사람에게만 몹·영웅 몸의 R409 테두리(어두운 테·붉은 바깥 테)가 사라진다. 2단계 이상은 그대로, 1단계를 떠나면 원래대로.
몹 위 가림 옅게(영웅 큰 이펙트가 몹을 덮으면 옅게)는 그대로라 몹 위치는 여전히 읽힌다.

| 분야 | 점수 | 근거 |
|---|---|---|
| 미술 | 7.6 | 초저에서 테두리가 빠져 회색 몹이 배경에 조금 묻힐 수 있음. 초저는 "가볍게"가 목적인 단계라 허용 범위. |
| 연출 | 7.8 | 프레임 고르게(굽기·업로드 멈칫 제거) → 타격·각성 리듬이 덜 끊김. |
| 카메라구도 | 7.8 | 변화 없음, 프레임 튐 감소. |
| 공간인테리어 | 7.7 | 변화 없음. |
| 조명색채 | 7.7 | 몸 색 그대로, 테 색만 빠짐. |
| 애니메이션VFX | 8.0 | 몸 칸마다 테두리 굽기(거리장)가 없어져 새 칸이 늦게 뜨는 일이 없음. |
| UX레벨 | 8.3 | 사용자가 고른 "가장 가벼운 단계"가 실제로 더 가벼워짐. 단계를 올리면 자동 복귀, 사람이 정한 값 보존. |

평균 **7.84** (> 7.77 통과)

측정(헤드리스, 휴대폰 흉내 844×390 DPR2, dist01, 6게임초): R409 380ms → 0(테두리 굽기 0장), 프레임 평균 97.5 → 92.6ms·p95 216.6 → 200ms(헤드리스는 소프트웨어 그리기가 대부분이라 실기기 차이는 더 클 것으로 봄, 미검증).
남은 것: 엔진 phase1(약 610ms)·R302 영웅 2색(약 390ms, 사용자 색 규칙이라 유지)·첫 그림 업로드.
