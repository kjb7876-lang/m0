# R227 — 사몽 E 가 미카엘라(처방)보다 단서·문을 먼저

- 재현: 사몽 실플레이(헤드리스, 길잡이·미카엘라) `sz115-S01-1 찻잔 안의 집`에서 길잡이가 단서(24.5, 42.8) 바로 위에 선 채 23분 멈춤(단서 0/1). 멈춤 스크린샷은 모두 '미카엘라의 처방' 창.
- 원인: growth-r103 의 interact 감싸기가 1.9칸 안의 미카엘라(777 처치마다 영웅 옆 2.4~4.2칸에 나옴)를 사몽 표식보다 먼저 집었다. 단서 위에서 누른 E 가 처방 창만 다시 열었다(손으로 눌러도 같음).
- 고친 것: 미카엘라·상자보다 가까운 사몽 표식(단서·진술·문 등, '이전 구역' 표지는 뺌)이 있으면 E 는 그 표식으로 간다. 미카엘라만 가까우면 예전처럼 처방 창.
- 검사: `node r96/qa/r227/r227-cpu-check.cjs` (6/6). 헤드리스: 단서 위 + 1.5칸 옆 미카엘라에서 E → 단서 읽기창이 열림(이전: 처방 창).
- 미검증: GPU·실기기.
