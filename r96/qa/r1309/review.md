# R1309 3D 슬레이어 대검(Armory R2) — 7분야 심사

근거: `r1309-before-after.png`(왼쪽부터: 지금 게임 = 손에 무기 없음 / 대기 / 내려베기 시작 / 내려베기 뒤). 1920×1080 헤드리스 SwiftShader 캡처라 그래픽 검증 아님. 사용자가 체험판(무기 체험실)에서 직접 맞춘 값(크기 118%·날 방향 -18°·쥔 위치 +14·왼손 보정 켬)을 그대로 씀.

| 분야 | 점수 | 근거 |
|---|---|---|
| 미술 | 7.8 | 드라이브 Armory R2 대검 원본 그대로, 몸과 같은 한지 톤(R1304)·무기 금속감(R1305). 빈손이던 슬레이어가 대검 영웅으로 읽힘. 게임 배율에서 칼 금장 무늬는 거의 안 보임. |
| 연출 | 7.9 | 내려베기에서 칼이 머리 위로 올라갔다 내려와 동작이 무기와 함께 읽힘. 2D 소환이 나오는 적중 순간에는 3D 몸이 대기 자세(기존 R1305 규칙)라 칼을 든 채 서 있음. |
| 카메라구도 | 7.6 | 게임 기본 카메라에서 칼 길이가 몸 높이의 약 70%라 실루엣이 커짐. 모바일 작은 화면에서는 칼끝이 위쪽 요소와 겹칠 수 있음(미검증). |
| 공간인테리어 | 7.8 | 벽·지형과 같은 레이어 2·같은 깊이로 그려 벽 뒤에서 함께 가려짐. 몸이 반투명일 때 칼도 같은 투명도. |
| 조명색채 | 7.6 | 철색 칼날이 어두운 바닥에서 대비가 낮음. 먹 테두리는 칼에 넣지 않음(평면 칼날은 뒤집은 껍질 테두리가 끊어짐). |
| 애니메이션VFX | 7.9 | 공격 중 두 손이 모이는 구간만 왼팔 두 뼈 IK 로 칼자루를 잡고(최소 오차 0), 대기·걷기에서는 원래 모션. 팔 길이가 모자란 들어올림 구간은 가장 가까이까지만(IK 가 손을 더 멀게 만든 프레임 0/31). |
| UX레벨 | 8.0 | 기본 꺼진 3D 설정을 켰을 때만 0.57MB 를 한 번 읽음. 조작·판정·2D 소환·정령은 바뀌지 않음. |

평균 7.80 (> 7.77 통과).

미검증: GPU 실기기·모바일 렉·자연 플레이 체감, 2D 소환 없이 3D 가 직접 베는 시험(hwando-3d-r1302.js 의 ECHO_HEROES 에서 slayer 를 빼야 함, #1004 병합 뒤 별도 작업).
