## 1. 못 닿는 적 옮기기 (`reach-r225.js`)

### 실플레이에서 본 문제

- **증상**: 처음부터 길잡이로 진행하던 중 dist02(늪의 정원)가 1시간 넘게 끝나지 않았다. 살아 있는 적 1, 숨은 적 1이 남은 상태였다.
- **원인**: 남은 적 '늪의 염소머리 악마'(dist02-h1)가 입구에서 이어지지 않는 바닥 조각(52.6, 48.9)에 있었다.
  - 영웅 기준 칸 BFS(반지름 .27, 문은 열린 것으로 봄)로 확인했다. 같은 지역을 다시 열어도 같은 자리라 재현된다.
  - 적은 영웅이 가까이 오면 스스로 걸어 나온다. 하지만 길잡이는 닿지 못하는 곳에 가지 않아 끝까지 마주치지 않았다.

### 고친 것

- **언제**: 살아 있는 활성 적이 3 이하로 줄면 3초마다 확인한다. 막힘은 그때 드러나고, 평소 전투에는 비용이 없다.
- **무엇을**:
  - 입구에서 걸어서 닿는 칸을 새로 계산한다(문은 진행하며 열리므로 열린 것으로 본다).
  - 그 밖에 선 적을 가장 가까운 닿는 칸으로 옮긴다. 보스도 같다(잡을 수 없으면 진행이 막힌다).
- **옮기지 않는 적**: 숨은 적(나중에 나옴)·죽은 적.
- **유지하는 것**: 판정·체력·공격은 그대로이고, 자리만 옮긴다.
- **끄기**: `localStorage['storyworld.r225.reach']='{"on":false}'`

## 2. 약한 스킬 연출 강화 (`fx-boost-r225.js`)

### 비교 방법

8영웅의 Z(본편 W)·C(본편 R)·F(EGO)를 같은 자리(dist03, 표적 4)에서 헤드리스로 0.18초 뒤 찍어 비교했다.

| 영웅 | 강화한 칸 | 이유 |
|---|---|---|
| 네온 | Z·C·F | 셋 다 작음 |
| 미카엘라 | C·F | W 는 R209 에서 지움(공명방어와 중복), F 는 작은 문양 하나 |
| 거너 | Z·F | C(얼음 고리)는 이미 큼 |
| 라우렌 | Z·F | C 는 이미 큼 |
| 서하 | Z | C·F 는 이미 큼 |
| 헌터 | F | Z·C 폭발은 이미 큼 |
| 환도·슬레이어 | 없음 | 셋 다 이미 굵음 |

### 덧입히는 연출

R163 pixelfx 프레임 애니메이션을 영웅 고유색을 어둡게 눌러(다크 판타지 톤) 쓴다.

| 키 | 연출 |
|---|---|
| Z | 가까운 적(최대 3)마다 핏빛 어둠 폭발 + 겨눈 방향 땅 균열 |
| C | 발밑 안으로 무너짐 → 0.22초 뒤 바깥으로 터짐 |
| F | 발밑 어둠 폭발 + 둘레 땅 균열 셋 |

- 같은 키는 0.35초에 한 번만 겹친다.
- 판정·피해·쿨다운은 그대로다.
- 끄기: `localStorage['storyworld.r225.fx']='{"on":false}'`
