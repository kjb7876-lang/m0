# R1021 전투 화면 집중 — 7분야 심사 (임시, 헤드리스 장면 기준)

대상: 무한 생존 폰 375×812 · PC 1280×720 전후 장면(`/mnt/project-files/ui-r1021/compare-*.jpg`), 설정 창 스킬창(폰·PC), 폰 영웅 배치 창.
헤드리스 소프트웨어 렌더링 장면이다. 실기기·GPU·터치 감각은 미검증.

| 분야 | 점수 | 근거 |
|---|---|---|
| 미술 | 8.0 | 위쪽 황금실 두 단추와 두꺼운 청록 막대가 빠져 화면 위가 조용해졌다. 영웅 배치 단추는 초상화를 둥글게 잘라 기존 회피 단추와 같은 테두리를 쓴다. |
| 연출 | 8.0 | 전투 중에 보이는 글은 생존 한 줄, 구슬 이름표, 서사 자막 셋뿐이다. 자막은 끌 수 있다. |
| 카메라·구도 | 7.9 | 오른쪽 아래 동그라미가 둘로 줄어 화면 아래 3분의 1이 열렸다. 폰 자막 상자는 동그라미 왼쪽으로 좁혀 겹치지 않는다. |
| 공간·인테리어 | 7.8 | 구슬 바로 위에 '정화 구슬 n/m' 막대가 있어, 지킬 대상과 체력이 한 자리에서 읽힌다. 위쪽 같은 막대는 중복이라 숨겼다. |
| 조명·색채 | 7.9 | 이름표는 체력이 35% 넘으면 밝은 청록, 아래면 주홍이라 막대 색과 같다. 스킬창 배지는 자동이 청록, 직접이 금색이다. |
| 애니메이션·VFX | 7.8 | 기술(Q)과 EGO(F)는 자동으로 나가지만, 엔진 special()·ego() 를 그대로 부르므로 이펙트와 시트는 손으로 누를 때와 같다. 새 이펙트는 없다. |
| UX·레벨 | 8.2 | 설정을 열면 맨 위에 무엇이 자동이고 무엇이 손인지 보인다. 바로 아래 '전투 화면' 묶음에서 자막, 화면 단추, 자동 발동을 켜고 끈다. 생존의 '이전 시작점' 단추는 숨겼지만, 이야기 모드에서는 문과 제단을 여는 데 필요해 남겼다. |

평균 **7.94**로 기준 7.77을 넘는다.

남은 위험(확률):
- 폰 실기기에서 자동 EGO 가 원치 않는 때에 켜졌다고 느낌: 25%. 설정에서 끌 수 있다.
- 사파리 15.4 미만에서 설정 창 위에 생존 글줄이 남음: 5%. `:has` 를 지원하지 않기 때문이고, 보기만 겹칠 뿐 기능 문제는 없다.
