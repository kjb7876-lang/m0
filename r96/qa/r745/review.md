# R745 게임 시네마틱 영상 — 생성 도구 표시 제거·화질·소리 개선 7분야 심사(헤드리스)

사용자 2026-11-11 요청: "게임에 들어간 시네마틱 영상 중 워터마크 있는 것 워터마크 제거랑 화질·퀄리티 개선 및 음성 개선".

지운 표시는 모두 사용자가 만든 영상에 생성 도구(Gemini 별, Veo 글자, Dreamina·AI 배지)가 자동으로 붙인 것입니다. 다른 저작권자 표시는 없었습니다.

| 영상 | 전 | 후 |
|---|---|---|
| r309 오프닝 · r372 책·보스 문 | Gemini 별 그대로(지운 적 없음) | 역합성으로 지움, veryslow 재인코딩 |
| r369 중독의 도시 | 별 자리 delogo 흐림 자국 | 원본에서 역합성(흐림 자국 없음) |
| r368 배신 | 화면 비율 자르기로 표시 줄 화면 밖 | 원본에서 다시 인코딩(CAS 0.2) |
| r617 강림·해변·추락 | 960×540, CRF27, 모노, 표시 자리 delogo 흐림 | 1280×720, CRF22~23 veryslow, 스테레오, 역합성 |
| r667 타이틀 루프 | 흐림 자국 있는 정지 원천 | 표시 지운 오프닝에서 다시 만듦 |

소리는 모두 30 Hz 아래 자르기, 약한 잡음 줄이기, 2단계 EBU R128(−16 LUFS, 트루 피크 −1.5 dBTP), 48 kHz 스테레오 AAC 128k입니다.
