# R1189 7분야 심사: 잘리던 사몽 잔영 나머지 6종 새 시트(Dots CX-0164CR r1 ROUGH 손질, R1188 다음)

대상: 검은 고리의 대련생(S-03), 폐선로 태엽 군단병(S-06), 낚싯바늘 원고지 망령(RF), 카이로 회랑의 시계침 수문장 잔영(RB), 검은 제단의 전선 망자 잔영(RG), 승전식 제복 마네킹 잔영(RE).
- 손질은 R1188과 같다(scripts/r1189-uncut-shades.py): 알파 16 이하를 0으로 지우고, 발을 y236에 맞추고, 보이는 키는 예전 화면 크기에 맞췄다.
- 역행 4종의 칸 나눔: 원래는 이동 0~5, 공격 6~10이었다. 새 시트는 요청서대로 이동 0~4, 공격 5~10으로 그려져서 칸 나눔도 새 시트를 따르게 했다. 그러지 않으면 걷다가 공격 첫 자세가 한 칸 비친다.
- 테스트 수정 1곳(사용자 지시 동작 변경, 알림 대상): r96/qa/r200/r200-cpu-check.cjs 의 '대기 칸·공격 칸' 검사.
  - 원래는 칸 번호를 원래 index 의 칸 너비(108)로 나눠 셌다. S-03 대련생 칸이 256으로 바뀌어 번호가 18.9로 잘못 나왔다.
  - 그래서 실제 그린 칸 너비로 나누도록 고쳤다. 검사 뜻(대기 0~1칸, 공격 5~10칸)은 그대로다.

검증
- 실패 먼저 27/61, 지금 ALL PASS 61.
- r1188 30/30, r200 17/17, r203 14, r204 25, r444 73, r176 22 통과.
- 새 시트 여백은 칸마다 14px 이상이다(전선 망자 채찍 끝 14px, 아래 발 쪽은 모두 20px). 발 줄은 236 하나다.
- 헤드리스 S-03에서 대련생, RG에서 전선 망자가 r1189 시트로 그려졌다. 나머지 4종은 CPU 검사로만 확인했다.
