# 모바일 시작 영웅 선택창 검토

왼쪽은 기준 버전, 오른쪽은 수정 버전이다. 같은 슬롯과 영웅으로 캡처했다.

- 아이폰 13 미니 가로 크기 812 × 375 [전후 화면](landscape.webp)
- 아이폰 13 미니 세로 크기 375 × 812 [전후 화면](portrait.webp)
- PC 1280 × 720 [전후 화면](desktop.webp)

가로 화면에서 선택창이 열릴 때 기준 버전은 자체적으로 108px 스크롤해 슬롯 제목이 잘렸다. 수정 버전은 0px에서 열리고 제목과 두 버튼이 화면에 들어온다. 시작 버튼 높이는 40px에서 44px로 늘어났다. 카드 8개가 유지되며 세로 화면에서는 목록을 좌우로 스크롤할 수 있다. 가로 화면에서 선택한 영웅의 추가 설명은 아래로 스크롤해 확인할 수 있다.

## 7개 분야 임시 심사

Chromium 헤드리스 캡처와 터치 에뮬레이션에 근거한 자체 평가다.

| 분야 | 점수 / 10 | 근거 |
| --- | ---: | --- |
| 미술 | 8.5 | 기존 초상화와 양피지 패널 색을 사용하고 영웅 선택 강조가 읽힌다. |
| 연출 | 8.3 | 슬롯과 영웅을 고른 뒤 새 게임으로 넘어가는 순서가 화면 배치에 드러난다. |
| 카메라·구도 | 8.2 | 가로 화면에 슬롯 제목부터 시작 버튼까지 들어온다. 영웅 설명 아래쪽은 스크롤이 필요하다. |
| 공간·정렬 | 8.5 | 영웅 목록 바로 아래에 결정을 확정하거나 되돌리는 버튼이 붙어 있다. |
| 조명·색채 | 8.4 | 밝은 바탕에서 본문과 버튼, 어두운 영웅 설명 패널의 텍스트를 구분할 수 있다. |
| 애니메이션·VFX | 8.4 | 선택창이 자동 스크롤로 튀지 않고 터치와 화면 회전 후에도 선택과 미리보기가 일치한다. |
| UX·UI | 9.0 | 실제 시작·취소 경로를 터치해 확인했다. 시작과 취소 버튼의 최소 높이는 44px이다. |

평균 8.47 / 10. iOS Safari 실기기 확인은 남아 있다.
