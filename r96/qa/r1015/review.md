# R1015 UI 깔끔 정리: 7분야 심사 (헤드리스 임시)

근거는 같은 화면을 전후로 찍은 헤드리스 스크린샷이다(PC 1280×720, 폰 가로 844×390). 실기기, GPU, 자연 플레이로는 보지 않았다.

| 분야 | 점수 | 근거 / 고칠 점 |
|---|---|---|
| 미술감독 | 8.0 | 짙은 바탕과 금빛 실선 팔레트는 그대로 두었다. 두 겹 금테와 그라데이션 막대를 얇은 한 줄과 둥근 모서리로 바꿔 장식을 줄였다. 고칠 점: 양피지 질감 쪽지(R177·R255)와 새 둥근 창 사이에 결이 조금 다르다. |
| 연출감독 | 7.9 | 서사 글과 장면은 바꾸지 않았다. 첫 화면은 '시작 → 모드 → 도구' 차례로 읽힌다. |
| 카메라·구도 | 8.1 | 첫 화면 창 폭을 1040에서 640으로 줄여 뒤 배경 영상이 드러난다. 폰 가로에서는 스크롤 없이 한 화면에 다 보인다(746/376 → 290/290). |
| 공간·환경 | 7.8 | 메뉴는 빠른 줄 1개와 접는 묶음 6개로 동선이 짧아졌다. 고칠 점: 지도 창의 원래 차례(출구 칸이 위에 있음)는 이번 범위가 아니어서 그대로다. |
| 조명·색채 | 8.0 | 머리띠의 밝은 금색 막대를 걷어 화면 위쪽 명도 튐을 없앴다(호러 70~85% 어둠 원칙). 강조색은 금색 하나만 쓴다(주 단추·체크·슬라이더). |
| 애니메이션·VFX | 7.8 | 펼침 화살표 회전과 단추 눌림 1px만 남겼다. 헤드리스에서 투명도 전환이 밀리는 문제가 있어 세부 수치는 전환 없이 바로 켜고 끄게 했다. 흐림(blur) 필터는 쓰지 않았다. |
| UX·UI·레벨 | 8.4 | 보이는 단추 수: 첫 화면 11 → 8+접기 1, 메뉴 29 → 14, PC 설정 첫 화면 190여 개 → 60개 이하. 폰 곡 쪽지 2줄 → 1줄(26px). 모든 원래 단추와 id는 그대로다. |

평균 8.0으로 7.77을 넘어 통과했다. 헤드리스 결과이므로 임시 판정이다.
