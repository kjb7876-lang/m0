# R1095 이펙트 수묵 색 — 7분야 심사 (작성자 자체 심사, 헤드리스 캡처 기준 · 임시)

대상: `fx-ink-r1095.js`. 새 그림 없이 이미 있는 이펙트의 색만 옮긴다. 맵 수묵화풍(R1055)이 켜져 있을 때만 작동한다.
적용 대상(사용자 2026-11-16 정정): 기존 영웅은 바꾸지 않는다.
- 히든 영웅 EGO 형상의 이펙트 → 언주색(연지·주홍) + 먹 + 백 세 가지 색.
- 페르소나의 기술 그림·소유 이펙트 → 언주색 단독(붉은 농담만).
- 환도 영웅(02:55Z 추가 지시)의 이펙트 → 먹 + 백. 붉은색은 EGO·페르소나의 고유색이라 쓰지 않았다(색 지정이 없어 이렇게 해석, 다르면 한 줄로 바꿈). 다른 영웅은 그대로.
붉은 값은 페르소나 스레드 R1096 상수와 같다(70,14,10 / 132,30,22 / 204,52,40 / 255,176,140).

증거: `hwando-sumi-before-after.jpg`(환도, 끔 → 켬), `ego-before-after.jpg`(EGO 형상, 같은 순간을 멈춰 끔 → 켬), `neon-plain-unchanged.jpg`(보통 영웅은 그대로), `r1095-cpu-check.cjs` 158/158, `r1095-browser.mjs` 19/19(헤드리스).
측정: 환도는 이펙트 106개 가운데 103개가 먹·백으로(색상 돌리기 0개) → EGO 형상을 켜면 언주색 팔레트로 바뀜. 보통 영웅 네온은 이펙트 61개 가운데 0개 변경. 예고 표시·탄·몸·피해 숫자·그림자·적 표식은 0개 변경.

남은 약점·미검증
- 애니메이션 VFX 7.7: 색 바꾸기로는 붓 번짐이 나오지 않는다. 덮어 그리는 먹 획 시안은 어두운 바닥에서 안 보여 버렸다.
- 페르소나 보스의 실제 기술 장면은 헤드리스에서 띄우지 못했다(보스를 불러도 기술 그림이 뜨기 전에 끝남). 페르소나 쪽은 CPU 검사(경로·소유 id 규칙)로만 확인. 페르소나 '거울 천체'(R1096)는 자체 필터로 그려 이 모듈을 타지 않는다.
- 회색·흰색 그림은 색 행렬로는 붉게 만들 수 없어, 페르소나 그림 가운데 무채색 부분은 옅게만 물든다(선·채움은 완전히 언주색).
- 미검증: GPU·실기기 모바일, 자연 플레이, R1094 로 EGO 에 추가되는 새 기술 장면.
