# R775 몹이 죽을 때 불붙는 연출 없애기

사용자 지시(2026-11-12 07:11Z): "사망모션없는 경우 지금처럼 토막나 죽는걸로, 그리고 죽을때 불붙는 연출 없애"

## 바꾼 것 (mob-death-r462.js, 설정 `flame`, 기본 false)
- R462 '불' 갈래 몹(영혼·악마·기계 등)
  - 없앤 것: 엔진 불꽃과 불티, 붉게 달아오름(brightness 2.6), 화염벽 시트(boss-fire-wall).
  - 남긴 것: 몸이 금 간 조각으로 어두워지며 부서져 내려앉는 연출, 숯빛 사체.
- 엔진 죽음(보스, 중간보스, 기억 못 한 몹, R462 끔): 불꽃 그림(VFX.burnFlame)과 불티를 빼고, 몸이 사라지는 장면만 남깁니다.
- '피' 갈래(토막·피 터짐)는 그대로입니다.
- `flame:true` 로 바꾸면 예전 연출이 돌아옵니다.

## 검사
- 실패하는 테스트를 먼저 썼습니다. R462 CPU 검사는 32개 통과, R532 는 51개 통과입니다. 관련 CPU 검사 19개도 통과했습니다.
- 헤드리스 dist03 에서 몹 4마리와 중간보스를 동시에 죽여 비교했습니다(공개본과 로컬 빌드, `death-scene.mjs`). 중간보스 발밑의 주황 불꽃과 불티가 사라졌고, 화염벽 시트 그리기 횟수가 28에서 15로 줄었습니다. 전후 사진은 `r775-death-noflame-before-after.jpg` 입니다.
- 브라우저에서 drawBurnDeath3 를 직접 불러 보았습니다(`flame-calls.mjs`). 불꽃 texture 호출은 끔 0회, 켬 1회였고, 불티는 지워졌습니다.
- GPU, 실기기, 자연 플레이는 미검증입니다.
