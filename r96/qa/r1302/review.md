# R1302 3D 환도 시험판 — 7분야 심사(임시: 헤드리스 SwiftShader 캡처 기준)

대상: 설정 '3D 환도(시험)'을 켰을 때 환도의 몸 그림(대기·걷기·대각 베기). 기본은 꺼짐. 같은 카메라 자리의 2D/3D 캡처:
- PC 1280×720: `2d-vs-3d.jpg`(윗줄 2D 대기 · 3D 대기 · 3D 공격 / 아랫줄 2D 걷기 · 3D 걷기)
- 모바일 가로 844×390: `2d-vs-3d-mobile.jpg`(같은 배치)

1차 캡처(필터 없음)는 모델이 황토색으로 2D 한지빛 몸·밝은 테두리와 동떨어져 미술·조명 분야가 7점 아래로 예상됨 → 3D 캔버스(DOM)에 채도↓·밝기↑·한지색 1px 테두리를 넣고 다시 찍어 심사함.

| 분야 | 점수 | 근거 | 고칠 점 |
|---|---|---|---|
| 1. 미술감독 | 7.6 | 한지빛 흰 두건·흰 옷·검은 띠가 2D 환도와 같은 계열, 테두리로 수묵 화면에서 떨어져 보임 | 작은 화면에서 텍스처가 뭉개져 옷 주름이 흐림. 수묵 굽기(외곽 먹선)는 없음 |
| 2. 연출감독 | 8.0 | 두건 쓴 환도 검객이라는 인물 정체성 유지, 서사·장면은 손대지 않음 | — |
| 3. 카메라·구도 | 7.5 | 발 기준 오차 5px·키 60px(2D 54px), PC·모바일 모두 영웅 한가운데 | 벽 뒤로 들어갈 때 가림 순서를 안 맞춤(앞에 그려짐) |
| 4. 공간·환경 | 7.8 | 맵·조형물 변경 없음, 그림자·발밑 고리는 2D 것 그대로라 바닥에 붙어 보임 | 벽 가림(3번과 같음) |
| 5. 조명·색채 | 7.9 | 사용자 시험 페이지 빛(따뜻한 해 + 옅은 반구광 + 차가운 테두리광) + 채도 0.62로 한지 팔레트에 맞춤, 어두운 바닥에서 읽힘 | 어두운 지역(사몽)에서 따로 확인 필요 |
| 6. 애니메이션·VFX | 7.6 | 실제 클립 Idle·Walk·Attack_DiagonalSlash, 발이 미끄러지지 않음, 공격 0.45초에 대각 베기 전체가 보임 | 자동 무게라 로브 자락이 다리 따라 갈라져 바지처럼 보일 때 있음. 걷기 회전은 헤드리스에선 느리게 보임(게임 시간 기준) |
| 7. UX·UI·레벨 | 8.4 | 기본 꺼짐·설정 한 줄, HUD 가림 없음(영웅 둘레 상자만), 켤 때만 3.9MB 받음, 판정·키 그대로 | — |

**평균 7.83 (통과 기준 7.77 초과).** 헤드리스 결과라 '임시'. GPU 실기기·자연 플레이·어두운 지역은 미검증.
