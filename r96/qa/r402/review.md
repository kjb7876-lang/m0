# R402 사몽 학생·스토리텔러·순찰자/상대 초인 보행 — 7분야 심사 (헤드리스 임시 화면)

자산: 드라이브 SWDL-45(학생 공격4·책갑옷 스토리텔러 이동4+공격4), SWDL-46(순찰자 v4·상대 초인 v2 오른쪽 걷기4) 재조립, 원본 SHA-256 일치. 학생 이동4 는 기존 보정본(student-move4-native-padded-800).
개선: 이동·공격 그림의 몸 높이와 발 위치를 맞춰 한 시트로(학생 이동은 크게 그려져 있어 0.84배, 상대 초인 v2 는 기존 v1 이동 높이에 맞춤), 옅은 알파(<10) 잡음 지움.
배치:
- S-02 '얼굴 없는 학생'(짙은 형상 포함): R105 정적 한 장 → 이동4·공격4. R200 그림자로 바뀐 개체는 그대로.
- RF 보스 '스토리텔러': R105 정적 책갑옷 → 이동4·공격4.
- 열쇠 순찰자(S-02·RA 보스): 정적 이동 1칸 → v4 걷기 4칸(공격 4칸 그대로).
- S-06 상대 초인: 이동 v1 → 보행 개선 v2.
