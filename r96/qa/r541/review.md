# R541 빈 자리 효과음 — 검사 기록

사용자 2026-11-10: "직접 녹음 말고 너가 여러 효과음 참조해서 적절하게 생성" → "소리 거슬리지 않게 개선해서 적용".

## 바뀐 것
- 기억 조각·쪽지 줍기(`sound('pickup')`, 호출 3곳)는 `soundProfiles.pickup` 이 없어 무음이었다 → 부드러운 유리 종 2변주.
- 몹 소멸(보스 제외, 0.6초 간격 제한) → 낮게 꺼지는 숨 2변주.
- R74 문을 열 때(닫힘→열림, 1.5초 간격 제한) → 낮게 끌리는 소리 1개.
- 기존 소리(공격·피격·보스·강화 등)는 그대로. 재생은 게임 `sound()`·SFX 조절기(저역통과 3.8kHz·음성 4개 상한)를 그대로 탄다.

## 음원
`scripts/build-sfx-r541.py`(numpy 합성, 녹음·외부 음원 없음) → `r96/runtime-text/assets/r541/sfx/` 5개 합계 약 44KB.
참조: 지금 게임 효과음 51개의 길이·피크·중심 주파수(발걸음 -22~-31dB rms, 타격 -21~-25dB rms)에 맞춰 더 조용하게.
거슬림 기준: 피크 -8.5dB 이하, 5kHz 위 에너지 1% 이하, 어택 10ms 이상, 끝 -40dB 아래.

## 검사
- `node r96/qa/r541/r541-cpu-check.cjs` — 오버레이 작성 전 29개 실패 확인 → 93/93.
- `SW_URL=… node r96/qa/r541/r541-browser.mjs` — 헤드리스 7/7(줍기 2회 번갈아, 5마리 동시 처치 1회, 실제 문 열기 1회, 재생 음량 0.105~0.126), `SW_OFF=1` 3/3.
- 기존: r176 22, r222 22, r225 13, r531 15, r511 47, r103 42, r104 10, r105 26 통과.

## 미검증
- 귀로 듣는 확인(헤드리스는 재생 경로·음량 수치만 봄). 실기기 스피커·휴대폰에서의 체감.
- 시각 요소 변경이 없어 7분야 시각 심사 대상이 아님.
