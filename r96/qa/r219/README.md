# R219 — 실내 맵 넓히기 · 이음매 벽 · 외벽 · 지붕 덮개 어둡게

사용자 요청(2026-11-02, murder03 스크린샷과 함께):
> 이동가능한공간이 적고 벽지붕?같은공간 너무 이질감이 있고 너무 많아서 그리고 맵 외곽쪽을 벽으로 채워서 여기가 진짜 내부라는 점이 들도록 모든실내맵 전반적인개선해줘

## 원인

실내(디테일 전용) 26개 지역은 모두 R171 병동 틀(68×70)을 쓴다. 바닥이 1,738~2,549칸(36~54%)뿐이고, 나머지 칸은 벽 높이(2.7)에 깔린 지붕 덮개(평판)로 그려졌다. 그래서 내려다보면 방보다 지붕이 더 넓었다.

## 바뀐 것

| 파일 | 내용 |
|---|---|
| `cave-r204.js` `inflate()` | 실내 지역 바닥을 둘레로 최대 3칸 넓힌다(8방향, 원래 바닥에서 4방향으로 이어진 칸만). 아래 세 곳은 넓히지 않는다. |
| | ① **이음매 벽**: 원래 바닥 위 4방향 길 거리가 1.5×직선거리+4보다 먼 두 곳이 만나는 칸은 벽으로 남긴다. 그래서 방·구역 구분이 유지되고 지도가 한 덩어리 홀이 되지 않는다. 대각선으로만 닿는 경우도 끊는다. |
| | ② **문**: R74 문 둘레(문 폭 절반+2.5칸, 최소 3.5칸)와 입구 둘레는 그대로 둔다. 길 거리를 잴 때는 문 선을 넘지 못하게 해서, 닫힌 문을 새 바닥으로 돌아가는 길이 생기지 않는다. |
| | ③ **외벽**: 맵 가장자리 1칸은 늘 벽으로 남아 실내를 두른다. |
| | 벽은 새 바닥 경계 변을 이어 다시 만든다. 원래 벽의 높이·그림 등 속성은 복사한다. 원래 양쪽이 바닥이던 칸막이는 남긴다. 바닥 사각형(floorRects)도 새로 만든다. |
| `story-maps-r171.js` `layoutFor()` | R204/R219 손질을 여기서 입힌다. 전에는 엔진 바닥·벽 덩어리(loadDescriptor)가 손질 전 원본을 그리고 판정만 손질본을 써서 둘이 어긋났다. 이제 같은 객체다. 손질은 한 번만 들어간다(이미 손질된 레이아웃은 그대로). |
| `cave-r204.js` `dimRoofs()` | 실내에 남은 지붕 덮개 재질을 0.45배로 어둡게 해 벽 덩어리로 읽히게 한다. 엔진이 덮개를 다시 만들 수 있어서 30프레임마다 다시 확인한다. |
| 끄기 | `storyworld.r204.cave {inflate:false}`(다음 지역부터 적용). 어둡게 하기는 R218 `{skeleton:false}` 와 함께 꺼진다. |

## 실측(헤드리스, 26개 R171 실내 지역)

| 항목 | 결과 |
|---|---|
| 바닥 | 1,738~2,549칸 → 3,198~3,646칸(맵의 67~77%) |
| 문 닫힘 우회 | 26곳 모두 0. 문을 닫았을 때 원래 못 가던 원래 칸이 넓힌 뒤에 닿게 된 경우가 없다. |
| 원래 바닥 도달 | 26곳 모두, 문을 다 열면 모든 원래 칸에 닿는다. |
| 엔진 판정 | 새 칸 1,338~1,388개 중 막힌 칸 0개. 문이 닫힌 상태에서 그중 약 85%에 닿는다(나머지는 문 너머). |
| 길잡이 | murder03·ep1a09·u203 자동 진행에서 움직임을 확인했다. |
