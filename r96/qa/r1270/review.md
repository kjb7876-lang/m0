# R1270 7분야 심사 — 평타 자동 실검무 표시 제거 · 적중 그림 자리

바뀐 것(그림만, 피해·판정 그대로)
- 원거리 영웅(서하·미카엘라·헌터·기억사수) 평타 적중 때 실검무를 배웠으면 자동으로 붙던 은색실 베기(R174 silverMark) 제거. T 실검무·황금실 돌기·포인트·습득 조건 그대로.
- R1041 의 R106 `iai-cut` → 환도 발도 시트(H6) 교체를 환도 기술 그림에만. 실검무 베기(`r111:thread-slash:*`)는 원래 은빛 iai-cut.
- R111 실검무 베기 중심 = 맞은 몹 그림 몸통(R115 centreOf), 몹이 움직이면 따라감. 대상이 없으면 예전 그리기.
- R912 탄 적중 시트(미카엘라 하트·서하·헌터·기억사수) 자리 = 엔진 충돌점 `impactPoint152`.

헤드리스(844×390, 소프트웨어 렌더) 측정: 서하 실검무 1단계 평타 적중 5번 동안 환도 시트 그림 126장 → 0장, 피해 값 모음 같음(352.8·1270.08 치명). 미카엘라 하트와 충돌점 사이 거리 최대 0.254칸 → 0. T 실검무 베기 중심과 몸통 사이 거리 0px(0.05~0.40초, 몹을 움직인 상태).
