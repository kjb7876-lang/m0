# R228 — 실내 방마다 다른 바닥 색조

- 요청: 실내맵을 방 형식으로(사용자 영상 + 디아블로 + 이터널리턴). R224 가 방·가구·방 이름을 넣었고, 이번에는 방이 바뀌면 바닥 결도 바뀌게 했다.
- 바꾼 것(cave-r204.js `roomFloorMesh`): R224 방(r224Rooms) 사각형마다 지역 계열(진료·집·도시·대장간·기계·교단) 팔레트에서 고정 시드(지역+방 id)로 한 색을 골라
  곱하기 혼합으로 깐다(바닥 그림의 무늬는 그대로, 색조만). 가장자리 0.35칸 띠는 더 어둡게 해 방 경계가 깔개·타일 구역처럼 보인다. 2×2 미만 방은 건너뛴다.
  그림만 바꾼다(충돌·길찾기·문 판정 그대로). 끄기: `localStorage['storyworld.r204.cave']` 에 `"roomFloors":false`.
- 검사: `node r96/qa/r228/r228-cpu-check.cjs` (8/8). r224 검사의 기본값 정규식은 새 설정 항목(`rooms:true,roomFloors:true`)을 허용하도록 `rooms:true[,}]` 로 고침(기본값 자체는 그대로).
- 헤드리스 비교(ep1b02 집·ep1a09 진료·cult02 교단, 켬/끔): 방마다 색조와 테두리가 달라지고 바닥 무늬는 남음. 첫 시도(일반 반투명 덮기)는 바닥이 뿌옇게 씻겨 버리고 곱하기로 바꿈.
- 미검증: GPU·실기기 화면 색감.
