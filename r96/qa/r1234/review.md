# R1234 7분야 심사(헤드리스 근거, 임시)

대상: 몹 발밑 먹 안개 크기(R1195), 보스·중간보스 최소 크기 맞춤(R205), 죽음 몸 크기(R462 + R1065 Dots 죽음 시트), 막혀 밀리는 몹 그리기 위치(R1234 새 오버레이).
그림·시트는 새로 만들지 않았다(기존 프레임 시트 그대로). 바뀐 것은 크기·위치 계산뿐이다.

| 분야 | 점수 | 근거 / 고칠 점 |
|---|---|---|
| 미술감독 | 8.0 | 그림체·팔레트 변화 없음. 안개가 화면 절반을 덮던 큰 먹 덩어리(최대 616px)가 사라져 몹 실루엣이 읽힘. |
| 연출감독 | 7.8 | 서사·장면 변경 없음. 죽는 순간 커지던 '튐'이 없어져 15세 재 소멸 연출이 몸 크기 그대로 이어짐. |
| 카메라·구도 | 8.0 | 카메라 그대로. 공격 준비 때 안개가 화면을 가리던 문제 제거. |
| 공간·환경 | 7.8 | 맵 배치 변경 없음. 무리 속 몹 위치 떨림이 줄어 동선이 덜 산만함. |
| 조명·색채 | 7.8 | 색 변화 없음. 먹 안개 명도 덩어리가 과하게 커지던 것만 사라짐. |
| 애니메이션·VFX | 8.3 | 안개 크기 44~58px 안에서 유지(전: 44→616→44 1초 출렁임). 죽음 몸 = 살아 있을 때 몸 높이(주사실 중간보스 1.63·1.92배 → 1.00). 막혀 밀릴 때 화면 튐 p90 3.83→2.60px. |
| UX·레벨 | 8.0 | 공격 예고·판정 그대로. 맞는 동안 밀림은 그대로 둬 타격감 유지. |

평균 7.96 (> 7.77 통과). 헤드리스 소프트웨어 렌더링 결과라 GPU·실기기 모바일·자연 플레이는 미검증.
