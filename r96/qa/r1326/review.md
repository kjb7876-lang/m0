# R1326 7분야 심사 (2026-11-26)

변경: 7대죄 지역(ep1b02~08)에서 이미 있는 3D 몹·보스를 설정과 무관하게 3D로, 불면귀 마을(last302·303)은 늘 2D.
근거: 사용자 지시 "일단 7대죄는 다 3d로해줘 불면귀쪽은 다 2d로 하고", "작은잡몹들이 난 3d가 낫던데 … 동작별일관성은 있어서".
자료: r1326-ep1b07-before-after.png, 6종 크기·선명도 비교(헤드리스 SwiftShader, 그래픽 검증 아님).

| 분야 | 점수 | 근거 |
|---|---|---|
| 미술 | 7.5 | 작은 잡몹(사냥개·쓰레기·오물 봉투·유리 망령·식재료)은 2D와 실루엣이 가깝다. 같은 지역 안에 3D 없는 20종이 2D로 남아 섞임(Dots SW-3D-SIN7 요청으로 해소 예정). |
| 연출 | 7.8 | 지역 단위로 2D/3D가 갈려 불면귀 마을(수묵 2D 정서)과 7대죄(입체 괴물)의 대비가 분명해짐. |
| 카메라구도 | 8.0 | 카메라·시점 변경 없음. 3D 크기는 2D 보이는 키에 맞춤(R1316 방식), 6종 실측 키 차이 대부분 ±10% 이내. 개와 늑대의 시간은 방향에 따라 커 보이는 때가 있어 후속 관찰. |
| 공간인테리어 | 8.0 | 맵·조형물 변경 없음. 벽 가림 디더는 그대로 동작. |
| 조명색채 | 7.6 | R1323으로 맵 수묵 셰이더가 3D 몸에 걸리던 흐림은 빠짐. 3D 몸 대비가 2D 먹선보다 약해 여전히 약간 흐릿(사용자 지적, 후속: 먹 윤곽 선택지 R1325b). |
| 애니메이션VFX | 8.2 | 3D는 걷기·공격·피격·죽음 동작이 방향별로 일관(사용자가 꼽은 장점). 공격 방향은 R1323 수정 반영. |
| UX레벨 | 7.9 | 설정을 몰라도 7대죄 지역에서 3D가 보임. 규칙 끄기 storyworld.r1326.zone3d / ?zone3d26=0. 성능: 7대죄 지역 3D 동시 표시 부하는 실기기 미검증. |
