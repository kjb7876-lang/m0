# R1240 영웅 변경창 맞춤 — 7분야 심사(작성자 자체 심사, 헤드리스 스크린샷 기준)

사용자 보고(2026-11-19 12:12Z): "영웅변경할떄 한영웅이미지만 크게나오면서 영웅변경이 안되는문제 전수조사 개선".

## 재현(공개판 main 38ff68a, 헤드리스)
- 큰 무대(R263, 고른 영웅 1명 초상)가 영웅 줄 위에 있어, 777 해금 뒤 11칸(EGO 2D·3D + 8명 + 페르소나, 두 줄)이 창 아래로 밀림.
  1366×640 은 영웅 칸 전부, 1280×720 은 칸 아래 반과 페르소나 칸 전부, 1920×900 은 페르소나 칸이 창 밖. 1366×640 은 휠로도 창이 내려가지 않음(헤드리스 관찰). R1106 은 높이 620px 이하만 처리.
- 영웅 칸을 누르면 엔진이 창을 다시 그리면서 뒤로·앞으로 줄(R176)이 빠져 창 내용이 21px 위로 튐 → 칸을 누른 뒤 '이 영웅으로 변경'을 원래 자리에서 누르면 빈 곳을 누름.
- 페르소나·EGO 칸을 누른 직후(히든 칸을 다시 끼우는 0.25초 주기 전) 확정하면 라우렌·환도로만 바뀜.

## 고침
- `hero-fit-r1240.js`: 영웅 창이 열려 있을 때 칸 전부와 확정 단추가 창 안에 드는지 실제 자리로 잼 → 넘치면 무대 초상 높이를 넘친 만큼 줄임(최저 110px) → 그래도 넘치면 한 줄 가로 띠(R1106 과 같은 모양) → 그래도 넘치면 창을 줄·확정 단추가 남는 만큼만 스크롤. 맞춤 중에는 창 높이를 최대 높이로 고정(무대 높이가 바뀌어도 단추가 오르내리지 않게), 무대 글(EGO 기록 줄)은 초상 높이 안에서 스크롤하고 더 있을 때만 아래 18px 흐림.
- `nav-r176.js`: 뒤로·앞으로 줄이 있던 창을 제자리에서 다시 그리면 줄을 다시 붙임.
- `ego-sovereign-r1046.js`·`persona-hero-r1113.js`: 확정 때 히든 칸이 아직 없으면 '히든 의도 + 기본 영웅(환도·라우렌) 선택'으로 판정.
