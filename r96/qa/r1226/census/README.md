# R1226 몹 모션 전수조사 도구 (헤드리스, CI 아님)

- `census.mjs <out.json> <지역,…|-> [이름 정규식]` — 지역마다 nativeId 한 마리씩 떼어 대기·영웅 오른쪽 공격·왼쪽 공격·피격·사망 동안 실제 그린 몸 명령(경로·칸·네 점·뒤집힘)과 R444 쪽을 남긴다. `SW_URL`(기본 http://127.0.0.1:4410/m0/) 정적 서버 필요.
- `flips.py <json…>` — 시트·칸마다 R444 쪽에 따른 뒤집힘 극성(+ 원본 왼쪽 / - 원본 오른쪽 / N·F 안 따름 / ~ 흔들림). 한 몹 안에서 극성이 갈리면 POL.
- `ana.py <json…>` — 칸별 화면 몸 키·발 위치(numpy 필요) → ana.json.
- `raw.py <out.jpg> <assets 경로…>` — 원본 시트를 뒤집지 않고 나란히(그림이 어느 쪽을 보는지 사람이 확인).
- `sheet.py`, `shot.mjs`, `mont.py` — 실제 그린 칸 접촉 시트·화면 찍기.
극성이 갈려도 정면 그림·위아래 시트는 문제 아님 — 반드시 raw.py 로 그림 쪽을 눈으로 확인한 뒤 FACE 표에 넣는다(가고일 M007 공격을 처음에 잘못 읽은 적 있음).
