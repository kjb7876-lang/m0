# 타락천사 기사 성채 지붕

PC와 가로형 터치 화면에서 같은 자리에서 비교했다. PC는 변경 전후, 모바일은 바다 이미지 로딩 실패로 기존 지형을 그린 상태와 정상 로딩 상태다. 각 이미지의 위가 기존 지형이고 아래가 새 성채다.

[PC](desktop-rampart.webp) · [모바일](mobile-rampart.webp) · [브라우저 검증 기록](render-evidence.json)

| 항목 | 자체 평가 (10점) | 확인한 표현 |
| --- | ---: | --- |
| 재질 | 8.3 | 기존 검은 성채 판석에 석조 벽을 연결했다. |
| 명암 | 8.0 | 번개와 기존 빗줄기를 유지하고 벽 아래 바다를 열었다. |
| 가독성 | 8.2 | 양쪽 통행문과 바닥 경계를 유지했다. |
| 공간감 | 8.7 | 성가퀴, 벽 하단, 바다 사이에 높이 차를 두었다. |
| 양식 일치 | 8.4 | 기존 폭풍 성벽 자산의 색과 재질을 기준으로 삼았다. |
| 전투 구분 | 8.2 | 벽 바깥 시각 효과는 바닥과 전투 영역을 가리지 않는다. |
| 모바일 표현 | 8.1 | 812×375에서 경계가 보이며 추가 메시 2개와 31,556바이트 텍스처를 사용한다. |
| 평균 | 8.27 | 사전 자체 평가 |

같은 위치의 충돌 샘플 1,053개, 방 경로, 문 좌표·잠금, 보스 초기 배치, 저장 복귀, 소환, 추락 장면, 완료·출구를 변경 전후 비교했다. Chromium 소프트웨어 WebGL에서 셰이더·스크립트 오류가 없었고, 새 이미지가 실패하면 기존 지형이 그려졌다. 실기기 Safari 장시간 프레임은 미측정이다.
