# R1188 7분야 심사: 잘리던 사몽 잔영 3종 새 시트(Dots CX-0164CR r1 ROUGH 손질)

대상: 물감 철로의 유령 승객(S-05), 두족류 생체기계 침공병(S-06), 식탁의 마네킹 잔영(S-01).
- 원래 R200 시트는 칸이 좁아(97~126px), 공격 칸의 팔·의자·광선이 양옆에서 잘렸다(전수표 6~10칸).
- 새 시트는 칸 256×256에 같은 11칸 순서다. 손질(scripts/r1188-uncut-shades.py)에서는 알파 16 이하를 0으로 지우고, 칸마다 발을 y236에 맞췄다.
- 보이는 키는 예전 화면 크기에 맞춰 159·157.9·163.6으로 두었다.
- 적용은 samong-shades-r200.js 가 index 를 읽은 뒤 세 항목의 path·cell·pivot·visibleHeight 만 바꾸는 방식이다. 원래 값은 r1188Orig 에 남기고, uncut:false 로 끄면 원래 그림으로 돌아간다.

검증
- 실패 먼저 18/30, 지금 ALL PASS 30.
- 기존 r200·r203·r204·r444·r176 모두 통과했다.
- 새 시트는 칸마다 가장자리 여백이 20px 이상(아래 발 쪽 20px, 옆·위 35px 이상)이라 잘림이 없고, 발 줄은 236 하나로 맞다.
- 헤드리스 S-05에서 유령 승객, S-01에서 식탁 마네킹이 drawEnemy 로 r1188 시트를 그렸다. 원래 필터(saturate .8)도 그대로였다.
- 침공병(S-06)은 CPU 검사로만 확인했다.
- PR 826 안개는 실행 중 측정 방식이라 잘림 없는 새 시트는 자동으로 대상에서 빠진다(그 스레드 확인).
- 미검증: GPU, 실기기 모바일, 자연 플레이.
