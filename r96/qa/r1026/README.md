# R1026 적 피격·사망 효과음 또렷하게·생동감

사용자 요청(2026-11-14 01:43Z): "효과음들 특히 적피격,사망 더 잘들리고 스타,워크등 참고해서 더 생동역동성있게 음향전문가동반해서 전체적인퀄리티업".

**귀로 듣는 검증은 하지 않았다.** 아래 숫자는 헤드리스 Chromium 의 실제 엔진 출력(마스터 앞·압축기 뒤)과 CPU 모의 결과다. 실기기·스피커·이어폰으로 들어 본 사람은 아직 없다.

## 1. 원인

R993 믹스(`sfx-mix-r993.js`)는 몹 층(몹 피격·사망)을 맨 아래에 두었다(목표 −46·−43.5, 우선순위 1). 게다가 **이미 3음 이상 울리면 몹 소리를 아예 들이지 않았다.**
전투 중에는 영웅 평타·적중음·몹 공격만으로 거의 늘 3음이 차서, 몹 사망음이 대부분 빠졌다.

| 헤드리스 실제 엔진 같은 폭주 | 12번 중 1번 |

## 2. 고친 것(`r96/client-source/sfx-punch-r1026.js`, 재생 단계만, R993 에 훅 세 줄)

참고한 것은 RTS(스타크래프트·워크래프트류)의 **성격**뿐이다: 짧고 단단한 어택, 뚜렷한 중저음, 처치가 늘 들림, 사망 뒤 짧은 꼬리. 특정 게임의 소리·파일은 쓰지 않았다.

| 고침 | 값 |
|---|---|
| 사망음 자체 길 | 붐벼도 들임: 동시 2음·간격 .07초·초당 7번. 이미 2음이면 가장 오래된 사망음을 .018초에 걷고 새 처치를 냄. 전체 4음이 꽉 차면 더 낮은 순위 소리 하나를 미리 걷어 자리 만듦. 우선순위 4(몹 공격 1·적중음 2 위, 영웅 타격 어택 5·피격 9 아래) |
| 몰아 처치 | 간격에 걸려 빠진 처치마다 다음 사망음 +0.75dB(최대 +3dB) |
| 몹 피격 자체 길 | .09초에 한 번·동시 2음·초당 10번, 우선순위 2 |
| 음량 덧보정 | 몹 사망 +3.5dB, 몹 피격 +3.5dB, 적중음·보스 피격 +2.5dB (EQ 가 올린 몫 약 1dB 은 빼고 걸음). 피크 보호 .75 |
| EQ | 피격 240Hz +2dB(몸통)·1.9kHz +2.5dB(존재감), 사망 200Hz +2.5dB·1.6kHz +1.5dB. 150Hz 아래는 안 올림. 저사양(settings.lowFx, 모바일 기본)은 존재감 대역 하나만 |

## 4. 성능(모바일)

오프라인 렌더(헤드리스 소프트웨어, 4음/초·소리마다 1초, 끝난 노드를 끊지 않는 최악 조건) 20초 오디오 처리 시간:
기본 약 165ms → 소리마다 지연망을 만들면 약 1,100ms(+560%) → **공유 꼬리 버스 + EQ 약 500ms(약 +200%, 한 코어의 약 1.7%)**.
게임에서는 EQ 를 피격·사망에만 걸고 끝나고 .7초 뒤 끊으므로 실제는 이보다 작다(추정). 저사양은 EQ 1개. **실기기(아이폰 13 미니) 측정은 안 함.**
메모리: 새 버퍼·새 파일 없음(노드만).
