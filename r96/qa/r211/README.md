# R211 — 이지 모드 자연 진행 길잡이 막힘(dist00 도착 포털 앞) 수정

재현: 777 없이 새 게임 → 이지 → 길잡이. hub → dist00 에 들어가면 영웅이 (48.6~50.5, 56.5) 에서 경로를 가진 채 멈춤(40초 넘게 그대로).
증거: 그 자리에서 `blocked(x+.25,y,.27)` 이 R204 동굴 지형을 켜면 true, 끄면 false. `moveActor` 도 지형을 끄면 움직임.
777 시험에서는 다른 위치에서 시작해 드러나지 않았다.

원인 셋:
1. 좁은 목에서 거리장 흐림·잔물결(±.2칸)이 바닥을 깎아, 입구에서 이어진 길이 끊김(통로 반폭 보호는 넓은 곳 기준).
2. 길찾기(R100 navPath·원래 findPath)는 칸 중심만 .29(+.32)로 묻는다 → 두 칸 중심 사이 얇은 바위 띠를 못 봄.
3. R100 길안내 격자가 동굴 거리장이 만들어지기 전에 재어져 캐시됨(낡은 격자).

수정(cave-r204.js · polish-r100.js):
- 거리장 끝에 연결 보장: 원래 지형에서 입구·보호점으로부터 .27칸 몸으로 갈 수 있던, 아직 걸을 수 있는 점이 끊기면 원래 길을 따라 반경 .75칸만 바닥 깊이 .7까지 되돌림.
- 길로 보이는 이웃 칸 중심 사이 직선에 얇은 바위가 있으면 걷어냄(판정 감싸기와 같은 조건).
- 거리장을 만들면 R100 `resetNav()` 로 길안내 격자를 비우고, 지금 경로도 버려 새로 짜게 함.

검증: qa/r211 5/5(바뀌기 전 main 에서는 3개 실패 확인), r204 25/25, r152 11/11. 헤드리스 자연 진행에서 같은 자리를 지나 계속 이동.

## 설정 창 점검(이지 모드 자연 진행 뒤)
헤드리스로 설정 창의 입력 129개를 하나씩 바꿔 봄: 오류 0, 닫았다 다시 열어도 값 유지(128/129).
- 남은 1개는 '사몽 구역 분위기' 빠른 설정과 상세 설정이 같은 값을 쓰는데, 상세 쪽을 바꾸면 빠른 쪽이 따라가지 않던 것 → 양쪽 맞춤.
- 'R111 facing' 같은 영어 라벨 10개 → 한국어(설정 창은 한국어만).
- R137 라벨 '중간보스 크기 70%'·'환영 공격은 중간보스급 이상만' 이 R205 동작(50%·보스만 가끔)과 어긋남 → 라벨을 R205 기준으로.
