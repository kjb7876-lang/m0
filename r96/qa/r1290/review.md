# R1290 3D EGO 전환 뒤 렉 — 원인·고침·반투명 조사 (2026-11-21)

## 원인 (헤드리스 Chromium, 소프트웨어 렌더)
1. **그리기 push 핑퐁**: R1286 `ego-cloud`(1초마다)와 R1041 `hero-dots-fx`(2초마다, tick 안)가 `DrawCommands.prototype.push` 의 바깥 함수에 자기 표식이 없으면 다시 감쌌다. 서로 표식을 가려 번갈아 끝없이 감쌈.
   - 실측: 3D EGO 로 넘어온 뒤 4분 방치 → push 1회 28.5→158.4µs(5.6배), R1286 감싸기 22→137번 (`fail-first-browser.txt`).
   - CPU 가상 시계 600초: push 호출 깊이 19→419 (`fail-first-cpu.txt`). push 는 그리기 명령마다(화면당 수천 번) 불린다 → 시간이 갈수록 프레임이 무거워짐.
   - R1286 은 11-21 배포(EGO 진입 구름 오라)라 EGO 로 넘어온 뒤 체감했을 가능성이 큼. 실제로는 영웅과 무관하게 쌓인다.
2. **HUD 글자 핑퐁(전수 감시로 발견)**: R1113 페르소나·R1249 조작 안내가 `setHudTextR63R2` 를 같은 방식으로 번갈아 감쌈(600바퀴 깊이 25→1225, `fail-first-cpu-hud.txt`).

## 고침 (그림·판정·저장 변화 없음)
- 네 감싸기(R1286 push·ego·hurt, R1041 push, R1113 HUD, R1249 HUD)가 새 감싸개에 아래 감싸개의 `/^_*r\d+/` 표식을 옮겨 단다(R1244 ego-sovereign 과 같은 방식). 표식을 안 옮기는 다른 덧씌우기가 끼어도 한 번만 늘고 멈춘다.
- 검사: `r1290-wrap-cpu-check.cjs` 17/17(CI), `r1290-browser.mjs` 5/5(4분 방치 push 12.8→12.4µs, 감싸기 11→11), `rewrap-audit.mjs` 120초 전수 감시에서 계속 바뀌는 함수는 LAYOUT_HOOK_R204(접근자, 안 쌓임)·spawnBurnDeath3(로드 뒤 유한)뿐.
