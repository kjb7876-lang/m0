# R1112 히든 영웅 EGO 전수 복구 — 실제 화면 판독과 7분야 심사(자체, 헤드리스 화면 기준)

사용자 2026-11-16 10:43Z: "히든영웅에고 사몽이 환도영웅걸로 나오는문제, 에고이미지 전수조사해서 모션이랑 개선작업 지금 검도 휘고 공격모션도 환도랑 섞이고 윗부분 쪽이미지도 짤리고 총체적난국임".
수치 검사(환도 몸 명령 0)는 통과하고 있었으므로, 이번엔 새 판 시작 → 거점·스토리(dist02)·사몽 에피소드(S05)·사몽 세계(cult04 DREAM)·F EGO 각성·7회 사몽각성까지 실제 캡처를 눈으로 봤다.

## 7분야 심사
| 분야 | 점수 | 근거 |
|---|---|---|
| 미술 | 7.9 | 사몽각성 컷인이 EGO 원화(깃털·붉은 광륜·두건)로 바뀌어 HUD 초상과 같은 인물. 수묵 몸이 시작부터 한 가지 그림체. 휜 검은 남음. |
| 연출 | 8.0 | 사몽각성 순간 '환도 · 11초' 대신 '마지막 수호자 EGO · 11초' — 정체가 끊기지 않음. 가운데 큰 컷인도 EGO. |
| 카메라·구도 | 7.8 | 크기·발 위치 그대로(미리 구운 그림도 같은 잘라낸 상자·칸). 컷인 위치·크기 그대로. |
| 공간·인테리어 | 7.8 | 수묵 맵 위에서 원본 3D 칸이 튀어나오던 이질감 사라짐. |
| 조명·색채 | 7.8 | 사몽 오라가 언주+흰빛(EGO 고유색). 머리 위 흰 고리는 엔진 사몽 공통 연출이라 남김. |
| 애니메이션·VFX | 7.7 | 첫 공격·첫 걷기에도 수묵 칸만(원본 섞임 0). 그림 받는 짧은 동안(보통 로딩 화면 안)은 몸이 한순간 비어 보일 수 있음. 검 휨은 남음. |
| UX·레벨 | 8.0 | 선택창 HIDDEN 표가 머리를 가리지 않음. 수묵·얼굴 끄기 설정 그대로(끄면 예전처럼 실행 중 굽기). 판정·키·피해 변화 없음. |
