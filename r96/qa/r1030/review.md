# R1030 심사표 — 플레이어(영웅)가 몹·맵 배경과 따로 노는 문제

사용자 2026-11-14 "플레이어가 다른 몹과 맵배경과 이질감이 느껴지는 문제 그렇다고 플레이어가 너무 안보여도안됨".
헤드리스(Chromium 소프트웨어 렌더링) 촬영 기준의 **임시** 심사다. GPU 실렌더·실기기·사람 손 플레이는 미검증. 심사는 작업자(Claude) 자체 심사다.

## 원인(전 촬영 1280×720, 환도 dist00 · 미카엘라 dist02 · 기억사수 ep1b07 · 네온 ep1a08)
- 밝은 옷 영웅(환도·미카엘라·기억사수·윤서하)의 몸 그림이 장면에서 가장 밝다. 그림 평균 밝기 98~132(0~255)인데 몹·바닥은 45~80 대. 화면에서 영웅 몸 밝은 픽셀은 둘레 바탕보다 70 넘게 밝아 '오려 붙인 하얀 종이'처럼 뜬다.
- 발밑 그림자가 옅어(엔진 알파 .075) 영웅이 바닥에 서 있지 않고 떠 보인다.
- 어두운 옷 영웅(네온·라우렌·헌터·슬레이어)은 이미 몹과 같은 명도 띠라 문제 없음 → 손대지 않음.

## 바꾼 것(`hero-harmony-r1030.js`, 그림 원본·판정·저장 그대로)
1. 노출 맞춤: 밝은 옷 영웅의 몸 그림만, 그 프레임 동안 엔진 색 필터 행렬에 x' = a·x + b 를 곱하고 그린 뒤 되돌린다. 평균을 장면 기준 92 쪽으로(최대 −30%), 줄어든 명암 폭은 대비(최대 ×1.16, 기준점 .42)로 되살린다. 등불처럼 아주 밝은 빛(R451 1.3 넘음) 밑에서는 덜 내린다. 셰이더·텍스처·굽기 추가 없음 → 모바일 비용 거의 0.
2. 발 닿음 그림자: drawHero 동안 엔진 그림자를 같은 자리에 좁고 짙게 한 번 더(폭 0.8배, 알파 .9). R821(찻잔 안의 집) 방은 이미 짙어 제외.
3. 테두리(R409·R434)·R453 빛 맞춤·R350 영웅 다시 보이기는 그대로 → 가독성의 뼈대는 유지.
- 끄기: 설정 '영웅 그림 장면 맞춤 (R1030)' 또는 localStorage `storyworld.r1030.heroHarmony` `{"on":false}`.
