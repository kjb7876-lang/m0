# R1186 7분야 심사: 꿈 층 몹 새 그림 2종(Dots CX-0161DR r1 ROUGH 손질)

대상은 m032 '인간의 뇌를 닮은 투명 연산 장치'(ep1b09 꿈 층)와 m049 '시간핵의 명령 잔류'(kair03 꿈 층)다.
손질은 scripts/r1186-dream-mob-sheets.py 가 맡았다. R1179 칠한 시트와 같은 4×3 칸·발 자리로 맞추고, 알파 16 이하는 0으로 지웠으며, 몸 키는 m032 137·m049 227로 실측했다.
적용은 R1179 덮어쓰기 표의 path·body 를 바꾸는 방식이다. 원래 R248 시트는 그대로 두었다.

검증
- 실패 먼저 10/17, 지금은 ALL PASS 17.
- 다른 검사 r1179 23/23, r248, r290, r410, r176, r1183 모두 통과.
- 헤드리스 ep1b09 에서 연산 장치(본몹·증원·우두머리)가 drawEnemy 로 r1186/mobs/m032.webp 를 그렸다.
- kair03 의 시간핵 잔류는 아직 깨어나지 않은 웨이브라 처음엔 아무것도 그리지 않았다(엔진 규칙대로). 깨운 뒤에는 r1186/mobs/m049.webp 를 그렸다.
- 미검증: GPU, 실기기, 자연 플레이.
