## 2. 측정 결과와 문제(우선순위)

파일 자체는 깨끗했다: 클리핑 0, 끝 딸깍 0, 시작 딸깍 1(r789 하나, 엔진이 6ms·R545 가 10ms 올림을 걸어 실제로는 안 남), 150Hz 아래·5kHz 위는 R545 이후 대부분 낮음.
문제는 여러 라운드가 따로 만든 소리가 한 믹스에서 만날 때였다.

1. **범주 안 음량 차가 큼**: 실제 출력 기준 스킬 16.5dB, UI 11.8dB, 보스 10.1dB, 영웅 피격 9dB(파일 기준 22dB) 폭. R544 영웅 피격 파일은 −31~−39 LUFS 로 다른 소리보다 8~15dB 작았다.
2. **본체가 잘리는 소리 3개**: 쾌적 계층의 역할 길이 상한(awake 1.5초·boss 1.7초·별칭 없는 종류 1.2초) 안에 본체가 없다.
   - 윤서하 EGO 각성: 0.25초 작은 소리 뒤 1.2초 무음 → 본체 에너지 11%만 재생
   - 보스 등장·운석 `boss` 의 암흑 공격 변주: 1.35초 무음 뒤 본체 → 52%
   - 불면귀 실비 시전 `r761BossRain`: 2.8초 크레셴도 → 16%
3. **몹 층이 영웅 소리와 같은 우선순위**: 별칭 없는 오버레이 종류(R788·R789·R954·R955 등 400여 개)는 우선순위 4 = 영웅 평타. 동시 4음 상한이 차면 같은 순위끼리 빼앗는다. 모의(몹 60번 300ms + 평타 6 + 피격 2)에서 영웅 타격 2번이 적중음에 빼앗김, 몹 층 동시 4.
4. **반복 피로**: 재생 속도 1 고정, 변주는 파일 2~4개 돌려쓰기뿐. 같은 몹이 연속으로 맞으면 같은 높이가 반복.
5. **더킹 없음**: 영웅 피격·보스 공격·사망·각성 때도 몹 층·적중음이 같은 크기로 겹침.
6. **엔진 미리 해독**(참고, 이번엔 안 고침): `warmAudio` 가 오디오 시작 때 soundProfiles 앞 24개 경로를 해독하는데 대부분 위 '거의 안 나는' 엔진 rc133 파일(48kHz 스테레오 2.25초 = 개당 약 0.86MB)이다. 모바일 메모리(#551 R980) 담당 스레드에 넘김.

없는 소리: 정적 검사로 '부르는데 프로필이 없는 종류'는 0(R787 의 접두어 문자열 하나뿐). 몹 실제 이름 기준 빠짐은 R955·R967 이 이미 채움(r955-name-sweep).

## 7. 남은 위험

- 귀로 안 들음: 목표 음량 위계가 실제 귀에 맞을 확률 약 75%. 영웅 피격 +14~+19dB 보정이 잡음을 같이 키울 확률 약 15%.
- 피치 흔들기 ±6% 가 몹 계열 고유 음색을 흐릴 확률 약 10%.
