# R230 — 몹이 위·아래에서 때릴 때 옆자리로 블링크한 뒤 공격

- 요청(2026-11-02): "모든 몹들 모션과 방향성 개선 — 방향성 개선에 한계가 있다면 가장 자연스러운 위치로 블링크·돌진 스킬을 쓴 다음 공격하여 공격 어색함 줄이기".
- 한계: 몹 그림은 대부분 옆모습 한 장(좌우 뒤집기)이다. 영웅이 화면에서 몹의 바로 위·아래에 있으면 옆을 보고 허공을 치는 것처럼 보였다.
- 고친 것(`mob-flank-r230.js`, R53 `canPrepare(e,'melee')` 감싸기):
  - 근접 공격을 시작하는 순간, 영웅이 화면에서 몹의 위·아래 쪽(가로 차이 < 세로 차이×0.8)이면 블링크한다.
  - 블링크 자리는 영웅의 왼쪽이나 오른쪽, 같은 화면 높이에서 공격 거리 0.75배 지점이다. 몹이 있던 쪽을 먼저 본다.
  - 사라지는 자리와 나타나는 자리에 작은 어둠 수축(pvfx-void-implosion)을 보여 준다.
  - 그 자리가 막혔거나, 영웅까지 시야가 없거나, 3.2칸보다 멀면 반대쪽을 본다. 둘 다 안 되면 원래 자리에서 공격한다.
  - 보스·중간보스·페르소나·고정형 탑(r170Tower)은 그대로 둔다. 같은 몹은 2.4초에 한 번만, 원거리 공격은 손대지 않는다.
  - 판정·피해·쿨다운은 그대로이고 자리만 바뀐다. 끄기: `storyworld.r230.flank` 에 `{"on":false}`.
- 순서: `guide-unstick-r222.js` 바로 뒤. r176 순서 검사 정규식에 이 줄을 선택 항목으로 더했다(openPanel/show* 를 감싸지 않음).
- 검사: `node r96/qa/r230/r230-cpu-check.cjs` 15/15.
- 헤드리스 dist02 전투(300틱): 근접 판정 9번 중 블링크 2번, 오류 0.
- 미검증: 자연 플레이 체감(블링크가 너무 잦거나 드문지), GPU·실기기.
