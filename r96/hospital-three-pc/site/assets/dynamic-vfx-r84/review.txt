StoryWorld Dynamic VFX — 독립 검토
검토일: 2026-10-23 UTC
판정: PASS (CPU/정적 구조 범위). 브라우저·GPU·시각 품질 검증 통과를 뜻하지 않습니다.

검토 대상
- 독립 동적 자산 패키지의 catalog.json / catalog.js, provenance.json, runtime.js, preview.js / index.html, 16 SVG, 검사·포장 스크립트.
- 이 검토에서는 게임 코드, 원본 PNG 픽셀, 세이브, 서사, 공개 배포를 수정하지 않았습니다.

PASS — 카탈로그와 원본 보존
- 고유 ID 80개: 기존 PNG 기반 64개 + source가 없는 신규 절차형 16개.
- 64 PNG를 품질선별 원본과 직접 바이트 비교했습니다. 모두 동일하며 합계 75,068,221 bytes입니다.
- 카탈로그/출처 기록의 SHA-256, 상대 파일 경로, 역할·장면·보스 매핑의 내부 일치 여부를 검사했습니다.
- catalog.js의 전역 배열과 catalog.json이 동일합니다. provenance의 두 카탈로그 파일 해시도 현재 파일과 일치합니다.
- 신규 16개는 재사용 가능한 설계안이며 확정된 서사 스킬이나 게임 구현이라고 주장하지 않습니다.

PASS — 시간 기반 런타임
- 실제 카탈로그 80개 × 121 시점 = 9,680 프레임을 별도로 샘플링했습니다.
- 동일 시간/시드의 결정성, 다른 시드의 상태 차이, 모든 숫자의 유한성, 알파 범위, 양수 선 폭, 입력 카탈로그 비변경을 확인했습니다.
- 음수·비유한 시간과 duration 이상 시간에서는 비활성/빈 프리미티브로 종료됩니다.
- 모든 효과에서 2개 이상의 레이어와 다수의 시간별 상태 변화가 확인됐습니다.
- 관측 최대 프리미티브는 67개이며 코드 상한 96개 이하입니다. 이는 성능 벤치마크가 아닙니다.
- PNG 기반 효과도 단순 흔들림만이 아닙니다. 출현 링, 이동 궤적/꼬리, 접촉 확산, 시드 입자, 소멸 단계가 역할에 따라 결합됩니다. 원본 PNG 자체는 단일 정적 이미지입니다.
- 황금 질서 장벽은 가로 이동 없이 등장 후 정지합니다. 부활 봉합은 안쪽으로 모이는 입자/봉합을 사용합니다. 초기 검토에서 발견된 두 역할 예외의 불일치는 수정 후 재검사했습니다.
- 모의 Canvas2D에서 유한한 좌표 인자, 이미지 종횡비 계산, save/restore 균형, 상태 복원을 검사했습니다. 실제 픽셀은 렌더링하지 않았습니다.
- 동봉 runtime-test-report.json의 runtime SHA-256은 현재 runtime.js와 일치합니다.

PASS — 미리보기 코드
- JS 구문 및 로컬 스크립트 참조를 검사했습니다.
- CPU DOM 모의 실행으로 선택, 이미지 로딩/실패 표시, 이전 이미지 콜백 격리, 절차형 SVG 링크, 시간 이동, 일시정지/재개 상태를 확인했습니다.
- 외부 네트워크에 의존하지 않는 구성입니다. 단, 각 브라우저의 로컬 파일 정책과 실제 DOM/Canvas 동작은 확인하지 않았습니다.

PASS — 독립 SVG 16개
- 모두 XML 파싱 가능하며 512 × 512 viewBox를 가집니다.
- 모티프별 기하 구조 서명이 서로 다릅니다. 단순히 동일 파일의 색만 바꾼 16벌이 아닙니다.
- 총 252개의 SMIL 애니메이션 요소를 확인했습니다. 시간 값, keyTimes 정렬/범위, values/keyPoints 개수 및 opacity 범위를 검사했습니다.
- 스크립트, 이벤트 속성, foreignObject, 임베디드 래스터, 외부 참조, 외부 엔티티가 없습니다. 내부 URL/참조는 존재하는 ID를 가리킵니다.
- vectors-manifest.json의 파일 해시와 애니메이션 개수는 현재 SVG와 일치합니다.
- SVG와 Canvas는 같은 16개 모티프의 별도 표현입니다. 형상·타이밍의 일대일 동일성이나 추가 16개 효과를 주장하지 않습니다.

PASS — 문서와 검사 도구의 주장 범위
- 시드는 sample의 세 번째 인자로 조절한다고 명시했습니다.
- verify-package.py는 기본적으로 카탈로그 해시를 확인하며, --originals를 제공한 경우에만 원본과 직접 바이트 비교합니다.
- 정적 구조/CPU 검사를 실제 시각 품질, 게임 적용, GPU 성능, 실플레이 검증과 명확히 구분합니다.

아카이브
- 이 보고서는 ZIP 생성 전에 작성됐습니다. 따라서 여기서는 최종 ZIP의 CRC/복원 검사를 수행했다고 주장하지 않습니다.
- 포장 스크립트는 각 파일의 독립 ZIP 크기를 계산해 9 MiB 이하 파트로 나누고, ZIP CRC 및 복원 바이트 SHA-256을 검사하도록 구성되어 있습니다.
- 실제 최종 파트의 결과는 포장 후 delivery-manifest.json 및 별도 최종 무결성 확인 결과를 따릅니다.

미검증 / 남아 있는 한계
- 실제 브라우저/SMIL 재생, Canvas 픽셀·GPU, 시각 품질과 작은 크기 가독성.
- 게임 통합, 실제 판정 범위, 투영/깊이, 원본 여백, 알파 혼합, 전투 의미와 실플레이.
- 프레임 성능, 장시간 메모리, 모바일/실기기, 화면 캡처 기반 검증.
- 본 패키지는 새로 그린 다중 프레임 스프라이트 시트나 동영상이 아닙니다.
- 이 범위에서 미해결 기능상 차단 결함은 발견하지 않았습니다. 실제 환경에서의 성공을 보장하지는 않습니다.
