현재 묶음 주의: 이번 정교화로 아래 기존 설명 중 원본 PNG 바이트보존 설명은 63개에만 해당합니다. 1개는 정교화 PNG로 교체했습니다. 현재 해시는 catalog.json 및 상위 current-assets.json을 사용하세요. refinement-audit.json은 래스터 교체 전 런타임 변경 당시의 검사 기록입니다.

StoryWorld 동적 VFX 자산팩 · 2026-10-23

구성
- 64종: 기존 품질선별 PNG를 바이트 그대로 보존하고 실시간 다층 타임라인을 추가했습니다.
- 16종: 황금실·은실 검무, 메스, 독주사기, 중독·출혈·감전·빙결·화상·매혹·약화·부패·구속·수확·질병·포탈의 신규 절차형 효과입니다.
- 80개 런타임 레시피 + 신규16종의 독립 SVG 표현입니다. SVG는 같은16종의 별도 표현이며 추가16종으로 중복 계산하지 않습니다. Canvas와 SVG의 세부 형상/타이밍은 일대일로 동일하지 않습니다. 카탈로그 설명은 모티프 설계 의도입니다.
- 신규 효과는 알려진 게임 모티프를 바탕으로 한 후보 디자인입니다. 피해·상태 판정·보스 패턴·저장 구조를 바꾸지 않습니다.

사용
1. 모든 분할 ZIP을 같은 새 폴더에 압축 해제합니다. 각 ZIP은 독립 ZIP이며 .z01 방식이 아닙니다.
2. StoryWorld-Dynamic-VFX/index.html을 브라우저에서 열어 선택·재생·중지·시간 이동·배경 전환을 사용합니다.
3. 로컬 파일 정책에 따라 브라우저에서 차단된다면 보안 설정을 해제하지 마세요. 승인된 개발 환경에서 통합 후 점검해야 합니다.
4. PNG 로드 실패는 화면에 표시됩니다. 신규 절차형16종은 PNG 없이 동작합니다.
5. vectors/ 의 SVG는 SMIL 지원 뷰어가 필요합니다. SVG를 Canvas 텍스처로 불러올 때 애니메이션 동작은 엔진/브라우저마다 다를 수 있습니다. 게임에서는 runtime.js 타임라인 API 사용을 권장합니다.

런타임 API
catalog.js는 STORY_VFX_CATALOG 배열, runtime.js는 StoryVFX를 제공합니다.
frame = StoryVFX.sample(effect, elapsedSeconds, seed)
StoryVFX.render(canvasContext2D, frame, sourceImageOrNull)
샘플링은 결정적이며 시드와 시간을 고정하면 결과가 동일합니다. 종료 이후 프리미티브가 제거됩니다.
프레임의 좌표는 중심 기준 정규화 좌표이며 렌더러는 캔버스 짧은 변의0.35를 기준 크기로 사용합니다.
원본 PNG는 이미지 객체로 불러옵니다. 이미지 원본을 변경하지 않습니다.
색상/기간은 카탈로그 복사본에서, 시드는 sample의 세 번째 인자에서 조절할 수 있습니다. 원본 파일은 보존하세요.

검증 범위
CPU: JS 구문, 카탈로그/경로, 수치 유한성, 시간 종료 정리, 결정성, 레이어/프리미티브 예산, 모의 Canvas 호출, PNG 원본 SHA-256, SVG XML/애니메이션 노드, ZIP CRC와 복원 검사를 수행합니다.
미검증: 실제 브라우저 재생·실제 GPU·실기기·게임 통합·실플레이·전투 가독성·프레임 성능·메모리·모바일.
모의 Canvas 검사는 렌더링 성공이나 시각 품질 검사가 아닙니다.
이 팩은 새로 그린 다중 프레임 스프라이트 시트/동영상이 아니라 실시간 PNG+벡터 레이어 애니메이션 자산입니다.
기존 PNG 가장자리 여백, 실제 판정 범위와 투영/깊이 문제는 게임 통합 시 별도 검증해야 합니다.
원본 서사·세이브·게임 코드·main·공개 배포는 변경하지 않았습니다.

재검사 (개발자용)
Node.js가 있는 승인된 환경에서 node test-runtime.cjs를 실행합니다.
Python이 있는 환경에서 python verify-package.py를 실행하면 카탈로그 SHA와 SVG 구조를 검사합니다.
원본 selected 폴더가 있다면 python verify-package.py --originals <selected 폴더 경로>로 바이트 직접 비교를 추가합니다.
검사 도구 설치나 보안 설정 변경은 포함하지 않습니다.


정교화 추가 기록 (런타임 1.1.0)
- 80개 레시피의 역할·동작 분기와 시간 변화를 코드 수준에서 검토했습니다.
- 수확 흡수, 속박 조임, 불꽃 방향, 금실/은실 매듭 순환을 개선했습니다.
- 전체 레시피의 지연 파티클이 생성 시점 전부터 나타나던 현상을 수정했습니다.
- 원본 PNG 64개와 SVG 16개, 카탈로그는 변경하지 않았습니다. 새 래스터 그림이나 애니메이션 프레임을 만든 것이 아닙니다.
- node test-runtime.cjs 및 node test-refinements.cjs 실행 가능. 상세 변경: refinement-audit.json.
- CPU 검증만 통과했습니다. 브라우저 재생·육안 품질·실기기·게임 통합은 검증하지 않았습니다. 기존 review.txt는 이전 버전의 기록이며 이번 변경의 증빙은 refinement-test-report.json입니다.
