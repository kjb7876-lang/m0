# StoryWorld 가시나무 속박 · 게임 통합 후보 v1

## 포함 파일
24개의 서로 다른 RGBA PNG 프레임(512×512), 4×6 아틀라스(2048×3072), timing.json, QA.json, 미리보기. 모든 그림은 이미지 생성 도구로 제작했으며 단일 그림 확대/회전으로 만든 동작이 아닙니다. 원본 샘플은 변경하지 않았습니다.

## 동작
- emerge 00–07: 땅에서 뿌리 출현, 위로 상승(각80ms).
- bind 08–11: 교차 감기 및 조임(각80ms).
- hold 12–15: 상태 유지 반복(각120ms). 상태 해제까지 반복하세요.
- release 16–23: 풀림과 붕괴(각80ms), 마지막 프레임에서 알파1→0 후 제거.
- 첫 프레임에 알파0→1을 적용하면 돌연 출현을 줄입니다. 알파 연출은 엔진에서 수행하며 새로운 그림 프레임으로 세지 않습니다.

## 배치/렌더링
고정 피벗은 좌상단 기준(256,440), 정규화(0.5,0.859375)입니다. 각 프레임은 같은512×512 캔버스입니다. 프레임별 자동 트림/스케일을 끄세요. 캐릭터 발밑 월드좌표에 한 번 정렬한 뒤 동일 배율을 유지합니다. 전체 케이지를 캐릭터 위에 Normal Alpha로 그리는 단일 레이어입니다. Additive 블렌딩은 나무가 발광체처럼 보이므로 사용하지 마세요. 아틀라스는 sRGB 색, straight alpha이며 첫 통합에서는 bilinear, clamp, mipmaps off를 권장합니다.

## 가림 처리 한계
정확한 앞/뒤 분리 레이어는 제공하지 않습니다. 단일 케이지 오버레이는 뿌리가 캐릭터 앞을 지나는 표현이며 뒤쪽까지 물리적으로 올바른 가림을 보장하지 않습니다. 캐릭터와 3D 깊이 통합이 필요하면 아트 작업으로 front/back 분리 또는 엔진 stencil/depth 마스크를 추가해야 합니다. 자동 수평 분할을 정확한 앞/뒤 레이어로 가장하지 않았습니다.

## 검증과 남은 작업
모든 PNG 디코딩, 실제 알파, 가장자리 비접촉,24개 프레임의 서로 다른 RGBA 해시를 CPU 검사했습니다. 회색 배경에서 전체 프레임을 육안 검토했습니다. 생성 특성상 뿌리 세부 형태/위치가 프레임 사이 조금 흔들리고 hold 경계에서 작은 변화가 보일 수 있습니다. 최종 release에는 흙 조각이 있어 알파로 지워야 합니다. 이 자료는 게임에 가져올 수 있는 통합 후보이며 Unity/Godot/실제 StoryWorld 게임, GPU, 모바일 성능에서 검증한 완성품이라고 주장하지 않습니다. 실제 장면에서 크기, 피벗, 가림과 타이밍을 확인하세요.

## 권한/원본
비공개 Drive에 저장. 기존 게임 코드와 배포를 수정하지 않았습니다. 원본 이미지 생성 시트와 별도로 패키징했습니다.

hold12–15는 반복 재생 가능하도록 구성했지만 완전한 무봉제(seamless) 루프를 보장하지 않습니다. 피벗과 배율은 실제 캐릭터별 체형/키/발 좌표에 맞춰 튜닝해야 하며 모든 영웅·보스에 자동으로 맞는 자산은 아닙니다. 미리보기는 시작/끝에 짧은 알파 페이드를 모사하며 hold를3회 재생합니다. 이 반복은 새 그림으로 세지 않습니다.
