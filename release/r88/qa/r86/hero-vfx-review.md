# R86 영웅 이미지·신규 자산 사용 검사

런타임 변경 없이 기존 보정과 실제 이미지 명령을 다시 검사했다. 최종 전체 검사는 root의 빌드 후 다시 실행해야 한다.

- 영웅 8명, 원본 경로 520개를 4개 시점에서 검사했다(2,080 프레임). 실제 이미지 122개의 크기·투명도·재단 영역을 읽었고, 발 피벗 오차는 기준 몸 높이 66에서 최대 약 2.78픽셀이었다.
- 8명 × 8상태 × 4방향 × 3줌에서 실제 drawHero 이미지 명령을 검사했다(768회). 스케일은 줌에 정확히 비례한다. 병원 호흡·발걸음의 원래 미세 변형은 유지된다.
- 4장의 CPU 원본 재단 비교표를 확인했다. 총 알파 높이가 큰 북쪽 공격 이미지는 위로 든 총·창·손을 포함한다. 이 외곽 높이를 몸 높이와 같게 축소하면 신체가 작아지므로 원래 신체 기준을 유지했다. 다른 화풍을 새로 통일하거나 이미지를 다시 그리지는 않았다.
- 신규 170 + 기존 84의 원본 254개 중 장면에 필요한 153개(신규 141, 기존 12)를 선별했다. 소품 개념 91개, 서사 패널 배경 62개로 모든 선별 자산에 연결 경로가 있다. 나머지 원본 101개는 다운로드한 원본 묶음에 보존한다. 이 101개를 게임 실행본에 모두 로드하거나 raw PNG로 포함했다는 의미는 아니다.
- 62개 장면에 배치된 소품 630개를 해당 좌표에서 실제 렌더 명령으로 검사했고 91개 소품 이미지가 모두 사용됐다. 새 장식 소품은 충돌체를 추가하지 않는다. 서사 이미지 62개는 패널 연결을 검사한 수치이며 전투 스프라이트로 그렸다고 주장하지 않는다.
- 선택된 VFX PNG 64개는 원본 해시와 동적 레시피가 일치한다. 총 80개는 PNG 기반 64개와 절차형 16개다. PNG는 16지역의 경고·투사체·피격·회복 사건에 연결되며, 절차형은 실검무·도구·상태이상·열린 포탈에 연결된다. 기존 r84 이벤트 검사에서 실제 사건별 재생도 별도 검증한다.
- 수정된 병상·휠체어·모니터는 실제 병원 소품 명령에 사용되고, 모래 궤적은 Kair 회복 효과에 연결된다. SVG 미리보기 16개는 게임에 중복 로드하지 않는다.

이 결과는 Node VM의 실제 게임 코드 호출, PNG/WebP 디코딩, 명령 재생에 대한 결과다. 실제 브라우저·GPU·자연 플레이 검사로 해석하면 안 된다.
