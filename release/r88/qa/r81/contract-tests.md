# Native runtime contract tests

These tests execute the retained game scripts in the existing Node VM harness. They call the real native map factories, 777 API, difficulty flow, save/restore, story controllers, collision functions, projectile ticks and RenderBridge capture. The harness stubs the DOM, image/audio loading, timers and renderer readiness. Passing results do **not** establish browser rendering, GPU operation, real image compositing, keyboard/mouse play or natural combat quality.

The current hospital B2 plan, with 8022 floor cells and 87 × 113 bounds, is the geometry reference. The retired diagonal V4 world map generator is not a visual-quality baseline. `canonical-v4-baseline.json` retains V4 identities, stats, story hashes, graph exits and original prop contracts only.

| Script | Coverage |
| --- | --- |
| `geometry-contracts.cjs` | All55 native world map plans agree with actual current hospital floor/walls; visible tile rectangles exactly match collision cells; no old backdrop/fog; scope guards. |
| `runtime-contracts.cjs` | All55 canonical actor/story/prop data, safe actor placement, 2×/6× champions, actual normal-start777 cave/swamp, real frame entity coordinates, wounded/dead save restore, native previous portal and leaving777. |
| `cold-restore-contracts.cjs` | Separate fresh Node process restores the swamp checkpoint written by runtime tests, including the fourth champion beyond native serialized index40. |
| `projectile-contracts.cjs` | Actual swept terrain contact and native friendly/hostile projectile ticks stop at shared baffles/closed doors and pass after native door/story progression. |
| `hospital-start-777.cjs` | The user's exact hospital-direct-start →777→cave/swamp path; current geometry, actual hero frame and safe actor placement. |
| `legacy-save-contracts.cjs` | A genuine V4 native777 swamp save migrates without healing, losing actors/progress, or adding champions; all living field actors remain reachable outside the locked boss room. |
| `legacy-castle-save-contracts.cjs` | A genuine V4 native777 hando02 save preserves HP/identity/progress and restores native two-gate defense/owner bindings on the new structure. |
| `legacy-scope-check.cjs` | Exact preserved V4 geometry and actor placement for scoped EGO factory builds, and unchanged DREAM geometry. |

Run `runtime-contracts.cjs` before `cold-restore-contracts.cjs`; the latter deliberately consumes a native save from a different process. The two legacy save fixtures were generated by the preserved sibling V4 harness using `--generate`, and record their source hashes. Regeneration requires that preserved V4 checkout; do not replace it with the current implementation.

The parent `run-suite.cjs` controls final acceptance and report counts. Files containing `diagnostic`, `trace`, or `before-field-relocation` are historical fault evidence, not passing acceptance results. Assisted combat/portal position fixtures are identified in their reports. No assertion treats assisted lethal damage as natural play.
