## 검사 범위와 남는 한계

검사는 Node VM의 원본 게임 함수, Three CPU 기하·투영·재질, 실제 로컬 HTTP 전송과 파일 해시를 사용합니다. 전투 진행에는 위치 이동·무적·적 HP 감소 보조가 들어갑니다. DOM·이미지 로드·음원·렌더 준비 상태는 대역을 사용합니다.

실제 브라우저/GPU 화면, 자연 플레이 난이도·카메라 느낌·다수 적의 가림, 음원 재생과 Windows START.cmd 실행은 검증하지 않았습니다. PNG 카메라 비교는 CPU 투영 도식이며 게임 화면 캡처가 아닙니다.

기존 지형과 캐릭터 시야를 유지하므로 초광폭 화면의 좁은 주사실 출구·모서리 입구에서는 외곽 여백이 남습니다. 회색 가짜 바닥은 어두운 비전투 배경으로 바뀌었습니다. 27개 투영 표본의 평균 바닥 점유율은 약 55.6%에서 73.4%로 늘었지만, 가장 좁은 초광폭 출구 표본은 외곽이 42.7% 남습니다. 이 수치를 실제 GPU 화면 검증으로 해석하면 안 됩니다.

원본 자산·음원·데이터·임베드 서사와 기존 런처 바이트 보존을 확인했습니다. V5는 별도 테스트 저장을 사용합니다. 공개 배포, main, gate/pin과 보안 설정은 변경하지 않았습니다.
