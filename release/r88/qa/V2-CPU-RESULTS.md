# 병원 미로 V2 검사 재현

이번 폴더의 결과는 V2의 최종 고정 소스 검사입니다. `final-run-results.json`에 게임 코드 해시와 각 프로세스 종료 결과를 기록했습니다. 기존 후보와 V1 기록은 역사적 자료이며 이번 통과 수에 합산하지 않습니다.

압축 최상위 폴더에서 Node로 실행합니다.

```sh
node qa/run-final.cjs
node qa/package-check.cjs
```

첫 명령은 구조·실제 Three 기하·진행 검사를 하고, 진행 검사에서 만든 합성 저장으로 독립 프로세스 복원·EGO·강화형 체력/크기·V1 이행 검사를 실행합니다. 두 번째는 원본 로컬 서버를 시작해 파일 전송과 음원 range 전송을 검사한 뒤 종료합니다. 49328 포트의 기존 서버를 먼저 종료하세요.

게임 검사는 DOM/Image/Audio/타이머와 렌더러 준비 상태를 대체한 Node VM입니다. 위치 이동·무적·강제 처치와 난이도 선택을 보조합니다. 실제 브라우저, GPU, 화면 가림의 시각 품질, 자연 전투, 사운드 재생, Windows 런처 실행 검증은 아닙니다. 지붕은 실제 Three 라이브러리의 BufferGeometry를 검사했지만 WebGL 렌더러는 만들지 않았습니다.

`*-save.json`은 검사로 만든 합성 저장입니다. 사용자 실세이브가 아닙니다. V1 이행은 이전 실행본의 실제 합성 체크포인트 두 종류로 확인했습니다. `preservation-results.json`은 원본 파일·자산·음원·서사와 선택 PNG의 보존 검사입니다.
