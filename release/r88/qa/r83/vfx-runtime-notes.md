# Supplied static VFX components · R83

The supplied README and review catalog were read before selection. The source has 64 single static components: 48 upgraded selections and 16 retained originals. All 64 PNG bytes and the source review documents are copied unchanged into `hospital-three-pc/site/assets/vfx-r83/`.

Sixteen canonical boss regions each map to four components. The exact mapping, dimensions, source hashes, alpha bounds and selection decisions are in `vfx-role-map.json` and `client-source/vfx-selected-data-r83.js`. Mapped scenes are the spider cave, swamp, seven pillars, fall, Leviathan, Beelzebub, Asmodeus, chairman, bootloader, controller, fallen knight, insomnia demon, Siren Mor, rooftop cycle, cult threshold and cult finale.

These images supplement native events; they do not create new attacks or damage. The original projectile core/trail, hit admission, skill timing, statuses, collision and exact ground footprints remain authoritative. Charge images are small caster emblems above the body. They never replace a ground telegraph: several supplied warnings have a shape that differs from the native hit area. Projectile artwork without a unique forward axis becomes a stationary caster emblem. Ten narrower components use a measured alpha-weighted PCA axis, with the sign chosen by visual inspection; that calibration is presentation metadata, not authored hit geometry. Upright golden-wall art stays upright. Full PNG canvases are retained so sparse endpoint pixels are not cropped.

Impact components appear only after actual native player HP loss from the relevant major enemy. Brief remnants decorate the native post-impact interval without claiming a hit. The cult resurrection stitch waits for the actual returned leader after story acknowledgement and all six Cosmic guardians, with native phase 2, finalStage 2 and an active body. The first KO does not show the stitch.

The standalone cache holds four images for the current scene and loads at most two concurrently. Changing scenes cancels requests, rejects late completion by generation and releases only this module's images. It does not clear the native image cache. Decorative quads are limited to 15% of the smaller viewport dimension; native projectile cores remain visible. Up to ten new draws per frame (four at low effects) and eight transient records are admitted. Failed optional loads preserve original rendering. No all-64 decoded residency is requested.

Validation uses actual delivered event hooks, source SHA256/PNG dimensions and real pinned Three CPU geometry/material conversion. Representative boss events are scripted, and the finale sequence uses assisted native summons, HP-zero cleanup and story advancement. No browser/GPU, frame-time measurement, Windows launcher execution or natural-play acceptance is claimed.
