# StoryWorld PC V12 / R88

FINAL42 그림 프레임 효과42종을 기존 PC 게임에 연결한 인계본입니다. 두 ZIP을 같은 새 폴더에 풀고 `hospital-refinement-v12/hospital-three-pc/START.cmd`를 실행하세요. 병원 바로 시작은 설정 안에 있습니다. 일반 플레이는 제목 화면에서 시작합니다.

## 적용 내용

원본 아틀라스42개, 저장 프레임680개(그림671개와 투명 종료9개)를 보존합니다. PNG를 재인코딩하지 않았습니다. F6 상태 효과6종은 원본16상태의 정/역방향30스텝을 따릅니다. source-over 합성을 사용하고, 프레임별 rect·고정 피벗·시간·레이어를 정규화합니다. 원본 문서와 개별 프레임은 source-patch/asset-source-docs/final42-r88에 있습니다.

접촉 타격, 실제 독/메스 명중, 주사기 비행, 활성 상태이상, 실 궤적, 모래 예고, 늪지대 공격, 사망·포탈 전환과 실제 서사 장면에 연결했습니다. ID별 연결은 handoff/EFFECT-MAPPING.json을 확인하세요. 없는 스킬이나 진행 목표를 만들지 않았습니다. 이미지를 읽는 동안에는 기존 연출을 유지하며, 같은 장면에서 아직 유효한 이벤트만 이어서 재생합니다. 장면 전환·사망·화면 밖 종료와 텍스처 메모리 한도를 관리합니다.

기존 그림3종(독 착탄213, 메스215, 가시 속박99)은 중복 실행하지 않습니다. 첫 뿌리 보스는 기존2.2초 속박·4회 지속 피해와 S 블링크 탈출을 유지합니다. 시각 연출은 기존 공격 판정·피해 계산·경고 범위·스킬 쿨타임을 따릅니다. 이전 코드/도형 기반 동적80종은 보류 상태를 유지합니다.

## 유지한 PC 개선

기본 시야는 가로·세로1.5배이며 사용자 설정을 보존합니다. 병원 문3개·소품11개·미로/전투/진행 구조를 유지합니다. 문 앞면, 카메라, 영웅/적 방향과 크기, 공격 고유색, 벡터 버퍼 재사용과 수동 기본 공격 회귀 검사를 유지합니다. 일반몹 기반 중간보스는 몸체2배·체력6배·공격력6배이며 고유 보스에는 중복 적용하지 않습니다. 포탈은 E 이동, 길잡이는 자동 보행입니다.

V11 저장 접두사 `storyworld.hospital-three-pc.maze.v11:`를 계속 사용합니다. 원본/B2 저장은 삭제하거나 자동으로 가져오지 않습니다. HAPIL, 원본 웹판·Godot·음원·서사·자산을 보존합니다.

## 검사 및 인계

현재 결과는 handoff/CURRENT-RESULTS.json과 qa/r88/final-suite.json이 기준입니다. qa/r81~r87 보고서는 해당 과거 시점의 자료입니다. CPU 검사는 Node VM, 고정 Three의 CPU 지오메트리·그리기 명령, 실제 파일 해시와 로컬 HTTP 검사입니다. 이동·전투·엔딩 검사는 좌표/피해/무적 보조가 있으므로 자연 플레이 검증이 아닙니다. 실제 Windows 실행·브라우저/WebGL 픽셀·물리 GPU·음원 재생·하드웨어 FPS의 검증 여부는 각각 기록된 결과를 확인하세요. 모든 환경에서 버그가 없다고 보증하지 않습니다.

독립 자산 미리보기는 실행 서버의 /final42-preview.html 입니다. 게임 통합·GPU 검증을 대신하지 않습니다. 가시 속박은 단일 레이어이고 앞뒤 분리와 매끄러운 반복은 미완성입니다. 원본132·260의 검수 제한도 KNOWN-LIMITS.md에 남겼습니다.

Claude Code에서는 handoff/HANDOFF.md부터 읽으세요. 전체 CPU 검사는 Linux/WSL·Node22·Python3·Pillow11.3.0 기준입니다. 먼저 서버를 종료하고 `python scripts/prepare-handoff-baselines.py`로 동봉한 비교 자료를 복원한 뒤 `node qa/r88/run-suite.cjs`를 실행합니다. 원본과 다른 기존 비교 파일은 덮어쓰지 않습니다. 소스 수정 위치와 재적용 주의사항은 handoff에 있습니다.

배포 승인과 실제 commit/PR/배포 완료는 서로 다른 단계입니다. 확인된 값만 handoff/BUILD-IDENTITY.json에 기록합니다.
