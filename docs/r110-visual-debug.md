- 빌드 결과를 정적 서버(127.0.0.1:4396)에 올리고 헤드리스 Chromium(Playwright, SwiftShader)으로 1100×720에서 순회.
- 이야기 지역 64곳(`regionById` 전체)과 사몽 16 에피소드 × 단계(생존·미로·상승, P는 상승만) 46곳에 들어가 스크린샷·콘솔 오류·각 오버레이 `inspect()` 실패 수·FPS를 모음.
