## 쓰지 않은 Drive 자산

| 자산 | 이유 |

| 학생 이동 4키 v2 (`1uMMS2__…`) | 안내 문서가 "엔진 적용은 HOLD" |
| M126 부분 묶음 | 3번 키 사용 금지·"NOT LOOP"·참고용 |

## 미검증

- 실제 GPU·실기기 모바일·자연 플레이에서의 걷기 자연스러움(헤드리스 Chromium 스크린샷만 확인).
- M119는 대기 그림만 있어 걸을 때도 대기 동작으로 보임(이동·공격 4키가 오면 교체).
- 종이 인형 스트립과 원래 Drive 한 장 그림의 크기·방향 차이는 스크린샷으로만 맞춰 봄.
