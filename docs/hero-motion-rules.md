# 영웅 모션 법칙 (R720)

사용자 요청(2026-11-11): 영웅이 이동·공격·스킬 등으로 동작을 바꿀 때 버그 없이 자연스럽게 이어지도록, AAA 액션 게임의 동작 전환 원칙을 참고해 법칙을 만든다.

참고한 원칙은 다음과 같다(외부 작품의 자산·코드는 쓰지 않고 원리만 따름).
- 동작 상태기계의 **우선순위**
- **커밋(최소 유지) 창**과 **캔슬 창**
- **슈퍼아머**
- **방향 결정 시점**
- **한 캐릭터 한 스케일**

## 규칙 위치

| 무엇 | 어디 |
|---|---|
| 규칙 값·판정 함수 | `r96/client-source/hero-motion-r720.js` → `window.__STORYWORLD_HERO_MOTION_R720__` |
| 규칙을 묻는 덧씌우기 | R93 서 있기 방향 · R119 걷기 · R143 공격/피격/R201 시트 · R271 환도 · R351 슬레이어 · R437 라우렌 공격 크기 · R440 스킬 휘두르기 |
| CPU 검사(CI) | `r96/qa/r720/r720-cpu-check.cjs` |
| 헤드리스 실측 | `r96/qa/r720/probe.mjs`(8영웅 전환 시나리오) → `rules.cjs`(위반 세기) → `strip.py`(몸 그림 띠) |

새 영웅이나 새 몸 그림 덧씌우기를 만들 때는 아래 규칙을 직접 다시 짜지 않는다. `__STORYWORLD_HERO_MOTION_R720__`의 함수를 물어본다.

## 규칙

1. **우선순위**: 사망 > 대시 > 피격 > 궁극기 > 스킬 > 기본 공격 > 이동 > 대기.
   - 피격은 기본 공격을 끊는다. 함수는 `hurtFirst()`.
   - 대시·스킬·궁극기 중에는 피격 그림으로 바뀌지 않는다(슈퍼아머).
   - 예외: 슬레이어는 기본 공격 중 피격에도 밀리지 않는다(광전사 슈퍼아머). 피격 시트가 없고, 옛 R143 피격 그림은 칼이 없는 다른 화풍이기 때문이다.
2. **커밋 창과 이동 캔슬**: 함수는 `moveCancel('attack'|'skill')`.
   - 기본 공격은 시작 후 0.12초, 스킬·궁극기는 0.18초 동안 이동 입력으로 끊기지 않는다. 그동안 예비 동작이 보인다.
   - 그 뒤 이동 입력이 들어오면 바로 걷기로 넘어간다. 공격 자세로 미끄러지지 않는다.
   - 판정·피해·쿨다운은 그대로다. 그림만 바뀐다.
3. **같은 시전 합치기**: 같은 종류(스킬 또는 궁극기) 값이 0.25초 안에 다시 오르면 같은 시전으로 본다. 휘두르기를 첫 칸으로 되감지 않는다. 함수는 `castStart()`.
4. **대시 방향**: 대시는 실제로 옮긴 화면 쪽(좌·우)을 본다. 함수는 `dash().side`.
   - 대시는 진행 중인 기본 공격을 끊는다. 대시 뒤에 옛 공격 칸이 다시 튀지 않는다.
   - 안전망: 대시 중 몸 그림이 반대쪽을 보면 이 파일의 바깥 감싸기가 발밑 세로선을 축으로 좌우를 뒤집는다(엔진 `move-right` 대시 그림 등).
5. **멈춘 직후 공격**: 이동 입력을 뗀 뒤 0.4초 안에 시작한 공격은 걷기 꼬리(멈춘 뒤 0.15초 걷기 유지)보다 먼저 보인다. 함수는 `attackOverTail()`.
   - 걸으면서 쏘는 공격(입력 중 공격)은 예전처럼 걷기 그림을 이어 간다.
6. **피격 타이밍**
   - 피격 반응은 맞은 뒤 0.12초 안에 시작하지 못하면 버린다(늦은 피격 금지). 함수는 `hurtFresh()`.
   - 피격 시간이 끝나면 0.05초 안에 피격 그림도 끝난다.
7. **대기 방향**: 공격·스킬로 몸을 돌렸으면 서 있기는 마지막 이동 방향이 아니라 그 방향을 본다.
8. **한 영웅 한 몸 크기**: 같은 영웅의 걷기·서 있기·공격 그림은 같은 몸 키 기준으로 맞춘다. 라우렌 새 공격 시트는 걷기 시트처럼 창을 포함한 205 기준으로 맞췄다.

끄기: `localStorage['storyworld.r720.motion']='{"on":false}'`. 이렇게 끄면 규칙 판정 함수만 꺼진다.

## 헤드리스 실측 결과(R720, 640×360, 게임 시간 기준)

시나리오(영웅마다 6.2초)는 다음 전환을 차례로 돈다.
- 걷기 → 멈추고 공격 → 반대로 걸어 캔슬
- 걸으며 공격
- 공격 중 오른쪽 대시, 왼쪽 대시
- 스킬 → 걷기
- 좌·우 표적 바꿔 연타
- 공격 중 피격
- 위 → 아래 걷기

| 위반 규칙 | 수정 전 | 수정 후 |
|---|---|---|
| M1 한 프레임 번쩍임 | 2 | 0 |
| M2 이동·대시 방향 반대 | 15 | 0 |
| M3 이동 중 공격·스킬 자세 남음 | 29 | 0 |
| M4 피격 늦음·안 보임 | 2 | 0 |
| 합계 | 48 | 0 |

M5·M7(키·가로 중심 튐)은 무기·자세까지 든 테두리로 재는 보조 지표라서 실패로 세지 않는다. 남은 22건은 몸 그림 띠로 하나씩 확인했다. 창·활·대검이 뻗거나 웅크린 자세여서 생긴 값이었다. 실제 크기 차이였던 라우렌 공격(+14%)은 규칙 8로 고쳤다.

검증 범위: 위 결과는 헤드리스 소프트웨어 렌더링으로만 측정했다. GPU, 실기기 모바일, 자연 플레이에서는 확인하지 않았다(미검증).
