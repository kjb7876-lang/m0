# SW-0010 r2 — 무한생존 전투 소유권과 본진 지휘

기준 커밋: c0633d98565f24551813c872cd7c9916d8d6a011. 작업 이슈: #749.

## 동작

- 환도 전용 적중 효과의 공통 fallback을 제거하고 발사/적중 시 영웅 소유자를 보존한다. R160 연속 기본 공격 burst도 실제 공격자의 효과를 사용한다.
- 기억사수 Q/W 지속 레이저와 지연 스킬은 시전자 몸과 방을 기억한다. 배치 해제·교체·지역 이탈 후 무효한 시전은 취소한다.
- 배치 창에서 같은 자리의 영웅 변경은 위치와 자리 강화를 유지한다. 배치 해제는 영입 보유를 유지하고 해당 자리의 강화 비용만 전액 반환한다.
- H는 정화구슬 고정 시점과 본영웅 시점을 전환한다. 먼저 내린 이동/공격 명령이 완료되면 주변 적을 찾아 자동 전투한다. 복귀 시 기존 반자동 설정을 복원한다.
- 본진 시점에서 빈 땅을 클릭하면 그 지점을 선택하고 배치 창을 연다. 본영웅에게 내린 명령은 유지한다. 화면의 H 버튼으로도 전환할 수 있다.

서사·기존 공격력·쿨타임·스폰·세이브 형식·미술 원본은 변경하지 않는다.

## 확인한 원인

1. R1027 `OWN_HIT[h] || 'slash-hwando'`가 다른 영웅에게 환도 검흔을 선택했다. 그리는 순간의 global player를 보는 경로도 남아 있었다.
2. 엔진 E568 적중 routing은 명시적 sourceHero가 있어도 현재 조작 영웅으로 효과를 선택할 수 있었다. 새 소유권 overlay가 해당 호출 범위에 정확한 context를 제공한다.
3. R561 draw의 Q/W 시작점은 global player를 사용했다. 배치 기억사수 시전이 다음 프레임에 본영웅으로 복귀한 뒤 잘못 그려졌다.

## 검증 제한

현재 작업 환경에서 Chromium 실행이 UNIX socket 권한 오류로 차단되었다. 로컬 실제 브라우저 검사를 통과했다고 주장하지 않는다. GitHub Actions에서 실제 빌드의 키보드·캔버스·배치 UI와 PC/모바일 크기 화면을 검사한다. 헤드리스 소프트웨어 렌더링과 모바일 크기 에뮬레이션은 GPU/모바일 실기기 검증과 구분한다.

시각 7분야 심사는 실제 생성된 전후 캡처 확인 후 기록한다. 확인 전 점수를 만들지 않는다.

## 이어서 확인한 수정

- 모바일 coarse 포인터에서는 header 전체가 숨겨져 H 진입 버튼이 보이지 않았다. stage에 44px 터치 버튼을 추가했고 상태 검사는 26/26 통과했다.
- 현재 장비 I·배치 B 매핑을 실제 소스에서 확인했다. 본진 배치 안내와 브라우저 검사는 B를 사용한다. 최초 브라우저 실행은 예전 I키 가정 때문에 실패했으며 이를 통과로 세지 않는다.
- 윤서하 Q/R 내부 예약은 시전자 몸에 묶어 동일 영웅 즉시 재배치 시 이전 시전을 취소한다. 다른 자리 해제 시 남은 영웅 시전은 유지한다. 슬롯 회귀는 수정 전 실제 2발 잔류로 실패 후 12/12 통과했다.
- 실제 hasTouch/isMobile/DPR3 조건의 터치 진입·복귀 검사와 본진 카메라 캡처를 추가했다. 최종 브라우저 결과 및 시각 심사는 후속 기록한다.

- 2차 실제 브라우저 실행: H 전환·명령 유지·카메라·레이저 소유권·모바일 터치 경로는 통과했다. 초기 배치 fixture에서 네온이 배치되지 않아, 이에 따른 5개 assertion이 실패했다. fixture 좌표 설정을 배치창의 전투 정지 뒤로 옮기고 실제 배치 확인을 추가했다(4자리·환불 조건을 낮추지 않음).
- 2차 캡처에서 PC 지휘 바가 HUD 뒤에 가리고 모바일 H 버튼이 기존 배치 버튼을 덮는 문제를 확인했다. PC 바를 HUD 위로, 터치 H를 기존 원형 버튼 위로, 터치 지휘 바를 왼쪽으로 옮기고 겹침 검사를 추가했다. 이 실행의 미술/연출/색채 임시점수 7.8/7.5/8.0은 최종 통과 점수가 아니다.

- 3차 브라우저 검사는 H·모바일 버튼 겹침 검사까지 통과했으나 배치 fixture 실패가 지속됐다. unchanged R706만 실행한 최소 재현에서 modal=true여도 실검무 종료 처리가 기억한 본체 좌표로 player를 복원함을 확인했다. 이전의 모달 이후 좌표 설정만으로는 충분하지 않았다. 초기 W/E/R 자동 시전을 잠그고 실제 실검무 종료 및 body 해제를 기다리도록 고쳤으며, 영입 UI 뒤 실제 슬롯 오프셋까지 엄격히 확인한다.
- 3차 전후 PNG 12장 검수: 미술 8.0, 연출 8.0, 카메라 8.0, 공간 8.0, 조명색채 8.1, 정적 VFX 7.8, UX 7.6 (평균 7.93). 헤드리스 정지 화면 한정 잠정평가이며, H 수정 참여자의 자체 검토가 포함되어 독립 검수로 부르지 않는다. 연속 모션·실 GPU·실기기는 미검증이다.
- 해당 캡처에서 PC 지휘 바에 일시 스킬 습득 알림이 겹치는 잔여 문제를 발견해 PC 바를 38px 위로 이동했다. 모바일 배치는 유지하며, 브라우저 검사에 알림 문구와의 사각형 겹침 확인을 추가했다. 최종 실행 결과는 PR의 Actions artifact로 제공한다.
