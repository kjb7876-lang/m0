# StoryWorld 효과음 대규칙 (R1049)

사용자 2026-11-15 09:01Z "대규칙 너가 게임에 맞게 세우고 효과음 조사해서 크게 엇나가는것들은 재생성하던가 무료효과음개선적용해줘".
새 효과음을 만들거나 고칠 때는 이 문서를 먼저 따른다. 수치는 `r96/qa/r1049/sound-rules.json` 하나에서 가져오고, 전수 대조는 `scripts/audit-sfx-r1049.py` 가 한다.

## 0. 한 줄 원칙

**고딕 호러 세계의 실제 사물 소리, 귀에 편하게, 누르면 바로.** 칩튠 삑소리·만화 소리는 쓰지 않는다. 재질은 쇠·뼈·천·유리·살·물·나무·돌로 정하고,
꼬리는 성당·병원 복도처럼 짧고 어둡게 둔다. 세 모드(스토리·무한생존·영화)는 같은 소리를 함께 쓴다.

## 1. 재는 방법 — 파일이 아니라 '플레이어가 듣는 소리'

게임은 파일을 그대로 틀지 않는다. 그래서 검사도 파일 그대로가 아니라 게임 재생 사슬을 흉내 낸 뒤 잰다.

1. R545: 150Hz 1극 고역통과 2단(모든 효과음 버퍼)
2. 쾌적 계층(`__STORYWORLD_SFX_COMFORT__`): 45Hz 고역통과, 역할별 저역통과 1극 2단(공격 3.4kHz·적 피격 3kHz·영웅 피격 2.6kHz·스킬 3.8kHz·보스 2.5kHz 등), 역할 길이 상한(공격 .65초·적 피격 .45초·스킬 1.2초·보스 1.7초 등). attack·enemyHit 은 늦게 오는 본체 시작점을 건너뛴다.
3. R993: 범주 목표 음량으로 맞춤, 변주, 붐빌 때 몹 층부터 빼기, 큰 소리 때 더킹. R1026: 몹 피격·사망 덧보정.

음량(크기)은 R993 이 맞추므로 이 규칙은 **소리 모양**을 본다.

## 2. 큰 위반 — 이것에 걸리면 고친다

| 규칙 | 뜻 | 기준 |
|---|---|---|
| M1_clip | 원본 클리핑(깨진 소리) | ±0.999 이상 표본 20개 이상 |
| M2_bodyCut | 역할 길이 상한에 본체가 잘림 | 상한 뒤 에너지 35% 이상 |
| M3_lateStart | 누르고 늦게 남 | 들리기 시작(최대의 10%)까지 150ms 이상 |
| M4_latePing | 끝에 '띡' 하는 높은 재어택 | R1026 검출기(재어택 +9dB·최대보다 8~26dB 작음·중심 1.4kHz 이상·.15초 뒤). 적·보스·적중·투사체·UI·영웅 피격·타격 범주. 영웅 스킬의 끝 울림은 설계된 꼬리라 뺀다 |
| M5_harsh | 2~5kHz 귀 찌름 | 자주 나는 범주(일반몹·적피격·타격·투사체·발걸음)에서 2~5kHz 비중 55% 넘음 |
| M6_boom | 150Hz 아래 쿵(스피커 터지는 느낌) | 재생 사슬 뒤 150Hz 아래 비중 25% 넘음 |
| M7_silent | 거의 안 들림 | 재생 사슬 뒤 피크 −40dB 아래 |
| M8_tone | 세계관 톤 이탈 | 생성 문구에 cute·boing·cartoon·toy·comic·goofy·funny·silly·whimsical·kazoo·8-bit·chiptune |

## 3. 목표치 — 새로 만드는 소리가 노릴 값 (11-10·11-14 사용자 지시)

- 150Hz 아래 8% 이하(재생 사슬 뒤).
- 자주 나는 소리는 2~5kHz 35% 이하.
- 시작은 10ms 넘게 부드럽게 올림(딸깍 없음). 끝은 페이드.
- 파일 피크 −9~−14dB.
- 변주 2개 이상(같은 소리 연타 방지).
- 끝 '띡' 없음. 초반 본체가 좋은 소리를 쓴다.

## 4. 영웅별 질감

| 영웅 | 핵심 재질 | 평타 | 스킬 방향 | 피할 것 |
|---|---|---|---|---|

| 미카엘라 | 빛·종·유리 | 따뜻한 작은 종(하트탄) | 빛기둥: 부드러운 합창풍 부풂 | 3kHz 위 날카로운 반짝임 과다 |
| 윤서하 | 태엽·시계·바람 | 똑딱 한 번 + 바람 | 시간 정지: 똑딱이 느려지며 얼어붙음 | 디지털 삑 |
| 헌터 | 나무 활·시위·불 | 시위 튕김 | 불화살: 시위 + 불 바람 | 총소리처럼 들리는 것 |
| 기억사수 | 소음 권총·기계 | 눌린 '퍽' + 작은 기계음 | 충전: 낮은 웅 → 깨끗한 발사 | 큰 폭발음 |
| 라우렌 | 결정·중력 | 결정 파동 | 중력 붕괴: 안으로 빨려든 뒤 결정 터짐 | 저음 웅웅 과다 |
| 네온 | 전기·네온관 | 작은 스파크 | 번개: 마른 '딱' + 짧은 지직 꼬리 | 긴 지직 소음 |
| 슬레이어 | 대검·사슬·무게 | 무거운 휘두름 | 내려찍기: 큰 바람 + 단단한 충격 + 사슬 | 150Hz 아래 쿵 과다 |

## 5. 보스 — 7대죄 톤 (서사·보스 설정은 바꾸지 않고 소리 방향만)

| 죄 | 소리 방향 |
|---|---|
| 교만 | 차가운 금속 공명, 높은 합창풍 울림, 기계 관절음 (예: 교만의 사이보그 교주) |
| 질투 | 긁는 현, 겹치는 속삭임, 엇박 |
| 분노 | 불·폭발, 짧고 거친 어택(저음은 150Hz 위로) |
| 나태 | 늘어지는 피치 하강, 느린 숨, 끈적한 꼬리 (예: 나태에 잠식된 남자) |
| 탐욕 | 동전·금고 — **맘몬 맵은 손대지 않는다(Codex 작업)** |
| 폭식 | 젖은 씹기·삼키기 |
| 색욕 | 숨결·비단·입술 (서윤 키스 입술 공격과 맞춤) |
| 불면귀 | 멈추는 시계·눈꺼풀·실 (기존 불면귀 소리 유지) |

어느 보스가 어느 죄인지는 정본 문장으로 확인된 것만 적는다.

## 6. EGO 특수

- 모든 영웅 공통 모티프 하나 + 그 영웅 질감.
- 0.2초 빨려듦(역방향 부풂) → 터짐 → 1초 안쪽 꼬리.
- 발동 때 다른 소리는 R993 더킹(−6dB)으로 물러난다.
- 한 판에 드물게 나는 소리라 가장 크게 둔다.

## 8. 새 소리를 만들 때 순서

1. 이 문서의 영웅·보스 표에서 재질과 피할 것을 고른다.
2. 생성 문구는 중립적으로("muffled/dark" 같은 말은 깨진 소리를 만든다), 만화·장난감 낱말 금지.
3. 만든 뒤 `python3 scripts/audit-sfx-r1049.py` 로 큰 위반 0 을 확인한다. 생성 비용이 드는 도구(ElevenLabs 등)는 사용자 허락 범위 안에서만.
4. 고칠 때는 원본을 덮지 않고 파생본을 만들어 경로만 바꿔 끼운다.

## 9. R1049 전수 결과

- 대상: R993 전수표 1,232줄(쓰이는 줄 1,187).
- 고치기 전 큰 위반 55파일: 끝 '띡' 22, 2~5kHz 찌름 23, 만화 소리 9(초원 슬라임), 쿵 3, 본체 잘림 1(겹침 있음).
- 모두 파생본으로 고침(`assets/r1049/sfx`, 원본 그대로) → 같은 측정으로 큰 위반 0.
- 크게 바뀐 것: 결정(crystal) 몹 공격 3개는 거의 전부 2~5kHz 울림이라 음높이 ×.65~.75 로 내림. 초원 슬라임 9개는 음높이 ×.8 과 저역통과로 어둡게 함.
- 미검증: 귀로 듣는 검증, 실기기. M8(톤)은 생성 문구로만 판정하므로 가공한 파생본의 톤은 사람이 들어 봐야 한다.
