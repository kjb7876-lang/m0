# 3D 범위 규칙 (R1389)

사용자 요청(2026-11-28 06:02Z): "발록·루시퍼 같은 챕터별 중요보스, 7대죄 모든 보스, 나머지 중요보스 … 둥근 구체나 네모가 많은 몹들만 3D, 3D 퀄 8점 이상만 3D, 나머지는 2D 로 해서 품질 높이기". "기계·유령처럼 일부러 기괴하게 만든 건 특색 있어 괜찮다".
이 규칙은 R1385 몹별 규칙(`docs/mob-2d3d-rule-r1385.md`) 위에 덧붙는다. 적용 `r96/client-source/mob-scope-r1389.js`, 판정 `scripts/r1389-scope.py`, 근거 `r96/qa/r1389/`.

## 규칙
1. 사용자가 카드·몹 단위로 정한 것은 그대로(`scope.json` card_locks, R1385 의 2D 잠금).
2. 3D 대상 = 중요 보스(`scope.json` boss) + 구체·핵·결정·점액, 네모·덩어리, 기계, 유령형 몹(`scope.json` shape). 대상이 아니면 2D.
3. 대상은 **3D 품질 8.5 이상 그리고 원화 닮음 8 이상**일 때만 3D. 3D 품질 = .40×9.5 + .35×(클립 점수 × 동작 폭 배율) + .25×원화 닮음.
   동작 폭 배율 = 공격·특수·시전 클립의 정점 이동 p90 ÷ 키 를 0.25 로 나눈 값(0.3~1). 측정 `r96/qa/r1389/amp.cjs`(+ `glb-amp-viewer.html`).
4. 지금 2D 인데 R1385 가 화면 색·전환 문턱으로 2D 유지한 몹은 2D(색 맞춘 GLB 가 오면 R1385 재측정).
5. 맘몬 맵(ep1b06·ep1b06b)과 설정으로 켜고 끄는 보스(발록·루시퍼·베엘제붑·분노의 귀·나태 남자)는 이 표 밖.
6. 켜고 끄기 `storyworld.r1389.scope`, 주소 `?scope89=1·0`. 자동 검사(webdriver)는 기본 꺼짐.

## 발견: 왜 몹·보스 3D 가 영웅보다 못한가
- HF+Dots 리깅 hq5 판 보스는 공격 동작 폭이 옛 Dots 모델보다 훨씬 작다(공격 p90/키: 서윤 0.45→0.04, 세이렌 0.26→0.005, 컨트롤러 0.41→0.09, 수호 프레임 0.38→0.09, 생체조 관리자 0.35→0.08).
- 그 전 hq 판(옛 뼈대 가중치 옮김)은 동작은 크지만 면 늘어남이 2~9%(기준 0.5%)라 쓸 수 없다(`stretch.cjs`).
- 그래서 큰 동작 + 깨끗한 면을 함께 얻는 길은 Dots r2 리깅(SW-R1354E)이나 보스별 손질이다.
