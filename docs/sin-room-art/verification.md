# 전용 보스방 조형물 검증 기록

사용자가 지정한 여섯 공간에 서로 다른 PNG 아틀라스 6종, 조형물 24개를 적용했다. 나태·질투는 거주집, 탐식은 호텔 주방, 색욕은 퇴폐적인 호텔 고급 바, 맘몬은 호텔 사장실과 기존 금고, 불 지른 자는 불이 난 호텔 식당이다. 교만은 기존 구성을 유지한다. 맘몬의 금고·현금 조형물을 다른 방에 재사용하지 않았다. 기존 공통 촛대·화로는 남아 있다.

## 브라우저와 이미지

실제 전체 빌드를 Chromium 헤드리스로 실행했다. 일반 STORY에서 기존 777 보조 진입 기능을 사용하고 게임을 일시정지해 카메라를 고정했다. 자동 이동·가이드는 끄고 캡처용 무적 상태를 사용했다. 자연 플레이나 실제 모바일 기기 검사는 아니다.

- 최종 캡처 21개: 일곱 방 × PC, 기본 모바일, 모바일 상세 각 1개.
- PC 1920×1080 / DPR 1. 모바일 390×844 CSS / DPR 3, PNG 1170×2532.
- 기본 카메라 `(16, 11)`, 상세 카메라 `(21, 10)`.
- 모든 최종 캡처에서 게임·페이지·리소스 오류 0, Three 렌더러 활성, 해당 방의 신규 소품 4개 및 PNG 로드 확인. 교만에는 신규 소품 없음.
- 브라우저의 실제 최종 렌더 명령에서 보이는 전용 그림의 sourceRect·투영 좌표·수직 평면 메타데이터도 검사했다.
- 이전 구성 캡처 21개는 이전 v1 증거의 바이트 그대로 보관했다. 적 위치와 순간 상태는 전후에 다를 수 있다.
- 전후 비교판 4개는 원본 화면 전체를 비율 유지 축소해 나란히 놓은 자료다. 게임 화면을 보정하거나 재생성하지 않았다.

원본 PNG와 JSON은 `/workspace/sin-room-art-evidence`, 비교판은 `/workspace/sin-room-art-delivery`에 있다. 파일별 해시와 검사 요약은 `evidence.json`에 기록한다. 실행 방법은 `implementation.md`를 따른다.

## 남은 한계와 통합 상태

새 가구와 기존 촛대·화로의 국소 겹침, 기존 단순한 맘몬 금고와 새 가구의 재질 차이는 남는다. 불 지른 자의 새 가구 불꽃은 정지 그림이며 새 화염 애니메이션이나 피해 영역을 추가하지 않았다.

실제 GPU·실제 모바일 기기·움직이는 카메라와 자연 보스전·성능/FPS·약 25분 전체 회귀 묶음은 미검증이다. 헤드리스 화면 점수는 그 범위의 임시 판단이다.

이전 GitHub 조회가 HTTP 403으로 차단되어 최신 main과 클로드의 원격 진행 변경을 확인하지 못했다. 거부된 조회를 반복하거나 다른 경로로 우회하지 않았다. 따라서 원격 충돌 안전성·CI·Pages 결과는 미검증이며, push·병합·공개 배포를 수행하지 않았다. 배포 전에는 저장소 접근을 복구하고 최신 main 반영, 공용 파일 충돌 검토, CI와 Pages 성공 확인이 필요하다.
