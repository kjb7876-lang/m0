## 맘몬과 기존 V16의 공존

`맘몬의 금고` PC에서 북쪽 문, 책상, 가죽 의자, 서랍장, 금고 위 돈다발, 옆 카트가 모두 보인다. 큰 장부와 녹색 뱅커 램프가 금고만 있던 공간에 사장실이라는 사용 목적을 더한다. 새 가구의 장축은 주변 사선 벽과 맞고, 바닥에 놓인 형태로 읽힌다. 화면 중앙의 전투 공간은 넓게 남아 있다.

PC와 모바일 상세 JSON은 기존 `mammon-miniature-v16-expanded-v3-furniture-depth`가 `on: true`이며 12개 가구를 기록한다. 같은 실행에서 `mammonFinish`는 `inherited: true`, `ownArchitecture: 0`, `safe: 1`, `cash: 5`이고, 현재 신규 아트는 `desk`, `chair`, `drawers`, `trolley` 네 종류다. 소스 읽기로 `pilotFinish()`가 기존 모듈의 `registered && on`을 보고 자체 철제 마감·황동 문틀 생성을 건너뛰는 것을 확인했다. 이 상태와 직접 본 화면은 건축 소유권을 기존 V16에 넘기면서 금고·돈다발·사무실 가구를 유지한다는 설명과 맞는다. V16 자체 수정이나 전체 구역의 모든 카메라 각도 검증을 수행한 것은 아니다.

표준 모바일은 책상·문·중앙 플레이어 위주의 좁은 구도여서 오른쪽 의자 일부와 금고가 프레임 밖이다. 상세 모바일에서는 의자·금고·현금 카트가 보이므로 이를 자산 누락으로 판단하지 않는다. 기존 촛대가 책상 앞면·의자 옆을 일부 가리는 점은 남지만 주 실루엣을 알아볼 수 있다.

## 남은 한계와 검사 구분

- 기존 촛대·가로등·돌 화로의 반복이 새 가구 앞이나 주변에 남는다. 특히 고급 바의 화로는 호텔 실내보다 던전의 인상을 더한다. 이번 통합으로 새로 생긴 현상으로 보이지 않지만 연출 점수를 제한한다.
- 새 세밀한 사무실 가구에 비해 기존 금고는 평평하고 단순한 재료로 보인다. 테마는 분명하지만 완전히 같은 표현 밀도는 아니다.
- 벽 둘레에 조형이 모여 전시장처럼 느껴질 여지는 있다. 중앙 전투 가독성과 교환된 연출 선택이다.
- 식당 조형물에 그려진 불꽃은 정적 아트다. 실제 화염 애니메이션, 불의 확산, 시간에 따른 조명 변화나 음향은 이 점수에 포함하지 않았다.
- 직접 열어 본 PC JSON 7개와 맘몬 모바일 상세에서 game/page/resource 오류 배열은 비어 있었다. ep1b08의 `art.last`는 앞서 방문한 방의 기록이고 `art.current.props` 및 `artCommands`는 비어 있으므로, 이를 교만에 화재 식당 아트가 적용된 증거로 읽지 않았다.
- `mammon-runtime.log`, `sin-art-runtime.log`, `sin-art-cpu.log`의 PASS 결과를 읽었다. 원본 진행·저장 복원 및 충돌 검사의 결과는 해당 자동 검사 로그의 근거이며, 이 연출 검토자가 재실행하거나 자연 플레이로 재현한 결과는 아니다.
- 브라우저 헤드리스 캡처와 CPU/자동 실행 결과는 물리 모바일 기기·실제 GPU·자연 플레이 검증과 구분한다. 실기기 입력, 움직이는 카메라 전 구간, 장시간 플레이, 자연스러운 보스전 체험은 미검증이다. 이 문서는 병합·배포 승인이나 Pages 성공 확인을 대신하지 않는다.
