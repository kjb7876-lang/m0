# 테마별 가구 비교판 전달 검사

판정: **PASS — 파일 전달 범위**. PC·모바일 비교판 4개를 실제로 열었으며, 교만의 최종 캡션 수정 후 PC 2/2와 모바일 2/2도 확인했다. 게임 코드·원본 캡처는 수정하지 않았다.

- 표기는 사용자 지정 테마와 일치한다: 나태는 방치된 거주집, 질투는 정돈된 거주집, 탐식은 호텔 전문 주방, 색욕은 퇴폐적인 호텔 고급 바, 맘몬은 호텔 사장실과 금고, 불 지른 자는 불타는 호텔 식당이다. 교만은 제목과 오른쪽 캡션에 기존 구성 유지로 표시했다.
- 왼쪽은 이전 가구 구성, 오른쪽은 이번 테마별 가구 적용이다. 4개 HTML의 이미지 28개를 디코딩해 `/workspace/sin-room-art-evidence/` 원본 PNG와 바이트 단위로 대조했고 모두 일치했다. 캡처 위에 그림을 합성하거나 보정한 결과가 아니다.
- CSS의 `width:100%;height:auto`로 종횡비를 유지하며, 실제 비교판에서 화면 전체와 HUD가 보인다. 확대 프레임을 중앙 시점 전후 비교로 혼용하지 않았다.
- 원본 폴더의 PNG 42개·상태 JSON 42개를 확인했다. 이전 화면 21개는 `/workspace/seven-sins-evidence/after-*`와 바이트가 동일하다. 이번 after 상태 JSON 21개에는 게임·페이지·리소스 오류가 없다.
- 캡션은 일반 STORY, 777 진입, 일시정지, 카메라 (16,11), PC 1920×1080 DPR1 / 모바일 390×844 CSS DPR3 조건을 표시한다. Chromium 헤드리스, 실기기·자연 전투 미검증, 공개 배포 미실행을 명시하며 과장된 검증 주장이 없다. 식당 불꽃은 정지 그림이라고 적었다.

비교판의 축소 때문에 세부 소품은 원본보다 작게 보인다. 실기기·자연 전투·동적 불꽃 또는 공개 배포를 이 전달 검사에서 새로 검증하지 않았다. 차단 사항은 없다.
