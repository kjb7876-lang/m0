## 검증 한계

- 이번 점수는 맘몬과 탐식 표본의 정지 화면에 관한 공간 평가다. 최신 통합본의 다른 5개 방까지 이 심사자가 재검토했다고 확대하지 않는다.
- V16 플래너 전체 가구의 노드별 위치 개수, 동적 가림, 문 개폐·충돌 반경·보스 진행·저장 복원은 별도 통합 테스트 범위다. 화면에서 비어 보이는 통로만으로 해당 동작의 통과를 선언하지 않는다.
- 실제 모바일 기기, 물리 GPU, 자연 플레이, 손가락 가림과 전투 중 프레임 성능은 미검증이다. 따라서 최종 그래픽 검증 완료나 공개 배포 승인으로 표현하지 않는다.
- 불타는 식당의 새 불꽃은 기존 심사에서 정적 환경 PNG로 구분했다. 이번 재심사는 해당 방의 불꽃 애니메이션을 새로 검증하지 않았다.

관찰한 범위에서 배포 후보의 공간 구성을 막는 새 결함은 발견하지 못했다.
