# 몹별 2D·3D 선택 규칙 (R1385)

사용자 요청(2026-11-27 23:49Z): "규칙 만들어서 3D 가 나은 건 3D, 2D 가 나은 건 2D 로, 일관성과 모션·미관에 중점을 둬서 몹 분리".
이 문서가 몹마다 2D 와 3D 중 무엇을 그릴지 정하는 기준이다. 판정표는 `r96/qa/r1385/decision.json`, 적용은 `r96/client-source/mob-dim-rule-r1385.js`.

## 1. 대상
- 3D 모델이 있는 몹·중간보스·보스만 고른다(3D 오버레이 R1312·R1315·R1316·R1317·R1322·R1322c·R1329·R1330·R1338·R1343·R1382, R1339 고품질 교체 포함).
- 3D 모델이 없는 몹은 2D 그대로다. 이 규칙이 새 3D 제작을 정하지는 않는다(3D 범위는 사용자 11-27 지시: 작업하던 몹 + 사용자 지시분).
- 영웅(3D 영웅 기본 규칙)은 이 규칙 밖이다.

## 2. 점수 (2D·3D 각각 10점 만점)
가중치: **일관성 0.40 · 모션 0.35 · 미관 0.25**.

### 일관성 (같은 몹이 동작·방향이 바뀌어도 같은 크기·같은 인물로 보이는가)
- 2D: 10 에서 뺀다
  - 대기·걷기·공격·피격 키(중앙값)의 최대/최소 차 5% 마다 −1(최대 −4)
  - 다른 인물·다른 결 그림이 섞임(R1377 대조 block 목록) −2
  - 위·아래 방향 전용 그림 없음(옆 그림 재사용) −1
  - 동작마다 다른 시트 계열이 3개 이상 섞임 −1
- 3D: 한 모델·한 뼈대라 기본 9.5. 기본 4동작(대기·걷기/떠서 이동·공격·피격) 클립 중 하나라도 없으면 7.

### 모션 (동작 수와 칸 수)
- 2D: 동작마다 (쓰인 칸 수 / 목표) × 2.5, 목표 = 대기 4·걷기 6·공격 6·피격 3. 공격·피격 칸은 그 이름의 그림이거나 그 상태에만 나온 칸만 센다.
- 3D: 대기·걷기·공격·피격 클립 각 2점 + 사망 1점 + 고유기(Attack_Special·Cast 등) 1점.

### 미관 (화면에서 보기 좋은가, 원화와 같은 몹으로 읽히는가)
- 2D = 선명도: 원본 칸 키 대비 화면 키(1280×720 기준) 배율이 1.15 를 넘으면 0.1 마다 −0.6(최대 −4).
- 3D = 원화 닮음(사람이 대조표로 매김): 같은 디자인 10 · 대체로 같음(색·비율 조금 다름) 8 · 비슷하나 다른 부분 뚜렷 6 · 다른 몹처럼 보임 3.
- 3D 원화 닮음이 6 미만이면 점수와 상관없이 **3D 금지**(다시 만들 대상으로 표시).

## 3. 결정 순서
1. **사용자가 몹 단위로 정한 것은 그대로**(잠금). 판정표의 `lock` 칸에 출처를 적는다. 사용자 '2D 몹·보스 극한 품질'(R1377) 로 Dots 2D 시트를 붙이는 보스(세이렌 모르·사이보그 회장)도 2D 잠금.
   - 사용자 11-28: 이 몹별 규칙이 '7대죄·금이 간 안경 지역 전부 3D' 보다 앞선다.
2. 3D 원화 닮음 < 6 → 2D.
3. 총점 차 = 3D − 2D. **+0.8 이상 → 3D, −0.8 이하 → 2D.**
4. 차가 ±0.8 안(비슷함) → 그 지역 다수 쪽(지역 통일, 사용자 11-26 규칙). 다수가 없으면 지금 상태 유지.
5. **지금 2D 인 몹을 3D 로 바꿀 때만** 더 엄격하게(QA 1차 6.96 뒤 11-28): 원화 닮음 **8 이상**이고, 게임 화면에서 3D 몸 색이 2D 와 크게 어긋나지 않아야 한다(평균 채도·밝기 차 각 0.12 이하, 둘 다 채도 0.2 이상이면 색상 차 30° 이하; `scripts/r1385-color.py` → `r96/qa/r1385/color.json`). 못 넘으면 2D 유지·3D 다시 만들 대상. 3D→2D 는 위 문턱 그대로.
6. 같은 몹의 우두머리·증원·추격대·중간보스판은 본 몹과 같은 결정.
7. 사몽·꿈 층·무한생존은 지금처럼 2D(3D 오버레이가 이야기 층만 그림).
