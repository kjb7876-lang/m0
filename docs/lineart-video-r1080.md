# R1080·R1081 시네마틱 영상 → 선 그림 장면, 선 그림 컷씬 수묵화풍

사용자 2026-11-15 15:15Z: "모든시네마틱영상 실로그린영상그걸로 대체생성하고 그것돌도 수묵화풍으로 개선".

읽은 뜻: '실로 그린 영상' = R880 선 그림 컷씬(SVG 선 그림). 게임 안 시네마틱 영상(mp4)을 모두 그 방식으로 다시 그려 대신 보이고, 선 그림 컷씬 전체를 맵 수묵화풍(R1055)과 같은 먹빛으로 바꾼다.

## 무엇이 바뀌나
- 영상 일곱 편이 나오던 자리에 **선 그림 장면**이 보인다. 뜨는 때·자막 문장과 시각·보스 이름 카드·건너뛰기·게임 멈춤·BGM·영상 소리는 그대로다(영상 모듈 파일은 고치지 않았다).
- 선 그림 컷씬(지역 54곳 + 이번 일곱 장면)이 **한지 바탕·먹선·중간 먹** 색으로 보인다. 장면 코드·자막·길이는 그대로, 색만 옮긴다.
- 원본 영상 파일은 그대로 남는다. 새 그림 파일·영상 파일·글은 없다(사이트 용량은 코드 약 60KB 늘어남).

## 어떻게 대신 그리나 (R1080)
- 영상 모듈이 올린 루트(`#r309v`·`#r372v`·`#r369v`·`#r368v`·`#r617v`) 안의 `<video>` 를 지우지 않고 투명하게만 한 뒤, 바로 뒤에 SVG 를 얹어 `video.currentTime` 을 따라 그린다.
- 그래서 영상이 시계와 소리 구실을 한다. 영상이 못 뜨면 영상 모듈의 원래 대비책대로 간다. 그리다 오류가 나면 선 그림을 걷고 영상을 다시 보인다.
- 끄기: `localStorage['storyworld.r1080.lineartVideo']='{"on":false}'` 또는 `__STORYWORLD_LINEART_VIDEO_R1080__.set({on:false})` → 원래 영상.
- 한 장면만 보기: `__STORYWORLD_LINEART_VIDEO_R1080__.preview('knight')` (실시간), `preview('knight',{at:5})` (정지 화면).

## 수묵화풍 (R1081)
- 화면 전체 필터가 아니라 색 규칙으로 옮긴다(흰 옷·흰 날개가 검게 뒤집히지 않게).

| 원래 | 수묵 |
|---|---|
| 어두운 종이 바탕 | 한지 색 |
| 밝은 잉크 선 | 먹 |
| 어두운 덩어리 채움 | 중간 먹(더 어두웠던 것이 더 짙게, 그 위의 먹선이 보임) |
| 흰 채움·색 채움 | 그대로(담채) |
| 밝은 색 선 | 같은 빛깔의 짙은 선 |
| 밤하늘 바림 | 한지 농담 |
| 빛 번짐(screen) | 옅은 색 번짐(multiply) |
| 암전·처음 어둠 | 빈 종이 |
| 가장자리 어둠 | 옅은 먹 바림 + 한지 결 |

- 먹·중간 먹·한지 색은 맵 수묵화풍(R1055)에서 고른 화풍 값을 읽는다(R1055 파일은 고치지 않음). 맵 수묵화풍이 꺼져 있어도 컷씬은 수묵으로 나온다(사용자 지시가 컷씬 자체의 화풍이므로).
- 끄기: `localStorage['storyworld.r1081.lineartInk']='{"on":false}'` 또는 `__STORYWORLD_LINEART_INK_R1081__.set({on:false})` → 다음 장면부터 원래 색.
