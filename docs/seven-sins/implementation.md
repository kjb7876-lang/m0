# 7대죄 보스방 실내 소품

사용자가 승인한 맘몬의 가구·금고 구성에 이어, 실제 STORY 보스방 여섯 곳에 각각 다른 소품을 추가했다. 기존 맘몬 방은 그대로 포함하며, 겨울 기억 구역(ep1b06b)은 변경하지 않았다. 별도 목업이 아니라 게임의 layout/render 훅으로 연결된다.

## 적용 범위

| 구역 | 서사 기반 구성 | 근거 위치 |
|---|---|---|
| ep1b02 나태 | 내려앉은 소파, 얼룩진 냉장고, 병과 읽지 않은 종이 | 정본 264–270행 |
| ep1b03 질투 | 정렬된 가구, 반복 사진과 훼손 흔적, 금이 간 유리 패널 | 정본 280–288행 |
| ep1b04 탐식 | 조리대의 정렬된 접시, 오븐·프라이팬, 하부의 버린 음식 | 정본 294–300행 |
| ep1b05 색욕 | 붉은 커튼, 비어 있는 객석, 뒤쪽 실과 하이힐 | 정본 308–314행 |
| ep1b06 탐욕 | 승인된 철제 벽·황동 문틀·책상·서랍장·돈다발·금고 유지 | 정본 322–326행 |
| ep1b07 분노 | 그을린 벤치·보관장, 청소 카트·물통·버려진 음식 쟁반 | 정본 343–349행 |
| ep1b08 교만 | 기록 콘솔·화면, 일곱 신호 단자, 전극 침상·보관 장치 | 정본 355–363행 |

정본: `story-source/hapil-canon-r106-improved.txt`. 구체적인 가구 형태·배치는 시각적 해석이다. 게임에 사건·대사·상호작용·보상은 추가하지 않았다. 교만은 백색 정장의 호텔 회장이며, 앞 장의 루시퍼로 교체하지 않는다.

## 보존과 구현

- `seven-sins-bossrooms.js` 하나에 새 가구·재질·충돌·렌더 수명주기를 격리했다. 맘몬 소스는 변경하지 않았다.
- 북쪽 벽과 서쪽 벽에 세 그룹씩 배치했다. 원래 바닥 배열·벽 객체·기둥·문 ID·진행 데이터는 보존하며, 가구 충돌만 새 layout 객체에 추가한다.
- 협동·사몽·다른 지역에는 적용하지 않는다. 상자·제단·문·기억·상호작용 소품을 숨기지 않는다. 새 가구와 겹치는 비상호작용 장식만 표시에서 제외한다.
- 기존 학교 목재 아틀라스를 읽기 전용으로 재사용한다. 새 이미지·유료 서비스·외부 게임 자산은 없다. 가구는 Three 메시이며, 동일 형상의 기하 자원을 공유한다. 신규 애니메이션이나 스킬 효과는 없다.
- 같은 장면의 layout 교체·지역 이동·장면 세대 변경에 맞춰 소유 자원을 정리한다. 오래된 이미지 로드/실패 콜백은 현재 장면을 바꾸지 않는다.
- Legacy 렌더러에서는 충돌 위치에 단순 가구 실루엣을 표시한다. 테마별 세부 표현은 Three 경로에 구현했으며 Legacy의 상세 아트는 동등하지 않다.
- 공용 변경은 스크립트 로딩, manifest/입력 목록, 공개 파일 검사 목록, 로딩 순서 검사와 CI 검사 연결 및 cave-r204 거리장에서 새 가구만 바위 생성에서 제외하는 조건에 한정한다. 통합 시 최신 main의 공용 목록과 다시 합쳐야 한다.

## 검증 범위

CPU: 여섯 방의 원본 불변성·범위·가구를 반영한 문 개폐 경로·보스 위치, 실제 메시 외곽·렌더 자원 회수·늦은 이미지 콜백·Legacy/상호작용 보호를 검사한다. 실제 컴파일 게임 VM에서는 일곱 방의 가구 충돌·일반 진입·보스 존재와 저장 복원의 보스 HP·문 상태·진행 단계를 검사한다.

브라우저: PC 1920×1080과 모바일 390×844 DPR3에서 같은 카메라(16,11)로 전후 캡처한다. 777 진입·일시정지 fixture이며 자연 전투 완료나 실제 모바일 기기 검증이 아니다. 화면 오류와 overlay 상태를 JSON으로 남긴다. 보완 확대 화면은 별도로 표기한다.

독립 검토 중 서랍 전면이 보관장 끝을 넘어가는 문제를 수정했다. 사진틀의 표시 높이와 오래된 이미지 실패 처리도 보완했다. 새 스크립트 추가 후 기존 로딩 순서 검사의 기대 목록을 갱신하고 재검사했다. 첫 실제 화면에서 색욕·교만의 새 가구가 벽/바위 덩어리로 덮이는 결함을 확인했다. R98의 지역별 높이 변환 제외 메타데이터와 cave 거리장의 가구 제외 조건으로 해결하고, 입장 후 높이 유지 및 바위 거리장 불변성 검사를 추가했다. 이때의 첫 후보 화면은 /workspace/seven-sins-first-candidate에 보존했다.

최종 검사·스크린샷 해시·심사 결과는 `evidence.json`과 분야별 review 문서에 기록한다. 실제 GPU·모바일 기기·자연 플레이·전체 25분 회귀 묶음은 미검증이다.

## 통합 상태

로컬 기준은 `c8861dbf4455c9cba6e5366b2dd03620e0e4d8ec`, 독립 브랜치는 `claude/seven-sins-bossrooms`이다. 원래 작업 디렉터리 `/workspace/m0`는 수정하지 않는다. 앞서 원격 GitHub 조회가 proxy 403으로 거부되어 최신 main/Claude PR과 공식 Issue 계약·원격 CI를 확인하지 못했다. 거부된 접근을 반복하거나 우회하지 않았다. 원격 잠금·충돌 안전성이 확인된 결과로 표시하지 않으며 push·PR·병합·공개 배포는 미실행이다.

접근이 복구되면 최신 main과 열린 작업의 변경 경로를 확인하고 공식 작업 계약에 이 범위를 반영한다. 공용 연결 파일을 통합하고 manifest를 재생성한 뒤 검사·독립 검토·CI를 거쳐 PR을 통합한다. Pages SHA와 공개 URL 검증 전에는 배포 완료로 보고하지 않는다.

로컬 실행: `python3 scripts/sync-r99.py seven-sins-bossrooms.js`, `python3 scripts/build-r96.py`, 빌드의 `r96/hospital-three-pc/site`를 로컬 정적 서버로 제공한다. 브라우저 검사는 `SINS_TEST_URL=http://127.0.0.1:4400/ node scripts/seven-sins-bossrooms.browser.cjs after`. CPU 검사는 `node r96/qa/seven-sins/bossrooms-cpu-check.cjs`, 실제 게임 VM 검사는 `node r96/qa/seven-sins/bossrooms-runtime-check.cjs`이다.

## 최종 결과

최종 빌드·6612개 배포 파일 바이트 대조·전용 CPU 검사·일곱 방 실제 게임 VM 저장 복원·최종 브라우저 캡처 21개가 통과했다. 지형 회귀 25/11/13개 및 로딩 순서 22개 검사도 통과했다.

7분야 잠정 점수: 미술 7.5, 연출 8.0, 카메라 8.0, 공간 8.0, 조명 7.76, VFX 8.0, UX 7.9. 평균 **7.88/10**으로 7.77 기준을 초과한다. 헤드리스 정지 화면에 한정한 임시 평가이며 실기기·자연 플레이의 최종 승인이 아니다. 미술·조명 개별 분야의 낮은 점수와 표면 질감 보완 의견은 그대로 남긴다.

사용한 스킬은 `storyworld-art-style`, `ecc-e2e-testing`이며 셸·Node VM·Chromium/Playwright와 독립 분야별 검토를 사용했다. 최신 main 접근·공식 계약/원격 CI 확인이 가능해져야 통합·배포 단계를 진행할 수 있다. 현재 사용자가 추가로 승인할 사항은 없으며 접근 복구 전까지 공개 반영은 보류한다.
