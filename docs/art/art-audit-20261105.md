# CX-0027 미술감독 전수조사

2026-11-05 · 기준 SHA `7b9da25ee932be41807e5284ca84c398f2223a64` · 작업 가지 `codex/cx-0027-art-director` · revision 1.

이 감사는 실제 빌드의 영웅·지역별 대표 몹과 보스·맵·조형물·효과·UI를 비교하는 기준 세트와 한국어 [Art Bible](art-bible.md)을 만든다. 게임 구현·원본 그림·서사·밸런스·맵 순서·판정·저장 형식을 변경하지 않는다. 현재 보이는 것을 평가한 것이며 제품 개선 전후 비교나 물리 GPU 검증이 아니다.

## 실행과 범위

처음 실제 실행 경로는 `/workspace/m0`, 초기 체크아웃 `e63500df77f95c790e4559d1711d780d2c0b4359`였다. 원격 main을 가져와 기준 SHA에서 전용 가지를 만들었다. 기존 원격 CX-0027 가지·PR·Art Bible 실행 산출물은 발견되지 않았다. 기존 협업 견본 SW-0001과 별개로 CX-0027의 직접 지정 범위를 따른다. 공식 운영 상태 확정은 이 문서의 역할이 아니다.

`python3 scripts/build-r96.py`로 4,796개 파일·907,380,628바이트를 재구성하고 manifest 해시 `fcdef5359fa367d7e42a8e6fa001c502b082c3db5b03b375e2ef78d3501cd701`를 검증했다. 원본과 조합된 빌드 파일의 바이트 검사이며 그래픽 품질 판정과 구분한다.

화면은 로컬 빌드, Chromium 헤드리스, ANGLE SwiftShader, Chromium 샌드박스 유지 조건이다. PC는 1920×1080·DPR1, 모바일은 Android 계열 사용자 에이전트·390×844 CSS px·DPR3·터치/모바일 에뮬레이션이다. 모바일 캡처의 실제 파일 크기는 1170×2532px다. 내부 WebGL DPR 상한은 이 파일 크기와 별개다. 이 감사는 실제 iPhone·Galaxy 기기나 Safari 검사가 아니다.

## 고정 비교 장면

- 영웅은 환도·미카엘라·기억사수 3명이며 대기/걷기/공격/피격을 각각 기록한다. 걷기는 실제 ArrowRight 입력 중, 다른 동작은 별도 세션의 상태 타이머를 정상 범위에 고정한 fixture다. 전체 공격 주기·8방향·피벗 흔들림의 검증으로 해석하지 않는다.
- 현재 `regionById`의 64개 지역을 원장으로 삼는다. 거점은 새 여정 화면, 나머지 지역은 같은 좌표 기준의 대표 배우 비교 장면이다. 보스/persona를 우선하고 일반 몹은 그림 경로별로 대표를 고른다. 최대8명을 비교 위치에 재배치하며 나머지는 manifest의 omitted로 남긴다. hidden 요청을 후속 렌더 오버레이가 무시하는 경우 화면 가장자리에 다른 개체가 보일 수 있다. 기본 e.path로 대표를 고른 세트는 서로 다른 R248 최종 시트를 모두 대표하지 않을 수 있다. 모든 보스의 모든 페이즈/모든 몹 개체를 본다는 뜻이 아니다.
- 고정 시드27, 지역 비교 시간77, 영웅 환도, 위치/카메라는 gatherAnchor 또는 `(16,32)`, 배우는 앞쪽에 정렬한다. 지역 순서와 실제 맵 구조는 원본 그대로이며 fixture 좌표는 자연 스폰 증거가 아니다.
- 미해금 지역 복원은 게임이 거점으로 돌려보낸다. 전환 실패의 실제 상태를 읽어 원인을 구분했고, 게임이 제공하는 별도777 세션으로 감사 입장을 진행했다. 해금 검사를 제품 코드에서 고치지 않았다. 실패·중단 로그는 증거 묶음에 남기며 성공 캡처를 보충한다.

- 메뉴는 실제 showSettings, 쪽지는 실제 R177 컴포넌트에 감사용 문장을 입력한 fixture다. 비공개 서사나 개인 저장을 사용하지 않는다. 사몽은 제품의777/DREAM/R103 진입 표본이다.

## 독립 심사

제작/캡처 담당과 다른 심사 에이전트가 실제 이미지와 연락시트를 열어 평가했다. 원본·연락시트 중 무엇을 봤는지 파일명과 SHA256을 기록한다. 연락시트는 축소되어 작은 디테일 평가의 한계가 있다. 보지 않은 장면에는 점수를 만들지 않는다.

## 확인한 기준 충돌

- 작업 설명의 환도 청록·은 / 미카엘라 금·청록과 현재 R302의 실버·골드 / 핏빛 장미·실버가 충돌한다. 옛 엔진 HEROES.color도 별도로 남는다. 이번 감사에서는 임의 색 교체 없이 CX-0025에 결정을 인계한다.
- 시트 제작 몸키180px와 엔진66×zoom 렌더 기준은 서로 다른 단위다. 작은 화면에서 윤곽이 약한 문제는 별도 평가하며180px를 그대로 화면에 강제하지 않는다.
- HAPIL/STORY/EGO/HP 등 기존 HUD 문자는 스킬의 한국어 UI 규칙과 불일치한다. 이번 감사에서 번역 변경을 하지 않는다.
- R317의 궁전·골목 자산은 원본 코드에서 temporary references로 명시되어 있다. 점수가 올라가도 완성 자산으로 바꾸어 보고하지 않는다.
- 평면 인물 중 병원 심부의 집도의는 R248 byName→m017→assets/r248/mobs/m017.webp 경로이며, 독립 심사자가 실제 시트 픽셀과 게임 화면을 대조해 임시 픽셀 자산의 화풍 혼입을 확인했다. 다른 개체는 e.path와 최종 R248/프로필 경로를 각각 대조하고 같은 원인이라고 단정하지 않는다.

## 분담과 후속

CX-0023은 모바일 내부 해상도/LOD/흐릿함, 지형 명도·경계·안개와 성능 예산을 맡는다. 이 감사는 해당 구현을 중복하지 않고 화면과 우선순위만 인계한다. CX-0025는 영웅 스킬별 도형→프레임 교체와 팔레트 충돌 결정을 맡는다. 이번 제품 변경 범위는 감사 문서·프로젝트 기준 스킬·평가/증거 도구뿐이다.

`ART_AUDIT_DEVICE=pc|mobile`로 병렬 수집 시 폴더를 분리한다. `ART_AUDIT_RESUME=1`은 성공 캡처만 이어받는다. 재개 전에 기준 SHA와 capture manifest를 비교하고 이전 실패 로그를 보존한다. ART_AUDIT_FACTORY=1은 네이티브 makeRoom으로 실제 빌드의 룸을 만들어 렌더하는 fixture이며 진입/복원 래퍼 검증과 구분한다. 렌더러와 원본 자산은 유지하며 ART_AUDIT_STATIC_CLOCK=1은 정지 비교 장면만 공식 Playwright clock으로100ms씩 전진시킨다. 실시간 동작·성능 측정 도구로 쓰지 않는다. 전송용 이미지와 결과 보고서는 저장소 밖 증거 묶음에 보존한다.

## 검증 한계

물리 GPU·실제 모바일·Safari·자연 캠페인 진행·전체 동작 연속성·각 보스의 모든 페이즈·모든 스킬/최고점·사용자 기존 저장·변경 후 성능·개선 전후 화면은 미검증이다. 이 문서와 평가 도구의 통과는 그 항목의 통과를 의미하지 않는다. 독립 점수의 증거 파일과 누락 목록을 확인한 뒤 후속 수정 결과를 같은 장면에서 비교한다.
