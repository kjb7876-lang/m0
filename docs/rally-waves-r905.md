# R905 보스 앞 집결 구간 나눠 깨우기 — 지역별 표

사용자 2026-11-12: "스토리모드 적들 몰리는 보스앞구간 한번에 다 생성하지말고 절반씩나눠서 두번생성해" → "꼭 두번말고 2-6번 사이에서 너가 변칙도 주면서 적용해줘 스토리모드 모든맵 서사에 맞추면 더 좋고".

- 대상: 보스 문 앞 중앙 전투실 집결(R78 rally) 지역 48곳. 고치기 전에는 살아 있는 필드 적 전부(아래 "전체" 열, 한 마리도 안 잡고 들어갔을 때)를 한 번에 깨웠다.
- 총 적 수·체력·처치 목표·기억 글은 그대로. 묶음 크기는 아무도 안 잡고 들어갔을 때 기준이며, 길에서 잡은 만큼 줄어든다(4마리 미만이면 나누지 않음).
- 다음 묶음(이른 쪽): 깨어 있는 적 0 → 0.4초 뒤 · 직전 묶음의 "비율" 이하로 줄면 1.2초 뒤 · "간격"(묶음마다 ±20%)이 지났고 다음 묶음을 더해도 절반(최소 8) 이하일 때.
- 하지 않는 곳: 영화 모드, 협동, 특수 진행 지역(hando01~03·kair02·kair03·last301·cult04 — 엔진 필드 웨이브가 이미 나눠 깨움), 병원(ep1a08), 맘몬의 금고 ep1b06(사용자 승인 대상이라 그대로).
