## 5. 적용 규칙
- 원본 PNG·ZIP은 컨테이너 밖으로 복사하지 않았고, 저장소에는 WebP 파생본만 들어간다.
- 디아블로 등 외부 게임 자산은 쓰지 않았다. 엔진은 그대로다.
- 그림 로딩: 지역 진입 때 `releaseImageMemory()`가 준비된 그림을 지우므로 세 오버레이는 그릴 때 `imageCache` 기준으로 다시 요청한다.
