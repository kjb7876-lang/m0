# StoryWorld 전체 서사 2D 자산 통합 안내

## 범위와 검증 수준

이 묶음은 독립 제작한 PNG 자산과 엔진 중립 메타데이터입니다. 실제 게임 소스에 적용하거나 실행하지 않았습니다. PNG 디코딩·해시·알파·크기 검사는 런타임 검증과 다릅니다. 충돌, 차폐, 스케일, 피벗, 프레임 애니메이션, 실제 메모리·성능은 별도 검증해야 합니다.

기준 소스 커밋은 `f81d0d78af5bce04532b948a3cee36aa4fd4d5b8`입니다. 기준 서사 원문의 SHA-256은 `47a09cda7444df1bc2a09063da0748b367029f5c1fdeffb5660c477e6c60bd7a`입니다. 서사 카탈로그에는 8개 부, 62개 장면, hub/village를 포함한 64개 포탈 지역이 있습니다. 장면 `09-1`과 `09-2`는 별도 문자열 ID이며, 단순 정수로 합치지 않습니다. 자산의 지역 배치는 이 원문과 대응하는 추천이지 새 서사 설정의 추가가 아닙니다.

## 화면 투영과 레이어

기준 카메라 소스 `client-source/camera-r63r1.js`는 `u=x-y`, `v=x+y`, 수직 계수 `TILE*0.5`를 사용합니다. 이는 바닥의 2:1 마름모 투영을 나타내며, 특정 물리 카메라 각도를 확정하지 않습니다.

- 이미 아이소메트릭으로 그려진 소품과 VFX는 화면에 정렬한 스프라이트를 출발점으로 삼습니다. 이미 그려진 마름모를 지면으로 다시 기울이거나 워핑하면 이중 투영이 됩니다.
- 실제 위에서 내려다본 바닥용 텍스처는 별도 유형으로 표시해야 합니다. `screen_aligned_isometric_sprite`와 `top_down_ground_texture`를 혼용하지 않습니다.
- 바닥 경고, 캐릭터 주변 효과, 전경 구조물, 높은 벽/지붕은 서로 다른 차폐 요구가 있습니다. 알파가 있다고 렌더 순서가 자동으로 올바른 것은 아닙니다.
- 자동 충돌 윤곽을 PNG 전체 사각형이나 알파 경계와 동일시하지 않습니다. 장식·잔상·그림자는 충돌체의 근거가 아닙니다.

## 바닥 전용 텍스처의 별도 계약

`client-source/elements-r74.js`의 `mask`/`drawPatch` 경로는 소스 영역을 64×64 정사각형으로 샘플링한 뒤 충돌·시야 경계로 마스킹하고 월드 바닥 기저로 변환합니다. 이 경로에는 전체 이미지 피벗 추천이 직접 적용되지 않습니다. 전용 바닥 텍스처는 정면 위에서 본 평면 무늬여야 하며, 아이소메트릭 타원·직립 기둥·카메라 정면 후광을 포함하지 않습니다. 작은 크기에서도 남는 굵은 패턴과 중심 정렬을 우선합니다.

현재 r74의 별도 warning/residue/fade 선택은 fire/frost/shock/corruption에 한정됩니다. 다른 효과에 새 단계 PNG를 제공해도 자동으로 단계 재생이 되는 것은 아닙니다. 특히 `client-source/combat-fields-r61.js`의 `assets/ailments-r61/{key}.webp` 경로는 바닥 워핑과 화면 정면의 접촉/상태 효과가 함께 사용합니다. 따라서 새 바닥 전용 PNG는 별도 파일 후보이며, 이 기존 공유 파일을 대체해서는 안 됩니다. 향후 명시적인 라우팅 변경과 검증이 필요합니다. 이 제작 단계에서는 이를 변경하지 않았습니다.

## 기존 자산 기술 방식과 독립 PNG

기준 `client-source/art-r74.json` 자산 기술에는 `sourceRect=[x,y,width,height]`, 잘라 읽는 영역 내부 좌표의 `pivot=[x,y]`, `visibleHeight`, `visibleBounds`가 존재합니다. 기존 시트도 균일 격자만 사용하는 구조가 아니므로 새 PNG를 임의의 4×2/8프레임 시트로 분할하지 않습니다.

독립 PNG의 전체 영역을 가리킬 때는 `[0,0,W,H]`가 기하학적 출발점입니다. 이는 실제 등록 코드나 임포트가 완료되었다는 뜻이 아닙니다. 기존 셀의 피벗 숫자를 다른 PNG에 복사하지 않습니다.

카탈로그의 자동 알파 바운드는 좌상단 원점, x는 오른쪽, y는 아래, 오른쪽/아래 경계는 제외하는 `[x0,y0,x1,y1]`입니다. 바운드의 아래쪽 중앙은 지면 접점과 다를 수 있습니다. 침대·기둥 같은 소품은 지면 발자국을, 투사체는 중심/진행축을, 분출형 효과는 발생점을 실제 그림을 보고 결정해야 합니다. 확정 전 좌표는 null 또는 미검증 추천으로 남깁니다.

`client-source/world-r74.js`는 일부 소품의 표시 높이를 `actorHeight()`에 대한 상대값으로 정합니다. 예를 들어 문은 1.65배, 나무는 2.65배, 작은 상자·그루터기·양치류는 0.65배입니다. 이는 해당 호출부의 참고값이며 모든 신규 자산의 표준 크기가 아닙니다. 최종 `drawAssetFrame3` 내부 변환은 이 제작 단계에서 확인하지 않았으므로 픽셀 대 월드 단위 비율을 단정하지 않습니다.

실제 보이는 물체 크기를 기준으로 비교하며 원본 종횡비를 유지합니다. 원본 캔버스 높이가 같아도 작은 유물과 높은 탑을 같은 화면 높이로 표시해서는 안 됩니다. 단위와 표시 높이는 실제 렌더러에서 확인한 뒤 지정합니다.

## 알파와 프레임

- 검정 RGB 배경처럼 보여도 알파0이면 합성 결과는 투명합니다. 반대로 검정으로 채운 불투명 배경은 투명이 아닙니다.
- Straight alpha(비연관 알파)와 premultiplied alpha(미리 곱한 알파)의 해석·블렌드 설정을 실제 렌더러와 일치시켜야 합니다. 알파0 영역의 숨은 RGB나 낮은 알파의 색상은 샘플링·보간·mipmap·블렌드 처리에 따라 프린지를 만들 수 있습니다. 원본 수치 검사와 대표 픽셀 샘플링은 셰이더/합성/런타임 통과 증거가 아니며 모든 엔진에서 테두리가 없다고 보장하지 않습니다.
- 밝은 배경, 어두운 배경, 실제 게임 바닥에서 반투명 테두리와 프린지를 확인합니다. 낮은 알파를 일괄 삭제하면 실·연기·서리·전기 같은 효과가 사라질 수 있습니다.
- `single`은 한 장의 자산입니다. 자동으로 움직이는 효과나 검증된 애니메이션이 아닙니다.
- `verifiedsheet`는 각 프레임 경계·순서·피벗·시간과 실제 재생 검증 증거가 있을 때만 사용합니다. 정렬되지 않은 여러 그림을 시트라고 부르지 않습니다.

## 메모리와 원본 보존

기본 RGBA8 추정은 `W×H×4`바이트입니다. 전체 mipmap 단순 추정은 그 값의 약 `4/3`입니다. PNG 파일 압축률, 알파 투명 여백, 빈 배경은 이 기본 저장량을 줄이지 않습니다. 실제 GPU 압축, 캐시, CPU 복사본, 할당과 드라이버 비용은 포함하지 않은 추정입니다.

장면별로 필요한 자산만 로드하고 실제 표시 크기에서 품질과 비용을 확인합니다. 이 묶음은 원본을 크롭·리사이즈·아틀라스화하지 않습니다. 알파 정리 등 픽셀 가공은 이 제작 검사에서 수행하지 않습니다. 향후 별도 통합 작업으로 파생본이 필요하면 원본과 별도 경로로 만들고 피벗 및 바운드 변환을 추적해야 합니다.

## 서사와 플레이 보호

정확한 지역 ID와 역할별 공백은 `scene-coverage.json`을 기준으로 확인합니다. 범용 상태 효과는 지역 고유 VFX 확보로 계산하지 않으며, 이전 팩 재사용 후보도 실제 적용 완료로 계산하지 않습니다. 기존 스타일 이름보다 R75 정사 장면을 우선합니다. `kair06`은 겹치는 명령 층/관문, `cult05`는 현실·성·기억의 귀환, `cult06`은 원래 목표 회복과 코어 접근로이며, 각각 과거의 오염 수로·생체 배양조·심판 법정으로 자동 치환하지 않습니다. 기억·구조 대상·의료진·주민을 공격 대상처럼 표현하지 않고, 원문에서 보존해야 하는 코어/기억문을 파괴 완료 장식으로 바꾸지 않습니다. 단서용 소품에 임의의 이름·대사·문서를 생성하여 정사처럼 추가하지 않습니다. 경고 효과는 실제 위험 구역의 모양과 안전 간격이 검증되기 전 장식 자산일 뿐입니다.

최종 확인 순서: 원본 해시 → 실제 이미지와 알파 → 지역/용도 → 투영 → 지면 또는 발생점 피벗 → 기준 물체 대비 크기 → 차폐/충돌 → 작은 화면에서 가독성 → 실제 목표 기기 성능. 이 안내는 Godot, Three.js 또는 StoryWorld 실행 통과 증명서가 아닙니다.

## 파일 구성과 이전 자산

모든 JSON의 파일 경로는 묶음 최상위 폴더 기준입니다. `new_assets/`는 이번 제작의 주 자산이고, `prior_assets/`는 이전 84개 원본입니다. 이전 원본은 새로 생성한 수에 포함하지 않습니다. 방향/문 열림 변형도 새 서사 대상의 추가와 구분합니다. `new-assets.json`, `prior-assets.json`, `scene-coverage.json`에서 이미지 해시와 역할별 배치 제안을 확인합니다. 제외한 대체안·미정렬 단계 그림·거절본은 주 자산 목록에 포함하지 않습니다. ep1a08/ep1a09/dreamRest/restEp1b의 이전 소품 재사용은 추천이며 실제 적용 완료가 아닙니다.
